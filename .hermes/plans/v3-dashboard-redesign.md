> Hermes 编写 | 2026-05-02 | 取代 v3-architecture-analysis.md 的 Phase 4

---

## 🧠 设计原则

**不是换颜色，是换架构。** Azure Portal 的设计语言由以下核心模式构成：

| 维度 | Azure Portal 做法 | 当前 ASE Hub | 差距 |
|------|-------------------|-------------|------|
| **导航层级** | 顶栏 → 侧边栏 → 面包屑 → 内容区 | 只有侧边栏 | 缺2层 |
| **信息密度** | 瓦片(Tile)网格，不同尺寸 | 3个 stat card + 2个内容卡 | 密度低 |
| **空间利用** | 侧边栏可折叠到 50px | 固定 240px | 浪费空间 |
| **操作入口** | 顶栏全局搜索+通知+用户菜单 | 零 | 零 |
| **内容层级** | Hub(概览) → Blade(详情) | 平面 section 切换 | 无深度 |
| **组件语言** | Fluent Design (focus ring, subtle border, flat) | 零散自定义 | 缺乏一致性 |

## 📐 逐层设计

### Layer 1: 全局顶栏 (Top Command Bar)

```
┌──────────────────────────────────────────────────────────────────┐
│ ☰  ASE Hub              🔍 搜索资源、工具、文档...     🔔 ⚙️ 👤 ▾ │
└──────────────────────────────────────────────────────────────────┘
  ↑                      ↑                                ↑
  折叠侧边栏             全局搜索                         右侧操作区
```

| 元素 | 功能 | 实现 |
|------|------|------|
| ☰ 汉堡菜单 | 折叠/展开侧边栏 | JS toggle `.sidebar.collapsed` |
| ASE Hub 品牌 | 点击回仪表板 | `<a href="#" onclick="navigateTo('dashboard')">` |
| 🔍 全局搜索 | 跨 section 搜索 (Cmd+K) | 新组件 `global-search.js`，搜索所有 API 端点 |
| 🔔 通知 | 下拉通知列表 | 预留，v3.1 实现 |
| ⚙️ 设置 | 主题/语言/偏好 | 下拉菜单 |
| 👤 用户菜单 | 登出 | 下拉菜单 |

**样式要点**:
- 高度 48px，`position: sticky; top: 0; z-index: 200`
- 背景 `--bg-secondary` (#161B22)，底部分隔线 `border-bottom: 1px solid --border`
- 搜索框 360px 宽，聚焦时展开到 480px
- 右侧图标间距 8px

### Layer 2: 面包屑 (Breadcrumb)

```
仪表板 > 概览
```

- 高度 32px，`margin-left: var(--sidebar-width)`
- 当前页面高亮，历史可点击
- SPA 内通过 `navigateTo()` 更新

### Layer 4: 仪表板瓦片网格 (Dashboard Tile Grid)

Azure Portal 的仪表板是可定制的瓦片网格。我们将 `dashboard` 页面改造为：

```
┌────────────────┬──────────┬──────────┐
│ Azure 状态     │ VM 状态  │ 用户     │  ← 1×1 小型信息瓦片
│ 🟢 Normal     │ 🟢 OK   │ 1 admin  │
│ East Asia     │ 20.24.. │          │
├────────────────┴──────────┴──────────┤
│ 📊 服务健康                  ⚙️ ···  │  ← 2×1 宽型瓦片
│ 🟢 Compute 正常  🟢 Storage 正常    │
│ 🟡 Network 延迟                      │
├─────────────────────┬────────────────┤
│ 📝 最近更新          │ 🔗 快速链接    │  ← 2×1 宽型瓦片
│ · 2026-05-02 xxx   │ 定价计算器     │
│ · 2026-05-01 xxx   │ 文档中心       │
│ · 2026-04-30 xxx   │ GitHub 仓库    │
└─────────────────────┴────────────────┘
```

**瓦片规格**:
| 尺寸 | 列宽 | 用途 | 示例 |
|------|------|------|------|
| 1×1 | 1fr | 小型指标 | Azure 状态、VM 状态、用户数 |
| 2×1 | 2fr | 宽型列表 | 服务健康、最近更新、快速链接 |
| 2×2 | 2fr | 大型图表 | 预留：成本趋势图 |

**瓦片组件结构**:
```html
<div class="tile tile-1x1">
  <div class="tile-header">
    <span class="tile-title">Azure 状态</span>
    <button class="tile-action" title="刷新">↻</button>
  </div>
  <div class="tile-body">
    <span class="tile-value text-success">Normal</span>
    <span class="tile-subtitle">East Asia</span>
  </div>
</div>
```

**瓦片交互**:
- 每个瓦片右上角有 `···` 菜单：刷新、固定到收藏、全屏
- 刷新按钮带 loading spinner

### Layer 5: Blade 面板 (详情弹出)

Azure Portal 的核心交互模式是 **Blade** — 从右侧滑入的详情面板，取代当前的全页 section 切换。

```
┌──────────────────────────────┬─────────────────────┐
│                              │ Blade Panel         │
│  主内容区                     │ ──────────────────  │
│                              │ 翻译结果详情         │
│                              │                     │
│                              │ 术语: Availability  │
│                              │ 音标: /əˌveɪləˈbɪləti│
│                              │ 场景: 高可用架构     │
│                              │                     │
│                              │ 关闭 ✕              │
└──────────────────────────────┴─────────────────────┘
```

**何时使用 Blade**:
- 翻译工具：点击术语 → Blade 显示完整释义
- 定价：点击 SKU → Blade 显示详细规格
- 文档：阅读模式 → Blade 全屏阅读

**不适用 Blade 的场景** (保持 section 切换):
- 仪表板（概览页）
- 报告编辑（需要全宽）
- 用户管理（表格操作）
