## 交互流程

```
用户输入 "avail"  →  实时搜索建议下拉:
                    ├─ availability set → 可用性集
                    ├─ availability zone → 可用性区域
                    └─ ...

点击/Enter选择   →  右侧显示完整翻译卡片
                    同时自动加入"最近查询"列表 (顶部)

最近查询列表:
  - 最多 50 条
  - 存储在 localStorage
  - 每条显示: 🔊发音 | 术语 | → 中文 | ⭐收藏 | 📋复制
  - 点击术语重新查看
  - 最新查询在最上方
```

## 实现要点

1. **搜索建议**: 输入时 200ms 防抖 → GET /api/translate?q=... → 显示下拉
2. **翻译卡片**: 点击建议或按 Enter → 完整展示
3. **发音**: 两个按钮，分别调不同 voice
4. **历史记录**: 每次查询自动保存到 localStorage
5. **收藏**: 点击 ⭐ 切换状态，收藏项加星标显示
6. **复制**: 点击 📋 复制中文翻译到剪贴板
