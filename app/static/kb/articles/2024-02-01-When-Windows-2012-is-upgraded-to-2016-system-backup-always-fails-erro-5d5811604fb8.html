解决方案：出现该原因的报错可能会是由于Windows Server大版本变更导致的backup component file损坏，请建议客户通过下列方式手动重装一下最新版本的Backup extension：

Re-install the backup extension and have the latest version:

Open services, stop the service named ‘Windows Azure Guest Agent'

Rename the folder C:\Packages\Plugins\Microsoft.Azure.RecoveryServices.VMSnapshot as Microsoft.Azure.RecoveryServices.VMSnapshot.old

Export VMSnapshot registry key at HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows Azure\HandlerState\Microsoft.Azure.RecoveryServices.VMSnapshot_1.0.72.0

Delete HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\Windows Azure\HandlerState\Microsoft.Azure.RecoveryServices.VMSnapshot_1.0.72.0

Start the Service "WindowsAzureGuestAgent"

The above change DOES NOT require a server reboot
