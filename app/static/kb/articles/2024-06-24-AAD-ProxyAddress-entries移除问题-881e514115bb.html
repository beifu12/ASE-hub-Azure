AAD ProxyAddress entries移除问题

Lu Yitong

关于AADProxyAddress属性值是否可以移除的问题， 目前研究下来，大概分以下几种情况：

情况1：用户是从AAD Portal创建，或者B2C企业协作邀请Guest方式加入的，且用户没有O365订阅。

结论：无法移除ProxyAddress。这目前看应该是By Design的。

情况2：用户无论是从哪里创建的，但是有O365订阅。

结论：可以移除ProxyAddress。

方案：Powershell使用Exchange commands方式移除

If you have Exchange online of O365 with the same tenant domain, then the only way to fix it is to use Exchange Powershell cmdlet to add the offending smtp addresses back to the original account, then remove it.

Add:

Set-Mailbox account@domain.com -EmailAddresses @{add="smtpaddress@domain.com"}

Remove:

Set-Mailbox account@domain.com -EmailAddresses @{remove="smtpaddress@domain.com"}

===================

Reference doc: https://docs.microsoft.com/en-us/powershell/module/exchange/set-mailbox?view=exchange-ps
