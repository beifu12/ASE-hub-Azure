  • AzureVM使用删除虚拟机保留磁盘的方式，此步略

  • 使用方法很简单：四个参数
  • 运行WindowsAzureDiskResizer.exe
  • 使用刚才的VHD创建的虚拟磁盘
  • 使用新创建的磁盘重建虚拟机

排查思路

  • 磁盘管理器中查看如下图：diskmgmt.msc
  • 存储账号容器中查看VHD已经更改为30GB
  • 虚拟机创建完成后，登录系统验证

操作步骤 / 命令

  • 使用如下命令将C盘压缩为30GB ,如果没有1MB卷系统无法启动。
  • Get-Volume C |Resize-Partition -Size (30GB -1MB)
