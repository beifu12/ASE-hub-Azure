问题现象：

========

用户通过 az network bastion rdp的方式通过Bastion 访问到后端服务器后，copy paste 的功能键都变成了灰色。 该copy/paste 功能之前都一直正常。

az network bastion rdp --name "cn3-infra01-bas" --resource-group "vgcn-cn3-bastion-rg" --target-resource-id "/subscriptions/52124592-a676-49c7-8f0c-d4b63e9ab995/resourceGroups/VGCN-CN3-Vmtest-RG/providers/Microsoft.Compute/virtualMachines/C153683T01VM10"  --enable-mfa –config

排查过程：

=========

1， 根据官网说明及测试， 通过az network bastion rdp的方式通过Bastion 访问到后端服务器后是可以正常复制粘贴的。

参考：

https://docs.azure.cn/zh-cn/bastion/vm-upload-download-native#upload-and-download-files---windows-client-and-rdp

2， 客户端copy paste 到客户端自身没有问题， 服务器copy paste 到服务器自身也没有问题。 只有在通过bastion访问后， 客户端到服务器的copy paste 功能键为灰色。

bastion 的配置是沟选了 copy and paste 功能的：

3， 查RDP 文件本身的clipboard 是勾选状态：

4， 根据微软官网检查Clipboard 的配置：

： Get help with the clipboard - Microsoft Support

5， 进一步查询系统层面的组策略配置发现这里的“Do not allow drive redirection” 设置为Not configured 或者为Disable可以解决问题

Computer Configuration > Administrative Templates > Windows Components > Remote Desktop Services > Remote Desktop Session Host > Device and Resource Redirection >

组策略确实可以阻挡RDP session 中的clipboard file copy的功能。组策略默认状态是not configured。 这里的每一项的解释和使用均有相应的解释。
