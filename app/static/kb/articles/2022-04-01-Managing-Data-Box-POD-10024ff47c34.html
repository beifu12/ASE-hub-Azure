问题现象 / 场景

  • Data Box device orders are managed through the Azure portal. Once the device arrives at the customer's location and they connect it to their network, the customer will access the local web UI to configure the network ports in the device and obtain credentials for accessing the shares to copy data to or from the device.

背景信息

  • For import orders, the customer will run Prepare to Ship through the local web UI after copying their data onto the device, then they will ship the device back to the Azure data center.
  • For export orders, after the customer has copied the exported data off of the Data Box shares, they can delete their data from the Data Box device and then ship the device back to the Azure data center.
  • A basic overview of the Data Box service workflow can be found at the links below:
  • Get started with Azure Data Box to import data into Azure
  • Get started with Azure Data Box to export data from Azure
