2019-05-27

接着左大上次分享的共享映像库，继续研究了下，共享映像库不仅支持跨数据中心来调用镜像，还可以实现跨订阅、跨用户来访问使用。

https://docs.microsoft.com/en-us/azure/virtual-machines/windows/shared-image-galleries

根据官方文档，共享映像库SIG是tenant租户下的顶级资源，当我们为其配置RBAC来分配对应权限后，即可跨订阅、跨用户来进行调用。此外，映像库中的映像还可以根据我们的配置设定在不同区域产生指定数量的副本，以及映像的冗余方式（LRS、GRS、ZRS等）。具体配置步骤见下：

目前使用powershell和cli都可以配置此功能，创建完成后门户上可以看到对应资源但无法点击对应的功能按钮。Powershell需要安装azpowershell模块，老版本找不到最新的命令，本例仍使用cli

将虚拟机通用化并捕获成托管镜像：

使用az cli创建共享映像库

az sig create --resource-group resourcelht --gallery-name gallerylht

创建映像定义（映像定义相当于对映像库中所有映像逻辑上的一个分组，可以根据不同映像类型创建多个映像定义）

az sig image-definition create --resource-group resourcelht --gallery-name gallerylht --gallery-image-definition imagedef --publisher testlht --offer centos --sku 7.5 --os-type linux

创建映像版本（映像版本即根据源镜像生成的具体映像）

az sig image-version create --resource-group resourcelht --gallery-name gallerylht --gallery-image-definition imagedef --gallery-image-version 1.0.0 --managed-image “XXX" --target-regions "China North" "China East" "China North2" "China East2"（这里把中国区4个数据中心都设置可用，可自行更改）

为指定用户分配rbac权限

查看共享映像库id

az sig show --resource-group resourcelht --gallery-name gallerylht --query id

分配权限

az role assignment create --role "Reader" --assignee "XXX@microsoftinternal.partner.onmschina.cn" --scope “上面获取的映像库id”

完成上述步骤，登陆指定用户账号，使用命令创建VM测试成功
