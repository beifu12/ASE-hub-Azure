实验环境，使用Azure VM Ubuntu 24.04 LTS 镜像：

第一部分： 安装图形界面，以方便后续安装virt-manager。

具体步骤：

一、确保apt源可用并更新源

sudo apt-get update

二、安装桌面图形化显示

sudo apt-get install ubuntu-desktop

三、设置默认开启方式为图形化界面显示

sudo systemctl set-default graphical.target

四、 安装并配置 XRDP

XRDP 允许通过 RDP 协议进行远程连接，从而可以轻松访问服务器的桌面环境。

安装 XRDP：

sudo apt install xrdp -y

将 XRDP 用户添加到 ssl-cert 组：这对于安全连接是必要的。

sudo adduser xrdp ssl-cert

五、重启

reboot

第二部分：

安装virt-manager

virt-manager 简介：

Virt-Manager 是 Virtual Machine Manager 的缩写，是一个用于管理虚拟机的图形用户界面工具。它通过 libvirt 提供虚拟机的管理功能，主要用于 KVM（Kernel-based Virtual Machine），但也支持 Xen 和 LXC 容器。

Virt-Manager 提供了直观的界面，允许用户轻松地创建、编辑、启动、暂停、恢复和删除虚拟机。它还内置了 VNC 和 SPICE 客户端，用于查看虚拟机的全屏控制台。

Virt-Manager 的主要功能

虚拟机管理：支持本地或远程管理 KVM、Xen 和 QEMU 虚拟机。

资源监控：实时查看虚拟机和主机的性能统计信息，包括 CPU、内存、磁盘和网络使用情况。

虚拟硬件配置：支持添加、修改和删除虚拟硬件，如磁盘、网络接口、显示卡等。

克隆虚拟机：快速复制现有虚拟机，生成新的独立实例。

支持多种安装方式：支持本地 ISO 文件、网络安装（HTTP、FTP）或导入现有磁盘镜像。

具体安装步骤：

一、检查当前虚拟机是否开启了CPU硬件虚拟化，关于Azure Vm就需要选择之前嵌套虚拟化的机型，例如Dv3 、Dv4、Dv5等系列的虚拟机，我当前环境使用的是Dv3系列。

使用命令验证 egrep -c '(vmx|svm)' /proc/cpuinfo

其中，“vmx”是Intel平台下虚拟化术语，而“svm”是AMD平台下的虚拟化术语，若命令运行后输出数字大于0则说明物理CPU支持且已开启虚拟化功能。

二、安装virt-manager和依赖包：

sudo apt install qemu-kvm libvirt-daemon-system libvirt-clients bridge-utils virt-manager -y

启动并启用 libvirtd 服务

使用以下 systemctl 命令启动并启用 libvirtd 服务。

sudo systemctl enable --now libvirtd
