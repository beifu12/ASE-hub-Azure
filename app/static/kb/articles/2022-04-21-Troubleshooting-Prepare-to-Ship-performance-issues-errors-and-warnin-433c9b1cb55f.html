Contact the customer and gather as much information as you can about the issue (e.g. what is the error message on the client, any screenshots, past changes, operating system and any other additional relevant information)

During prepare to ship several tasks take place, Data box will validate and check data, perform checksums, etc. During this process different warnings or errors can occur.

Prepare to Ship should get completed with all stages green for the device to generate shipping label and ensure a successful data upload process.

The below error categories are seen:

1) Container of share names do not follow the Azure naming rules, total data in containers

2) Shares exceed the Azure limit

3) The object or files in containers or shares exceeds the Azure limit.

4) The data format or the file type is not supported.

5) The blob or file names do not follow the Azure naming rules or the file type is not supported.

Complete list of errors and resolution steps can be found at https://docs.microsoft.com/en-us/azure/databox/data-box-troubleshoot.

If not listed engage TA's or raise ICM

Troubleshooting and Tools:

1) Get into Webui, device will be reporting a warning/error

2)Unlock the device and go to the Connect and copy as shown below.

3) Have the customer Download issue list folder as shown in the screenshot below and upload it to the case for our review.

4) You will find an xml file in the folder and it will provide the exact error, description and resolution URL. The file output looks like the screenshot below.
