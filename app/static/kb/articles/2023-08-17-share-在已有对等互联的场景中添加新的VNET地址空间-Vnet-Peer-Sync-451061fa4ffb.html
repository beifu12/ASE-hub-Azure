该方法是通过最新版本的Az powershell模块来注册一个对等互联feature，之后在不移除对等互联的场景下新增地址空间。

测试环境：

rg-n2-vnet  地址空间：10.100.0.0/16，10.110.0.0/16，10.120.0.0/16，10.130.0.0/16，10.140.0.0/16

VirNet1 地址空间： 10.10.0.0/16，10.20.0.0/16

对等互联配置情况：

rg-n2-vnet 到VirNet1的对等互联名称为 to-1

VirNet1 到rg-n2-vnet的对等互联名称为 to-rg-n2

如下截图：

如下脚本是在VirNet1（spoke)中新增地址空间：10.21.0.0/16，之后使用命令同步对等互联。

参考脚本：

=========

if ((Get-AzProviderFeature -ProviderNamespace Microsoft.Network -ListAvailable | Where-Object featureName -eq "AllowUpdateAddressSpaceInPeeredVnets").RegistrationState -eq "NotRegistered") {

Register-AzProviderFeature -ProviderNamespace Microsoft.Network -FeatureName AllowUpdateAddressSpaceInPeeredVnets

}

#如上注册feature需要高于6.2以上的az模块版本才可以运行，因此执行该操作需要保证你的powershell Az模块是较新版本。我测试是7.2 。

#这个功能注册时间等待时间较长，大概20分钟左右，没有注册时显示为NotRegistered，注册中显示Registering，注册完成显示为Registered。

$rg1 = "TestGroup"

$rg2 = "RG-North2"

$vnethub = "rg-n2-vnet"

$peeringhubname = "to-1"

$vnetspok = "VirNet1"

$peeringspokname = "to-rg-n2"

Get-AzVirtualNetworkPeering -VirtualNetworkName $vnethub -ResourceGroupName $rg2 -Name $peeringhubname

Get-AzVirtualNetworkPeering -VirtualNetworkName $vnetspok -ResourceGroupName $rg1 -Name $peeringspokname

$spokeVVnet = Get-AzVirtualNetwork -name $vnetspok -ResourceGroupName $rg1

#添加地址段

$newIpRange = "10.21.0.0/16"

$spokeVVnet.AddressSpace.AddressPrefixes.Add($newIpRange)

Set-AzVirtualNetwork -VirtualNetwork $spokeVVnet

Sync-AzVirtualNetworkPeering -Name $peeringhubname -VirtualNetworkName $vnethub -ResourceGroupName $rg2

Sync-AzVirtualNetworkPeering -Name $peeringspokname -VirtualNetworkName $vnetspok -ResourceGroupName $rg1
