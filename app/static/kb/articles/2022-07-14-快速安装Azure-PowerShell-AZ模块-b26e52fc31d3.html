Windows Management Framework 5.1 内核版本

说明：如果用户安装Azure PowerShell 时，提示无法安装，或者提示内核版本较低，请升级时，通常也是在虚拟机Windows Server上需要升级、或者本地配置比较低的PC电脑上遇到。请尝试升级PowerShell：

官网链接：https://www.microsoft.com/en-us/download/confirmation.aspx?id=54616

另外，使用get-host 查看当前版本：

PS C:\> Get-Host

Name             : Windows PowerShell ISE Host

Version          : 5.1.17763.592

InstanceId       : c843d692-100f-436d-8483-57f9fe1df35a

Azure PowerShell 6.13.1：

说明：这是我们最熟悉的Azure PowerShell，并且已经更新到当前6.13.1，推荐使用。

官网GitHub链接：https://github.com/Azure/azure-powershell/releases/tag/v6.13.1-November2018

https://github.com/Azure/azure-powershell

Az 2.6.0 :

说明：Azure文档基本上都已变更成Az的指导命令，用户会特别需要这个版本的Powershell，推荐使用。

官网GitHub链接：https://github.com/Azure/azure-powershe ll/releases

另外，也已经下载出来放到我们的共享了，需要的话，也可以直接拿过来配置：
