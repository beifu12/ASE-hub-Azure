目前在Azure portal上创建专用AKS群集时,无法选择专用DNS zone,以下是我咋测试环境中测试的步骤:

参考文档:

https://docs.azure.cn/zh-cn/aks/private-clusters?tabs=default-basic-networking%2Cazure-portal#configure-a-private-dns-zone

1.  使用如下命令创建专用DNS zone:

az network private-dns zone create -g private -n private.chinanorth3.cx.prod.service.azk8s.cn

具体格式参考如下:

'private.chinanorth3.cx.prod.service.azk8s.cn,

privatelink.chinanorth3.cx.prod.service.azk8s.cn,

[a-zA-Z0-9-]{1,32}.private.chinanorth3.cx.prod.service.azk8s.cn,

[a-zA-Z0-9-]{1,32}.privatelink.chinanorth3.cx.prod.service.azk8s.cn'

2. 创建用户分配的托管标识(标黄部分自定义):

az identity create --name UserAssignedIdentity-aksprivate --resource-group private --location chinanorth3

3. 创建完成后,在专用DNS zone中,对上述创建的托管标识分配专用 DNS 区域参与者权限

4. 后续创建群集命令如下:

az aks create -n aksprivate -g private --enable-private-cluster --private-dns-zone “第一步创建的专用DNS zone资源ID”  --auto-upgrade-channel stable --ssh-access disabled --location chinanorth3 --assign-identity “第二步创建的托管标识资源ID”
