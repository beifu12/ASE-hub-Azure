First create a user:

Useradd user01

Then generate the ssh directory for this user:

Mkdir /home/user01/.ssh

Switch to this directory:

Cd /home/user01/.ssh

Create an authorized keys file in this directory.

Vim authorized keys

Then use the key generation tool to generate the public and private keys (here we use the tools that come with xshell. Putty also provides a similar tool):

The DSA encryption algorithm is selected by default.

Next, you can assign a password to this key:

The content of the key will be generated:

Save the contents of the key and paste it into the authorized_keys file：

When you are done, create a new connection：

Edit the authentication method and use the key we created before to authenticate：

After the connection is successful, you can't access the root privilege. You need to edit the sudo configuration file (this operation requires another session and needs to be on the root account to modify it)：

vim /etc/sudoers.d/waagent

Add the following line：

User01 ALL = (ALL) NOPASSWD: ALL

Save and exit, it should take effect immediately.
