测试重新安装

首先确认安装的python版本为2

python -V

下载安装脚本

wget https://github.com/microsoft/OMS-Agent-for-Linux/releases/download/OMSAgent_v1.13.9-0/omsagent-1.13.9-0.universal.x64.sh

最新的下载地址可以访问： https://github.com/microsoft/OMS-Agent-for-Linux#azure-install-guide

通过如下命令安装

sudo sh ./omsagent-1.13.9-0.universal.x64.sh --install -w <workspace id> -s <shared key> -d opinsights.azure.cn

安装时可以在LA的如下位置找到工作区id 和Key

安装之前如果这些软件仍然存在，需要提前卸载

sudo yum remove omi auoms

但通过这种方法卸载的软件，安装后会有报错提示：

安装后任然报错，请使用如下方法再进行删除一遍

sudo sh ./omsagent-1.13.9-0.universal.x64.sh --remove

然后在进行安装：

没有邮件的错误提示

安装后需要关闭重启虚拟机，再次查看扩展正常

如果是升级安装可以使用

sudo sh ./omsagent-1.13.9-0.universal.x64.sh --upgrade -w <workspace id> -s <shared key> -d opinsights.azure.cn
