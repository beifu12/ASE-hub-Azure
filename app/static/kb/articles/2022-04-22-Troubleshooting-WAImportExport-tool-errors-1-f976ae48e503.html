问题现象 / 场景

  • Contact the customer and gather as much information as you can about the issue (e.g. what is the error message on the client, any screenshots, past changes, operating system and any other additional relevant information)

背景信息

  • Make sure customer is following requirements accordingly: supported OS, software, storage account, disk type
  • Make sure the customer prepared the drive with the tool before starting the copy
  • Make sure the customer does not manually modify the journal file, if needed, a new one should be created.
  • If a copy session can't be resume or aborted: Delete the journal file and try again.
  • Engage TA's or raise ICM
  • After tool version 1.5.0.300 and later repair job is no longer supported.

排查思路

  • Check the tool version. Recommend to use the last one.
  • Check what command is the customer using.
