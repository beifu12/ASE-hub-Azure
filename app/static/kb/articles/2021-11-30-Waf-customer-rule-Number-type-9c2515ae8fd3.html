该规则表示它会检查名为 test-header这个RequestHeader的值，如果这个值小于数字5，则请求会被Deny，否则放行。

所以当我们使用数字4 作为 test-header的值 时，由于他小于5，所以命中规则，请求会被WAF阻止，得到403 Forbidden 响应。

而使用数字5 时，不满足小于5的条件，所以请求会被放行，收到200 OK 返回码。

需要注意的是，

选择Match type为Number时，请确保要匹配的值为数字，例如上例中所使用的数字4 和5。

如果匹配的值为字符 ，例如abc，请选用Match type String 。

如果选择Number 类型，而实际使用的是非数字值，所有字符 会按数字0 的效果来匹配。

还是以上面的规则为例，当使用"test-header的值为非数字 的字母abc或符号*时，其均会按数字0的效果来匹配，0小于5，所以会命中规则，请求被阻止。
