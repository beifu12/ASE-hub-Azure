Update

Lihaitao

2024/02/22

近期可能会有客户收到如下通知，并咨询基本SKU的公共IP地址退役的问题

微软公网也有说明：

https://azure.microsoft.com/en-au/updates/upgrade-to-standard-sku-public-ip-addresses-in-azure-by-30-september-2025-basic-sku-will-be-retired/

根据与后线团队的进一步沟通，小结如下供大家参考：

a. 在2025年09/30之后， basic 类型公网IP退役后， 用户将不能再使用具有基本IP地址的资源。 例如负载均衡等（Azure Cloud Services除外）

b. 在2025年09/30到期之后， 用户将不能再将basic IP升级到标准类型，即升级需要在此之前完成

c. 如果在2025年09/30到期之后，没有没有升级到标准类型， 那些持有基本IP的资源将无法正常工作， 平台也不能强制将其升级到标准类型

d. 在2025年09/30 基本IP退役后，平台将不再对基本IP提供支持

进一步了解到：

31 March 2025之前 可以创建，可以使用

31 March 2025 到  30 September 2025 不能创建Basic SKU，但是可以使用已有的

30 September 2025 之后，不能使用，不提供支持。

客户可能会问到的一些问题：

1. 在2025年以后，azure的basic sku IP是否可以继续使用以及是否会受到影响 ？

现在~2025年3月31日：用户可以创建新的Basic SKU Public IP，且可以使用；

2025年3月31日~2025年9月30日：用户不能创建新的Basic SKU Public IP，但是可以使用之前创建的；

2025年9月30日开始：用户既不能创建也不能使用Basic SKU Public IP；

2. 在2025年以后，basic sku ip是否还会提供支持？

2025年9月30日后，没有对Basic SKU Public IP的支持计划；

3. 不升级的话，会有什么影响；

不升级的话，2025年9月30日之后相关服务将不可用（Azure Cloud Services除外：If you have any Basic SKU public IP addresses deployed in Azure Cloud Services (extended support), those deployments will not be affected by this retirement and you don't need to take any action for them.）

4. Vpngw，appgw等服务，无法关机或者取消公网IP的关联关系，如何升级到标准SKU？

需要在2025年9月30日之前重建VPN，将APPGW升级到V2，具体请参考：Upgrading a basic public IP address to standard SKU - Guidance | Microsoft Learn

5.AGWv1什么时候能够支持非basic的SKU？

AGW1不会支持非basic的SKU，需要用户将APPGW V1升级到V2，文档也已经更新：Upgrading a basic public IP address to standard SKU - Guidance | Microsoft Learn；

6.非basic是standard吗？

是的；

7.如果basic要改非basic，怎么保留原有IP地址？特别是AGW和VPNGW

目前是不能保留原有IP地址，要重建新的IP地址；
