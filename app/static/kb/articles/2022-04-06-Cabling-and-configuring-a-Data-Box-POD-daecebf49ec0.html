原始内容清洗稿（保留备查）

The steps for cabling and basic configuration of a Data Box device are:

Connect power and network cables

Use an RJ45 cable to connect the MGMT port on the Data Box directly to a PC or laptop

Power on the device

Configure the Ethernet adapter on the PC or laptop with a static IP of 192.168.100.5 and subnet mask 255.255.255.0

Open a web browser on the PC or laptop and visit https://192.168.100.10 to access the Data Box device's web UI

Sign into the web UI using a password obtained from the Data Box order details in the Azure portal

In the web UI, configure the DATA1, DATA2, and DATA3 network interfaces as needed to enable access to the network shares on the device

For more information, see Cable and connect to your Azure Data Box.
