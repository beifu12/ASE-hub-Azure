1，参考文档：https://docs.azure.cn/zh-cn/aks/csi-secrets-store-identity-access 部署AKS群集及创建托管标识，并为托管标识分配相应的权限；

{

"aadProfile": null,

"addonProfiles": {

"azureKeyvaultSecretsProvider": {

"config": {

"enableSecretRotation": "false",

"rotationPollInterval": "2m"

},

"enabled": true,

"identity": {

"clientId": "f9fc47e4-8727-4ee9-9f74-9a09f6d3e8e3",

"objectId": "98cfa76e-c889-4484-85be-7169287bac91",

"resourceId": "/subscriptions/5e3124ff-22ad-4638-9c1c-645aa97017d1/resourcegroups/MC_myResourceGroup_myAKSCluster_chinaeast2/providers/Microsoft.ManagedIdentity/userAssignedIdentities/azurekeyvaultsecretsprovider-myakscluster"

}

2，参考文档：https://docs.azure.cn/zh-cn/aks/csi-secrets-store-identity-access 安装启用适用于机密存储的CSI驱动程序的Azure秘钥保管库提供程序安装，

同时启用自动轮换，需要注意默认的轮换间隔为2分钟；

az aks addon update -g myResourceGroup -n myAKSCluster2 -a azure-keyvault-secrets-provider --enable-secret-rotation

或自定义设置轮换间隔：

az aks addon update -g myResourceGroup -n myAKSCluster2 -a azure-keyvault-secrets-provider --enable-secret-rotation --rotation-poll-interval 5m

3，创建secretproviderclass和测试pod：

secretproviderclass.txt

++++++++++++++++++++++++++++

This is a SecretProviderClass example using user-assigned identity to access your key vault

apiVersion: secrets-store.csi.x-k8s.io/v1

kind: SecretProviderClass

metadata:

name: azure-sync

spec:

provider: azure

parameters:

usePodIdentity: "false"

useVMManagedIdentity: "true" # Set to true for using managed identity

userAssignedIdentityID: f9fc47e4-8727-4ee9-9f74-9a09f6d3e8e3 # Set the clientID of the user-assigned managed identity to use

keyvaultName: leoeast2keyvault # Set to the name of your key vault

cloudName: "AzureChinaCloud" # [OPTIONAL for Azure] if not provided, azure environment will default to AzurePublicCloud

objects: |

array:

  • |

objectName: secret2

objectType: secret # object types: secret, key, or cert

objectVersion: "" # [OPTIONAL] object versions, default to latest if empty

objectName: key1

objectType: key

objectVersion: ""

tenantId: b388b808-0ec9-4a09-a414-a7cbbd8b7e9b # The tenant ID of the key vault

secretObjects: # [OPTIONAL] SecretObjects defines the desired state of synced Kubernetes secret objects

  • data:
  • key: username # data field to populate

objectName: secret2 # name of the mounted content to sync; this could be the object name or the object alias

secretName: foosecret # name of the Kubernetes secret object

type: Opaque
