实现透传的思路和以前一样，就是在Point和Site2这两端分别增加去往对端的路由。

如下两种方式和之前镇山分享的一种方式中，Site2一端的配置方法都是一样的。

区别在于Point端的配置：

之前Point端的配置方式是：在Point上加静态路由route add x.x.x.x MASK x.x.x.x x.x.x.x，每次拨号后需要手动加一次（我测了下加永久路由的方式，但是不生效，很纳闷）。

如下方式一：每台拨号的Point都要改配置文件，但不需要每次拨号都改。

如下方式二：Point端无需额外操作，只需安装VPN Client和客户端证书。（对于用户而言，大多不了解路由啊这些乱七八糟的东西，推荐这种方式）

如下配置步骤，供参考：

一、组网：

Local PCs-----[P2S VPN]------Vnet03-------[S2S VPN]-----Vnet02

10.33.0.0/16                                          10.10.0.0/16

(P2S address pool:192.168.123.0/24)

二、需求：

在以上P2S和S2S VPN基础上，实现Local PC和VNet02之间互通

三、可以用如下两种配置方式，推荐使用方式二

方式一：

基于P2S和S2S VPN基础上，再增加如下两个配置：

1、在路径C:\Users\yao.yuejian\AppData\Roaming\Microsoft\Network\Connections\Cm\101cd3bb-cdd1-47d7-9c4d-ae125e3a9cb2\routes.txt下增加如下第三行标红路由：

ADD 10.33.0.0 MASK 255.255.0.0 default METRIC default IF default

ADD 192.168.123.0 MASK 255.255.255.0 default METRIC default IF default （默认有以上两条路由）

ADD 10.10.0.0 MASK 255.255.0.0 default METRIC default IF default （PS：如果P2S在此修改前已经连接，修改配置后再重新连接以调用新配置）

（这个步骤，每一台Local PC都要去配置一次）

2、Vnet02连接的本地网络网关中增加地址空间（P2S的address pool）
