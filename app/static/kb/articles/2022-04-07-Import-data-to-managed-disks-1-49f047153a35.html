原始内容清洗稿（保留备查）

If you specified managed disks as one of the storage destinations during order creation, you need to take into consideration the following:

You can only have one managed disk with a given name in a resource group across all the precreated folders and across all the Data Box Disk.

Always copy the VHDs to one of the precreated folders.

Only the fixed VHDs can be uploaded to create managed disks. Dynamic VHDs, differencing VHDs or VHDX files are not supported.

If you don't have long paths enabled on the client, and any path and file name in your data copy exceeds 256 characters, the Data Box Split Copy Tool (DataBoxDiskSplitCopy.exe) or the Data Box Disk Validation tool (DataBoxDiskValidation.cmd) will report failures.

Split Copy tool is not supported with managed disks.

For detailed and updated information of this product, refer to: Copy Data to disks
