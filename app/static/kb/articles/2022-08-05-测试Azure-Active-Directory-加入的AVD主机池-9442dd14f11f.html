2021-10-19

目前中国区的portal界面中已经可以使用加入Azure Active Directory 功能，而不需要部署ADDS，或这使用AADDS了。

参考文档将主机池中主机加入AAD：https://docs.microsoft.com/zh-cn/azure/virtual-desktop/deploy-azure-ad-joined-vm

设置好后需要如下2个额外步骤：

一、为用户分配对主机池的VM 配置角色分配

分配Virtual Machine User Login 角色让他们可以登录到 VM.

为需要本地管理权限的管理员分配Virtual Machine Administrator Login 角色.

二、默认需要使用 Windows 桌面客户端连接，本地环境需满足：

本地电脑 Azure AD 会话主机联接到同一个 Azure AD 租户

本地电脑 Azure AD 与会话主机混合联接到同一个 Azure AD 租户

本地电脑在 Windows 10（2004 及更高版本）上运行，Azure AD 注册到与会话主机相同的 Azure AD 租户

若要从未联接至 Azure AD 的 Windows 设备或其他客户端连接进行访问，请将 targetisaadjoined:i:1 作为自定义 RDP 属性添加到主机池中。（该属性修改可能需要等待几分钟生效。）

这个功能之前测试会出现主机池主机不可用的状态，目前已经正常：

如果仍有以上问题，可以通过虚拟机的运行命令添加如下注册表项，重启虚拟机。

New-Item -Path HKLM:\SOFTWARE\Microsoft\RDInfraAgent\AADJPrivate
