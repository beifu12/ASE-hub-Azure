问题：

客户希望在Azure China的AAD中创建一个自定义角色，并赋予该角色microsoft.directory/servicePrincipals/managePermissionGrantsForAll.microsoft-all-application-permissions权限，但是在Azure China AAD中操作时，在权限列表中却无法找到该项。但是我们可以看到AAD默认的Application administrator 组中包含了该权限。

解决方法：

根据客户提供的信息，以下权限属于应用同意权限，目前，管理门户尚不支持列出并添加到自定义角色中，需要使用Azure AD PowerShell来创建。

microsoft.directory/servicePrincipals/managePermissionGrantsForAll.microsoft-application-admin

参考文档和截图：

https://docs.azure.cn/zh-cn/active-directory/roles/custom-consent-permissions#app-consent-permissions

https://docs.azure.cn/zh-cn/active-directory/roles/custom-create#create-a-role-using-powershell

根据文档的先决条件，需要安装以下模块。

https://docs.azure.cn/zh-cn/active-directory/roles/prerequisites#azureadpreview-module

我这里测试是可以成功创建的。

参考脚本：

Connect-AzureAD -AzureEnvironmentName AzureChinaCloud

Basic role information

$displayName = "Application Consent"

$description = "Application Consent"

$templateId = (New-Guid).Guid

Set of permissions to grant

$allowedResourceAction =

@(

"microsoft.directory/servicePrincipals/managePermissionGrantsForAll.microsoft-application-admin"

)

$rolePermissions = @{'allowedResourceActions'= $allowedResourceAction}

Create new custom admin role

$customAdmin = New-AzureADMSRoleDefinition -RolePermissions $rolePermissions -DisplayName $displayName -Description $description -TemplateId $templateId -IsEnabled $true
