问题现象 / 场景

  • The SMB shares on a Data Box device have a naming convention based on the storage account(s) that data is being imported to or exported from and the type of data being imported or exported. The syntax for the UNC path to each share is shown below.

背景信息

  • The SMB shares on a Data Box device have a naming convention based on the storage account(s) that data is being imported to or exported from and the type of data being imported or exported. The syntax for the UNC path to each share is shown below.
  • Azure Block blob - \\<device IP address>\<storage account name>_BlockBlob
  • Azure Page blob - \\<device IP address>\<storage account name>\_PageBlob
  • Azure Files - \\<device IP address>\<storage account name>_AzFile
  • Azure Block blob (Archive) - \\<device IP address>\<storage account name>_BlockBlobArchive
  • If a Data Box device is being used to import to managed disks, the device will have additional shares with a naming convention based on the resource group selected during the ordering process and the type of managed disk that will be created upon data import. The syntax for these share names is shown below.
  • Premium SSD - \\<DeviceIPAddress>\<ResourceGroupName_MDisk>\PremiumSSD
  • Standard HDD - \\<DeviceIPAddress>\<ResourceGroupName_MDisk>\StandardHDD
  • Standard SSD - \\<DeviceIPAddress>\<ResourceGroupName_MDisk>\StandardSSD
  • For more information regarding SMB shares on the Data Box device, please see the links below.

操作步骤 / 命令

  • To connect to an SMB share on the Data Box device, the customer must first access the device web UI, visit the Connect and Copy page, and select "SMB" to obtain the username and password needed to connect to the shares. The customer can then use the "net use" command on the Windows command line, the "new-psdrive" command in PowerShell, or the "Map network drive" UI in Windows to connect from their Windows client to the desired shares. If the customer has a Linux client rather than Windows, they can use the command "sudo mount" with the appropriate syntax to mount the Data Box shares. The customer can then use a copy tool such as robocopy or rsync to copy data to or from the Data Box shares.
