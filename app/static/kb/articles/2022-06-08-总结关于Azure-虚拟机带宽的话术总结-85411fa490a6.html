  • 1，Azure 上虚拟机的带宽指标是哪个？
  • 2，Azure 的虚拟机有独立带宽吗？
  • 由于虚拟机托管在共享硬件上，因此网络容量必须在共享同一硬件的虚拟机中公平地共享。 在分配时，较大的虚拟机相对于较小的虚拟机会获得相对较多的带宽。
  • 3，Azure 的虚拟机的带宽该如何计算或者评估？
  • 分配给每个虚拟机的网络带宽按虚拟机的传出（出站）流量计算。 从虚拟机流出的所有网络流量均计入分配限制，不管流向哪个目标。 例如，如果虚拟机的限制为 1,000 Mbps，则不管出站流量的目标是同一虚拟网络中的另一虚拟机，还是 Azure 外部，均适用该限制。
  • 传入流量不直接计算，或者说不直接受到限制。 但是，其他因素（例如 CPU 和存储限制）可能会影响虚拟机处理传入数据的能力。
  • 4， Azure的虚拟机的网卡越多，带宽越大吗？
  • 分配的带宽是针对每个虚拟机的，不管为该虚拟机连接了多少网络接口。吞吐量限制适用于虚拟机。 吞吐量不受以下因素影响：
  • 网络接口数：带宽限制是源自虚拟机的所有出站流量的累积。
  • 加速网络：尽管此功能有助于流量达到已发布的限制，但不会更改限制。
  • 流量目标：所有目标都计入出站限制。
  • 协议：基于所有协议的所有出站流量都计入限制。

解决方案

  • 实际的网络性能将取决于多种因素，包括网络拥塞、应用程序负载和网络设置。 除了带宽，VM 上任意给定时间存在的网络连接数目也可能影响其网络性能。 连接建立速度和终止速度也可能影响网络性能，因为连接的建立和终止与包处理例程共享 CPU。

1，Azure 上虚拟机的带宽指标是哪个？

Azure 提供各种 VM 大小和类型，每一种包含的性能各不相同。 其中一种是网络吞吐量（也称带宽），以兆位/秒 (Mbps) 表示。 若要详细了解每种 VM 大小支持的预期出站吞吐量和网络接口数，请查看 Azure Windows 和 Linux VM 大小。每个系统都有一个表，在最后一列，名为“最大 NIC 数/预期网络性能(Mbps)”。预期的网络带宽 是指跨所有 NIC 为每个 VM 类型分配的最大聚合带宽，适用于所有目标。 有关详细信息，请参阅虚拟机网络带宽。无法保证上限。 限值用于在为目标应用程序选择适当的 VM 类型时提供指导。

2，Azure 的虚拟机有独立带宽吗？

由于虚拟机托管在共享硬件上，因此网络容量必须在共享同一硬件的虚拟机中公平地共享。 在分配时，较大的虚拟机相对于较小的虚拟机会获得相对较多的带宽。

3，Azure 的虚拟机的带宽该如何计算或者评估？

分配给每个虚拟机的网络带宽按虚拟机的传出（出站）流量计算。 从虚拟机流出的所有网络流量均计入分配限制，不管流向哪个目标。 例如，如果虚拟机的限制为 1,000 Mbps，则不管出站流量的目标是同一虚拟网络中的另一虚拟机，还是 Azure 外部，均适用该限制。

传入流量不直接计算，或者说不直接受到限制。 但是，其他因素（例如 CPU 和存储限制）可能会影响虚拟机处理传入数据的能力。

4， Azure的虚拟机的网卡越多，带宽越大吗？

分配的带宽是针对每个虚拟机的，不管为该虚拟机连接了多少网络接口。吞吐量限制适用于虚拟机。 吞吐量不受以下因素影响：

网络接口数：带宽限制是源自虚拟机的所有出站流量的累积。

加速网络：尽管此功能有助于流量达到已发布的限制，但不会更改限制。

流量目标：所有目标都计入出站限制。

协议：基于所有协议的所有出站流量都计入限制。

5， Azure官网为每个虚拟机提供网络带宽参考值吗？

若要详细了解每种 VM 大小支持的预期出站吞吐量和网络接口数，请查看 Azure Windows 和 Linux VM 大小。 选择一个类型（例如“通用”），然后在生成的页面上选择一个大小系列（例如“Dv2 系列”）。 每个系统都有一个表，在最后一列（名为“最大 NIC 数/预期网络性能(Mbps)”）中包含网络规格。

6, Azure 虚拟机的网络性能的影响因素有哪些？

实际的网络性能将取决于多种因素，包括网络拥塞、应用程序负载和网络设置。 除了带宽，VM 上任意给定时间存在的网络连接数目也可能影响其网络性能。 连接建立速度和终止速度也可能影响网络性能，因为连接的建立和终止与包处理例程共享 CPU。

7，Azure 官网有提供虚拟机上传下载速率的保证参考值吗？

没有，由于上传下载速率的影响因素包括azure 虚拟机自身的网络性能也包括公网传输和本地网络环境的因素影响，不同用户的环境也不同，因此这个上传下载速率以用户实际环境测试为准。

8， Azure 平台是否提供有监控指标用于查看网络流数

Azure Monitor 中提供的指标用于跟踪 VM 或 VMSS 实例上的网络流数和流创建速率。
