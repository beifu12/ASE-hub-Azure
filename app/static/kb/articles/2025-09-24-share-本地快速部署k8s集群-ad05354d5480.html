原始内容清洗稿（保留备查）

Azure 可以通过ARC 纳管 本地的k8s 集群进行管理，让本地的k8s 集群享有部分aks 集群的功能。

这里提供一个快速部署本地k8s 的方式，供大家参考。

环境： ubuntu22.04

1 部署docker :

参考文档 Ubuntu | Docker Docs

1.1最简单的方式是在如下连接进行必要的docker 组件包安装， 可以下载这一套组件包

Index of linux/ubuntu/dists/jammy/pool/stable/amd64/

containerd.io_1.6.21-1_<arch>.deb

docker-ce_5:24.0.7-1~ubuntu.22.04~<arch>.deb

docker-ce-cli_5:24.0.7-1~ubuntu.22.04~<arch>.deb

docker-buildx-plugin_0.11.2-1~ubuntu.22.04~<arch>.deb

docker-compose-plugin_2.21.0-1~ubuntu.22.04~<arch>.deb

1.2 上传，解压

在/home/hana/docker-debs 下执行 sudo dpkg -i *.deb

1.3 启动docker 服务：

sudo systemctl start docker

sudo systemctl enable docker

2 部署minikube

参考文档： minikube start | minikube

2.1 下载minikube 包

curl -LO https://storage.googleapis.com/minikube/releases/latest/minikube_latest_amd64.deb

sudo dpkg -i minikube_latest_amd64.deb

2.2 启动minikube 时 会拉取对应镜像，因为网络原因原因，需要调整镜像库地址：

minikube start --driver=docker --base-image="registry.cn-hangzhou.aliyuncs.com/google_containers/kicbase:v0.0.40" --image-mirror-country='cn' --image-repository='registry.cn-hangzhou.aliyuncs.com/google_containers' --force

2.3 安装kubectl

此处不做赘述 ，参考文档即可

Install and Set Up kubectl on Linux | Kubernetes

2.4 kindnet 是一个网络控件， 需要修改 daemonet kindnet 的镜像地址，否则会拉取不到。

修改 daemonet kindnet 命令

kubectl edit daemonset kindnet -n kube-system

image: swr.cn-north-4.myhuaweicloud.com/ddn-k8s/docker.io/kindest/kindnetd:v20241108-5c6d2daf
