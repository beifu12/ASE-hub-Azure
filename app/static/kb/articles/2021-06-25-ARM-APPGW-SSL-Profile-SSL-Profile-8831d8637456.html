APPGW SSL Profile：

这个就是client authentication , 验证客户端证书， It is front-end only,  和后端没有关系。 当设置这个的时候，  AppGw will always ask for client certificate from connecting users, validate that the certificate is trusted in its trusted client root cert list and is not part of revoked cert list. If these validation pass, it allows the connection to be established.

上传的客户端证书上传到trusted client root cert list里， 不在同一个trust store里， 所以不能用于后端。现在是public preview的阶段， 中国还不能用。
