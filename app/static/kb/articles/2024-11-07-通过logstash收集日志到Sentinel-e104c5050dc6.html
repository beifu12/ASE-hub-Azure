遇到客户使用Logstash在sentinel未收集到日志的单子，因为文档相关配置内容提及比较少，正好测试了一下供大家以后参考。

1，安装logstash： https://www.elastic.co/guide/en/logstash/current/installing-logstash.html

sudo rpm --import https://artifacts.elastic.co/GPG-KEY-elasticsearch

添加如下内容到/etc/yum.repos.d/目录里的repo中，新建一个文件logstash.repo

[logstash-8.x]

name=Elastic repository for 8.x packages

baseurl=https://artifacts.elastic.co/packages/8.x/yum

gpgcheck=1

gpgkey=https://artifacts.elastic.co/GPG-KEY-elasticsearch

enabled=1

autorefresh=1

type=rpm-md

安装命令：

sudo yum install logstash

2，默认安装最新版本8.8。根据官网描述，需要禁用ECS。

[root@centos8 logstash]# vim /etc/logstash/logstash.yml

3，启动logstash服务：sudo systemctl start logstash.service

4，可以看到logstash主要涉及以下两个目录：

5，需要预先安装对应插件。

[root@centos8 bin]# /usr/share/logstash/bin/logstash-plugin list ##查看支持的所有插件

[root@centos8 bin]#/usr/share/logstash/bin/logstash-plugin install logstash-input-file ##安装input-file插件，当然可以根据需求安装其他input插件

[root@centos8 bin]#/usr/share/logstash/bin/logstash-plugin install microsoft-logstash-output-azure-loganalytics ##安装output插件

6， 编辑一个文件内容方便测试

[root@centos8 logstash]# vim /tmp/access_log

7，编写pipeline 配置文件：vim /etc/logstash/conf.d/logstashfile.conf

input {

file {

path => "/tmp/access_log" ##将此路径文件内容发送到sentinel

start_position => "beginning"

}

filter {

output {

microsoft-logstash-output-azure-loganalytics {

workspace_id => "4f95cfe5-d8c0-4571-b358-d6ae3b1795f4" # <your workspace id>

workspace_key => "JaUKzp41A22QcxxJWrxN5n5zxMqaQ32SKik/yGmj9OqlP9iybKsxSpN6fXyPVu+2qA4xkk4IRojRHhHSK70USDXA==" # <your workspace key>

custom_log_table_name => "apachefile" ##sentinel中自定义表名称

endpoint => "ods.opinsights.azure.cn" ##中国区终结点，如果不写默认是到global进行认证

8，执行pipeline 配置文件：

[root@centos8 logstash]# /usr/share/logstash/bin/logstash -f /etc/logstash/conf.d/logstashfile.conf

首次生成表大概需要小半天的时间，后面新的日志几乎会实时传递到表中。

可以到/var/log/logstash查看日志文件。
