首先需要安装如下工具：

安装git 或gitbash工具

安装helm（参考https://docs.azure.cnzh-cn/aks/kubernetes-helm）

如下是安装过程（操作环境为Windows，如在Linux下请您根据系统的命令规范进行调整）：

首先下载git 源中的helm charts

git clone https://github.com/helm/charts.git

1、安装Prometheus

执行helm命令进行安装（注如下helm使用了ssl验证，如果没有配置可去掉命令中—tls以及后面的部分，证书为安装helm时使用的证书。）

helm install --name=prometheus .\charts\stable\prometheus\ --namespace monitoring --set rbac.create=true --tls --tls-ca-cert ca.cert.pem --tls-cert helm.cert.pem --tls-key helm.key.pem

按照最后提示的命令可设置prometheus所需要的端口转发进行本地访问测试：

Pod名重启Node可能会发生改变

获取Pod名称：kubectl get pods --namespace monitoring -l "app=prometheus,component=server" -o jsonpath="{.items[0].metadata.name}

（从 Kubernetes v1.10 开始，kubectl port-forward 允许使用资源名称（例如服务名称）来选择匹配的 pod 来进行端口转发。）监听本地客户端的端口9090并转发进出到deployment/prometheus-server 选择的pod的9090端口。可用于测试。

kubectl --namespace monitoring port-forward deployment/prometheus-server 9090

2、安装 Grafana

helm install --name=grafana .\charts\stable\grafana\ --set persistence.enabled=true --set persistence.accessModes={ReadWriteOnce} --set persistence.size=8Gi --namespace monitoring --tls --tls-ca-cert ca.cert.pem --tls-cert helm.cert.pem --tls-key helm.key.pem

为了保留监控数据需要使用 如下参数：

persistence.enabled=true

persistence.accessModes={ReadWriteOnce}

persistence.size=8Gi

来创建持久卷。

根据最后的提示做相应的转发设置并找到登录密码

同样找到要做端口转发的pod来进行访问测试

kubectl get pods --namespace monitoring -l "app=grafana,release=grafana" -o jsonpath="{.items[0].metadata.name}"

仍然使用deployment选择的pod做转发设置，当然直接选择pod也可以。

kubectl --namespace monitoring port-forward deployment/grafana 3000

转发后可以通过本机localhost访问这个deployments的端口进行测试了：
