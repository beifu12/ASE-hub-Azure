通过PowerShell 查询表可以参考：

https://docs.azure.cn/zh-cn/storage/tables/table-storage-how-to-use-powershell#query-the-table-entities

使用Get-AzTableRow 命令这需要您安装相应的模块

Install-Module -Name AzTable

获取表中数据可以使用：

$resourceGroup = "zhangwx"

$storageAccountName = "zhangsa"

$storageAccount = Get-AzStorageAccount -ResourceGroupName $resourceGroup -Name $storageAccountName

$ctx = $storageAccount.Context

#查看表名 $storageTable = Get-AzStorageTable –Name $tableName –Context $ctx

Get-AzStorageTable –Context $ctx | select Name

$tableName = "WADMetricsPT1HP10DV2S20181022"

$cloudTable = (Get-AzStorageTable –§CName $tableName –§CContext $ctx).CloudTable

Get-AzTableRow -table $cloudTable -ColumnName "CounterName" -value "\Memory\PercentUsedMemory" -Operator Equal | ft

以上命令获取表中CounterName值为\Memory\PercentUsedMemory的数据：
