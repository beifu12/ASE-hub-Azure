Hi All:

当前顾问à所有建议导出的CSV 文件资源名称显示的不是具体的资源名称，而是一长串莫名字符串的问题，这个问题是一个平台问题，Zhenjiang 8 月已经升级了ICM (521461984)，但是目前还没有ETA。

#顾问中安全建议部分导出的CSV#

我发现从顾问à所有建议导出的CSV文件中对应的ID在被评估资源ID后面被加上了额外的providers/Microsoft.Security/assessments/xxxxxxx，作为workaround，可以在Azure Resource Graph 浏览器中运行如下的示例查询，将providers/Microsoft.Security之前的部分作为资源ID拿出来，再根据/进行拆分，然后使用拆分后资源ID的最后一部分作为资源名称来显示，最后可以将查询结果以csv格式进行导出。

#示例查询#

Advisorresources

| where subscriptionId == "1447ccf1-xxxx-xxxx-xxxx-2f370d142fa6"

//| where properties.category == "Security"

| extend ResourceID = tostring(split(id,'/providers/Microsoft.Security')[0])

| extend SplitedResourceID = split(ResourceID,'/')

| extend Resource = SplitedResourceID[array_length(SplitedResourceID) - 1]

| extend Impactlevel = properties.impact

| extend Advise = properties.shortDescription.solution

| extend LastUpdatedDate = properties.lastUpdated

| extend ImpactedField = properties.impactedField

| project Impactlevel, Advise, subscriptionId, ImpactedField, resourceGroup, Resource, LastUpdatedDate

注：如果希望查看所有订阅的情况，可以把第二行（| where subscriptionId == "1447ccf1-xxxx-xxxx-xxxx-2f370d142fa6"）删除。
