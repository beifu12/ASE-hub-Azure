后台查看 在问题时间 : 平台启动了Upgrade node image version的操作, 群集会自动更新节点OS镜像，并且对新 VHD 的更新是中断性的。

关于node image的描述:

查看Node OSUpgrade配置是否为NodeImage

通过命令查看:

az aks show --resource-group myResourceGroup --name myAKSCluster --query "autoUpgradeProfile"

通过工具ASI: Search for resources 查看:

可以在events中查看到详细信息: channel : 4 代表 node image

如何调整NodeImage策略

参考文档: 自动升级 Azure Kubernetes 服务 (AKS) 节点 OS 映像 - Azure Kubernetes Service | Azure Docs

使用命令:

az aks update --resource-group myResourceGroup --name myAKSCluster --node-os-upgrade-channel None

将节点OS升级渠道更改为None.

调整策略之后就不会出现node image “AKS 将使用新修补的 VHD 来更新节点，其中包含每周一次的安全修复和 bug 修复。 在维护时段和激增设置之后，对新 VHD 的更新是中断性的。 “的情况.

注意事项

1, 如果设置了集群的upgradechannel , 请先将集群自动升级改为None 再调整Node OSUpgrade , 否则会出现报错.

2, Node OSUpgradechannel参数是az cli版本2.52开始新添加的参数，低版本不会显示, 如果cli版本过低请先升级:

使用--node-os-upgrade-channel 参数需要az cli 2.52版本及以上.
