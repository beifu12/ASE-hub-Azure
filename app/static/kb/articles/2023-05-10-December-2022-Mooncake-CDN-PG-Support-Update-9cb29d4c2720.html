问题现象 / 场景

  • How to identify the problem: customer reporting missing telemetry reflecting their global CDN usage. This issue is limited to customers using global acceleration with mooncake CDN. All other services are working as expected.
  • Cache header setting behavior with Baidu – Provider Baidu has an unique behavior where it weighs cache rules over cache-header: private or no cache. Meaning, if a customer is on Baidu with cache rules, the default behavior is to respect cache rules for caching even though cache header is set to no-cache. Please engage PG if you encounter a customer on Baidu and has issues with cache header behaviors, work arounds will need to be addressed case by case.
