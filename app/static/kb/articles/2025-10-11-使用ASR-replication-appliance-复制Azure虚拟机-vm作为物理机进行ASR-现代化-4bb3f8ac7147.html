拷贝代理安装包到需要复制的主机解压安装包：

.\Microsoft-ASR_UA*Windows*release.exe /q /x:"C:\ASR"

进入到安装包

cd "C:\ASR"

使用如下命令安装：

.\UnifiedAgentInstaller.exe /Platform vmware /Silent /Role MS /CSType CSPrime /InstallLocation "C:\Program Files (x86)\Microsoft Azure Site Recovery"

注：以上操作需要注意操作顺序和目录

安装后拷贝token到appliance生成config 文件

生成后回来进行注册

首先修改IsAzureStackHubVM=1 windows - _C:\Program Files (x86)\Microsoft Azure Site Recovery\agent\Application Data\etc\drscout.conf（ linux - _/usr/local/ASR/Vx/etc/drscout.conf），正常情况下安装后如下只为0，需要修改为1。

运行C:\Program Files (x86)\Microsoft Azure Site Recovery\agent\UnifiedAgentConfigurator.exe进行注册（不需要提前在appliance中添加，对于物理机，选择credential-less），进行注册
