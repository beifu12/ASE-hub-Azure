Overview#

On 24th August 2020, Docker announced that they would begin rate limiting container pull requests from Docker Hub for anonymous and free authenticated users. To give Azure customers time to adjust to this change, Microsoft initiated a partner agreement with Docker not to throttle requests from IP addresses that originate from Azure. This agreement will end on June 30, 2022.

On 19th January 2022,  we/AKS team have sent out a reminder email to all customers.

And the notifications Mooncake customers have received:

Notification from Docker(Opensource):

https://www.docker.com/increase-rate-limits

Customers /Scenarios  will be effected#

If customers are pulling images from Docker Hub anonymously, or using a free account, they may be impacted. When using a free account, image pulls will be rate-limited by IP

If your environments on Azure have dependencies on images from Docker Hub, you may be affected. For example, if you:

• Run nginx or any other image without a registry URL (for example, nginx:1).

• Build container images that pull directly from Docker Hub (for example, FROM alpine).

• Use Helm to install charts that pull images from Docker Hub.

Solutions#

If a customer is being affected by throttling on image pulls, there are multiple possible solutions the customer can use depending on their use-case.

If the customer is pulling anonymously, they can sign up for a Docker account and begin authenticating their image pulls.  This should be relatively easy and free.

If they are still getting throttled after authenticating their image pulls, they have a few paid options.

They can sign up for a paid Docker account. This will greatly increase their rate-limit starting at $5/month. Docker Pricing

They can import the public images into an Azure Container Registry, and pull the images from there. This would be the best option for customers already using ACR. Import Images into an ACR.

They can also run their own image registry. This would have the highest operational burden, and would be out of the scope of Azure Support. We should only suggest this solution if the customer is very set against anything with a fee. Deploy a registry server
