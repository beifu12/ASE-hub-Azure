排查思路

  • 但是对centos 7.5. 在运行预配步骤中  yum groupinstall -y "GNOME Desktop" 可能会遇到报错 “file /boot/efi/EFI/centos from install of fwupdate-efi-12-5.el7.centos.x86_64 conflicts with file from package grub2-common-1:2.02-0.65.el7.centos.2.noarch ， 可以先运行yum upgrade -y （只升级所有包，不升级软件和系统内核），然后再运行yum groupinstall -y "GNOME Desktop"

操作步骤 / 命令

  • 第三步 编辑 /etc/systemd/system/vncserver@:1.service 对应的命令行中多了一个”\ “, 命令应该为 vim /etc/systemd/system/vncserver@:1.service
  • 第五步：启动服务以及开机启动命令中也同样多了一个”\”, 命令应该是 systemctl start vncserver@:1.service 以及  systemctl enable vncserver@:1.service
