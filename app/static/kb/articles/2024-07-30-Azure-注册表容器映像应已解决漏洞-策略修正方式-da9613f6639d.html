Update

WangZhaoqing

Case number： 20240716304819

问题背景：

“Azure 注册表容器映像应已解决漏洞”策略会检查ACR中的所有镜像，列出应该进行修正的补丁。建议修正步骤是让客户上传已经修正的镜像，删除问题镜像。

如果用户仅在acr中通过ACR中镜像库内镜像右侧的删除按钮将被扫描出的镜像删除，但是defender的策略依然会扫描出被删除的镜像，并且tags为NA

问题原因：

如果只是在存储库中将镜像删除其实并未真正清除所有的镜像，因为defender的策略扫描的是存储库Manifest中的所有信息，如用户的存储库中可以看到镜像有4个，但是Manifest中标注有10个镜像。

解决方案：

因为在页面上无法看到存储库Manifest中的全部镜像信息，所以需要使用cli命令进行查询和清理。

运行如下命令：

az cloud set -n AzureChinaCloud

az login

az account set -s 订阅ID

查看清单信息：

az acr manifest | Microsoft Learn

示例命令：az acr manifest list test123.azurecr.cn/hello-world1

是可以找到defender中扫描到的镜像digest的

看到有问题的映像是不包含Tags信息的。因为包含tags的镜像页面上是可以看到的，也可已通过页面操作删除。

对于没有tags的镜像可以通过命令进行删除。

相关问题文档：删除映像资源 - Azure Container Registry | Azure Docs
