通过portal 创建AKS时 选择启用虚拟节点池后报错：

测试了北2 东2 北3都报 如下报错：

{

"code": "DeploymentFailed",

"message": "At least one resource deployment operation failed. Please list deployment operations for details. Please see https://aka.ms/arm-deployment-operations for usage details.",

"details": [

"code": "VirtualNetworkServiceEndpointsNotSupported",

"message": "Virtual networks in chinanorth3 location do not support ServiceEndpoints for Microsoft.ContainerRegistry service."

}

]

通过查找文档通过az cli命令创建虚拟节点池的方法可以启用节点池：

https://docs.azure.cn/zh-cn/aks/virtual-nodes-cli

实际测试时，文档中有一步需要添加ssh-keys，请参考如下标黄部分：

az group create --name myResourceGroup --location chinanorth3

az network vnet create --resource-group myResourceGroup --name myVnet --address-prefixes 10.0.0.0/8 --subnet-name myAKSSubnet --subnet-prefix 10.240.0.0/16

az network vnet subnet create --resource-group myResourceGroup --vnet-name myVnet --name myVirtualNodeSubnet --address-prefixes 10.241.0.0/16

az network vnet subnet show --resource-group myResourceGroup --vnet-name myVnet --name myAKSSubnet --query id -o tsv

az aks create --resource-group myResourceGroup --name myAKSCluster --node-count 3 --network-plugin azure --vnet-subnet-id  /subscriptions/05a7ed23-e9a5-467b-b371-7a9d9f6a504b/resourceGroups/myResourceGroup/providers/Microsoft.Network/virtualNetworks/myVnet/subnets/myAKSSubnet --generate-ssh-keys

az aks enable-addons \

--resource-group myResourceGroup \

--name myAKSCluster \

--addons virtual-node \

--subnet-name myVirtualNodeSubnet

命令执行成功后，查看aks虚拟节点池启用成功：
