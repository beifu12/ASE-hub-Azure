客户修改了vnet上面的DNS配置，并且网卡也是继承了vnet的DNS设置

客户表示部分VM重启之后DNS配置并不生效，仍然是之前的DNS配置：

这种情况通常是客户自己网卡手动配置了DNS导致的，普通的windows系统可以直接在网络设置里进行查看和调整：

但是对于windows core等无图形界面的系统就没有办法直接查看和配置了：

即使get了网卡设置也只能看到DNS服务器地址而不能判断是否是手动配置：

这种情况就需要从注册表中获取信息了，指令和结果如下：

Get-ItemProperty "HKLM:\SYSTEM\CurrentControlSet\Services\Tcpip\Parameters\Interfaces\*" |

Where-Object { $_.NameServer } |

ForEach-Object { $_.NameServer }

可以很明显的看到，如果客户手动在网卡上配置了DNS服务器地址就会返回结果，如果没有手动配置使用了自动获取的情况就不会有任何结果返回：

这种情况，可以让客户使用管理员账户跑以下指令来删除手动配置的DNS就没问题了：

Set-DnsClientServerAddress -InterfaceAlias "网卡名" -ResetServerAddresses
