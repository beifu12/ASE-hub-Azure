Hi Team,

根据Azure 文档在Portal中使用迁移工具，是可以实现将ER GW  Basic Public IP升级到Standard Public IP的，但从之前用户的反馈，他们在Global升级是失败的，原因：用户的ER GW部署类型是VMSS：The gateway deployment type is VMSS, which does not support the migration

当前可以确认的是ER GW的部署类型至少有 CSES （Cloud Service Extension S????）和VMSS，早期创建的ER GW，其部署类型会有CSES的。根据用户在Global遇到问题时微软产品组的反馈，VMSS部署类型的ER GW无法使用Portal中的工具进行迁移，且后台会为这部分用户迁移：

As mentioned, you don’t need to migrate this gateway, and no action is required at this time. Azure will migrate these gateways to Az aware from the backend after September 25, which will be transparent to you.

中国区ER GW Portal中的这个迁移工具到底能否实现将部署类型为CSES的Basic Public IP升级到Standard Public IP，目前还不得而知，已建议有关用户试试，可以肯定的是如果用户迁移时Target SKU选择了带AZ那肯定失败，因为AZ Virtual network Gateway在Non AZ region都还不支持。
