原始内容清洗稿（保留备查）

产品组已经修复了备份数据写入Log A的功能。

请您按下图配置vault，确认备份任务发生并等待8小时后，使用以下查询语句。

后续备份任务不需要等这么久，一般任务完成10分钟后就可以进行查询了。

AzureDiagnostics

| where Category == "CoreAzureBackup"

//Get all Backup Items

| where OperationName == "BackupItem"

//Get distinct Backup Items

| distinct  BackupItemUniqueId_s, BackupItemFriendlyName_s

| join kind=leftouter

(AzureDiagnostics

| where Category == "AddonAzureBackupStorage"

| where OperationName == "StorageAssociation"

//Get latest record for each Backup Item

| summarize arg_max(TimeGenerated, *) by BackupItemUniqueId_s

| extend StorageConsumedInGBs = todouble(StorageConsumedInMBs_s)/1024

| extend Date = format_datetime(TimeGenerated+8h, 'yyyy-MM-dd')

| project Date, BackupItemUniqueId_s, StorageConsumedInGBs)

on BackupItemUniqueId_s

| project Date, BackupItemUniqueId_s, BackupItemFriendlyName_s, StorageConsumedInGBs

| sort by StorageConsumedInGBs desc

| render timechart

查询结果如下，由于只有一天的数据，只生成了一个数据点。如果数据够多的话可以看到用量趋势图。
