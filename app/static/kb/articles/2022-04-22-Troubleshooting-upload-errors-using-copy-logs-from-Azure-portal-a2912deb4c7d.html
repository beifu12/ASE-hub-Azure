排查思路

  • A copy/error log and a verbose log are generated for each storage account. These logs are uploaded to the same storage account that was used to upload data. Also can be found on the order details.
  • The copy log reports events for all failed copy operations between the disk and the Azure Storage account. The copy log ends with a summary of errors by error category.
  • The verbose log has a listing of all copy operations that succeeded on every blob and file.

A copy/error log and a verbose log are generated for each storage account. These logs are uploaded to the same storage account that was used to upload data. Also can be found on the order details.

The copy log reports events for all failed copy operations between the disk and the Azure Storage account. The copy log ends with a summary of errors by error category.

The verbose log has a listing of all copy operations that succeeded on every blob and file.

This applies for export job as well, There's also a manifest file, which is saved to the disk.

Check documentation for the errors listed: https://docs.microsoft.com/en-us/azure/import-export/storage-import-export-tool-reviewing-job-status-v1#data-transfer-errors
