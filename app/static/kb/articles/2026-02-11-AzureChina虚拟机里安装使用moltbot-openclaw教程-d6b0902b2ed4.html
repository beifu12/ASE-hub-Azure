以下是我总结出如何在Azure虚拟机中（Linux机器）安装openclaw的教程：

首先我们准备一个Ubuntu 24.04的gen2的机器。

由于AI的原因，为了方便使用web页面我们可能需要准备一个可视化工具插件，我使用的是VNC：Download VNC Server by RealVNC®

登录进虚拟机的时候，我们需要提前设置一下VNC的环境

执行以下命令，清空缓存，更新您的软件包列表。

sudo apt clean all && sudo apt update

执行以下命令，安装桌面环境所需软件包。

sudo apt install xfce4 xfce4-goodies dbus-x11

执行以下命令，安装 VNC。

sudo apt install tightvncserver

执行以下命令，启动 VNC 服务，并设置 VNC 的密码。

注意：

一般 VNC 服务器密码最大长度是8位，所以这里不能设置超过8位的密码。

vncserver

执行以下命令，打开 VNC 配置文件。

vi ~/.vnc/xstartup

按 i 切换至编辑模式，并将配置文件替换为如下内容。

#!/bin/sh

xrdb "$HOME/.Xresources"

xsetroot -solid grey

#x-terminal-emulator -geometry 80x24+10+10 -ls -title "$VNCDESKTOP Desktop" &

#x-window-manager &

Fix to make GNOME work

export XKL_XMODMAP_DISABLE=1

/etc/X11/Xsession

startxfce4 &

按 Esc，输入 :wq，保存文件并返回。

执行以下命令，重启桌面进程。

vncserver -kill :1 #杀掉原桌面进程，输入命令（其中的:1是桌面号）

在 VNC Viewer 软件中，输入 云服务器的 IP 地址:1，按 Enter。

目前进行到这里是不通的，因为我们有默认的NSG，我们需要在NSG上添加对应的规则，VNC使用的端口是5900，桌面进程会+1，因此我建议NSG直接建立为5900-5910.

运行此命令，来进行安装npm等一系列组件：

curl -fsSL https://clawd.org.cn/install.sh |sudo bash -s -- --registry https://registry.npmmirror.com

安装完成之后，有可能会出现npm的对应报错，npm的报错90%的原因为路径不对，请参考以下命令：

Npm prefix -g #找到全局的npm前缀

将全局的npm bin目录添加到shell启动文件：

macOS / Linux

export PATH="/path/from/npm/prefix/bin:$PATH"

然后打开新终端或者在bash上运行hash -r

使用 sudo npm install -g openclaw-cn@latest --registry https://registry.npmmirror.com

安装成功之后，如果之前的安装未结束，直接使用：openclaw-cn onboard --install-daemon

开始使用 | OpenClaw 中文版 - 开源免费 AI 助手 | WhatsApp/Telegram/微信自动化

按照流程逐步配置。

关于API的问题，由于我们是Azure China区，受限于长城防火墙，最好使用国内的API

在安装的时候，默认情况使用的是国外的API，我们需要手动跳转到国内。

输入以下指令： vi ~/.openclaw/openclaw.json

我使用的是moonshot AI的API，国外版本的是api.moonshot.ai/v1, 国内则需要使用api.moonshot.cn/v1

找到对应的URL： 首先输入i 键，然后URL修改之后，按ESC，然后输入:wq保存退出。

接下来配置的是飞书的控制插件：参考：https://cloud.tencent.com/developer/article/2626160#:~:text=%E4%BA%94%E3%80%81-,%E6%8E%A5%E5%85%A5%E9%A3%9E%E4%B9%A6%E6%9C%BA%E5%99%A8%E4%BA%BA,-%E6%88%91%E4%BB%AC%E9%9C%80%E8%A6%81%E5%85%88%E5%88%B0

之后重启OpenClaw的gateway： openclaw-cn gateway restart

配置过后，如果你的API有订阅的话，那么直接输入openclaw-cn tui触发就可以正常使用了。
