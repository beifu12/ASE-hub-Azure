背景信息

  • Try to ping the share name from command prompt. How to ping an IP or name.
  • Try to access from different clients, any other IP which is in the same network range and assigned to a different machine or device, if that works then try to restart the databox device and ping again.
  • Try to restart the device and then connect again.
  • If still doesn’t work collect support package and engage TA's or raise ICM
