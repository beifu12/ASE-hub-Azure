不迁移虚拟机，只迁移保留的虚拟IP：

Classic Reserved Public IP迁移到ARM模式下的步骤，根据文档描述只有如下几步，在PowerShell中使用Classic Module相关指令：

指定将要登录到Azure China:

Add-AzureAccount -Environment AzureChinaCloud

在弹出的浏览器窗口中输入Azure订阅账号和密码。

获取要迁移的那个Public IP的保留名称：

Get-AzureReservedIP

解除Public IP与Cloud Service的关联, ServiceName在Get-AzureReservedIP的输出中有，对应的Classic VM保持Running状态不要关机：

Remove-AzureReservedIPAssociation -ReservedIPName 'myReservedIP' -ServiceName ‘ServiceName’

验证是否可以迁移，将黄色部分替换成相应IP的ReservedIPName：

$validate = Move-AzureReservedIP -ReservedIPName 'myReservedIP' -Validate

$validate

如果验证成功，继续进行第5步；如果失败请执行以下指令查看具体的验证失败原因：

$validate.validationmessages

准备迁移到ARM模式中，将黄色部分替换成相应IP的ReservedIPName：：

Move-AzureReservedIP -ReservedIPName 'myReservedIP' -Prepare

如果此时不想继续迁移了，则可以中止迁移操作，且是唯一的回退到ASM （Classic）机会：

Move-AzureReservedIP -ReservedIPName 'myReservedIP' -Abort

提交完成最终的迁移操作：

Move-AzureReservedIP -ReservedIPName 'myReservedIP' -Commit

迁移完成后该公网IP会自动放到一个叫xxxxx-Migrated的资源组中，xxx为ReservedIPName，根据需要再将其迁移到目标资源组中，直接Azure Portal上点击资源组名称处的（move）链接进行操作。

迁移完成后该Public IP SKU为Basic，如果您新建的ARM模式下的VM Public IP SKU为Standard，此时在Azure Portal中找到那个Public IP，然后进行SKU的升级，Overview里就会有提示信息，根据提示操作。

Azure Portal把新创建出来的ARM模式下的VM找到，点击其网卡，进行公网IP的变更：

测试网络连通性，业务连通性。

注意：

公网IP从ASM(Classic)迁移到ARM模式后不支持回退到ASM（Classic）模式下。
