Microsoft Stream

Common Data Box POD Order Creation Issues

Some of the most commonly asked issues regarding the status of a Data Box POD job include the following:

Data Box Model not Available

The Data Box service does not currently support all customer countries and regions. The service also supports data ingestion or egress only within the same country/region as the destination, and won't cross any international borders. The only exception is for orders in the European Union (EU), where Data Boxes can ship to and from any EU country/region.

For information regarding region availability for the Azure Data Box service, go to: Azure Products by Region

For detailed and updated information, go to: Order Data Box

Could not Validate Address

The Data Box service uses the UPS Address Validator to validate customer addresses. Ensure the address is formatted correctly, then use the Validator to confirm that the address is valid. If the address is valid, but the issue still occurs when creating the Data Box order, raise an IcM with the Data Box SaaS team for assistance.

Could not Create Data Box Order

In order to create a Data Box order, the following is required:

A Microsoft Azure storage account with access credentials, such as the storage account name and access key.

An Azure subscription of one of the following types:

Microsoft Customer Agreement (MCA) for new subscriptions or Microsoft Enterprise Agreement (EA) for existing subscriptions. Read more about MCA for new subscriptions and EA subscriptions.

Cloud Solution Provider (CSP). Learn more about Azure CSP program (This service is not supported for the Azure CSP program in India).

Microsoft Azure Sponsorship

Microsoft Partner Network (MPN)

Owner or contributor access to the Azure subscription

For detailed and updated information, go to: Prerequisites for service

Could not Create Additional Data Box Orders

The Data Box service limits each Azure subscription to 5 active Data Box orders.

For detailed and updated information, go to: Data Box subscription limits

When will I receive the Data Box?

Use Lens or ASC to check the status of a Data Box job. Tracking information can be found and relayed to the customer once the device has been shipped.
