详细操作步骤：

操作过程中会有Downtime产生，请在许可的时间段进行操作。

需要用到Azure PowerShell指令集，如Powershell中没有安装相应的指令包，请按如下步骤进行安装，下载有时会非常非常慢，如有可能可以尝试切换不同的运营商：

Windows 10安装Resource manager Azure Powershell module：

以管理员身份打开Powershell

检查已安装Powershell版本信息：

$PSVersionTable.PSVersion

修改Powershell默认的脚本执行安全策略：

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

安装Azure Resource manager PowerShell模块：

Install-Module -Name Az -Scope CurrentUser -Repository PSGallery -Force   #下载有时候会很慢，可以ctrl+C重来一次，等待下载并安装完成

登录连接Chinacloud Azure：

Connect-AzAccount -Environment AzureChinaCloud  #在弹出的浏览器窗口中输入账号密码，注意提示信息，如果提示需要进行MFA认证，需要在这一指令后面加上-TenantID xxxxx。

在多个订阅间切换，如果登录账户下有多个订阅，请切换到防火墙资源所属的订阅：

$context = Get-AzSubscription -SubscriptionId …   #替换为相应的订阅ID

Set-AzContext $context

确认现有的防火墙使用的经典规则进行管理的还是使用策略规则进行管理的，如果能够在防火墙的Portal页面中看到如下所示的按钮，则说明使用的经典规则进行管理的，需要先将迁移到使用策略进行管理 ，方法如下：

如果现有防火墙已是使用策略进行管理，则其Portal Overview中不会出现上图中的按钮，继续进行下一步。

依据现有的标准版的策略，转换出高级版的策略；两者区别：前者中的如TLS、IDPS功能不能够进行启用和详细配置，显示灰色，后者才可以进行功能启用和详细配置。转换方法，将https://docs.azure.cn/en-us/firewall/premium-migrate 文档中的powershell脚本复制到本地，保存为Transform-Policy.ps1 文本文件；然后在Powershell中进入保存这一文件的目录，然后执行:.\Transform-Policy.ps1 /subscriptions/XXXXX-XXXXXX-XXXXX/resourceGroups/some-resource-group/providers/Microsoft.Network/firewallPolicies/policy-name  ，红色字体部分为现有标准版策略的资源 ID。等待几分钟，转换完成后，可以在Portal中查看到以原标准版策略名称开头，以premium结尾的新策略即是高级版策略，可以点击进去查看详情。转换完成后原标准版策略仍会保留不会自动删除。转换过程中不会对Threat Intelligence的设置进行转换。

收集现在标准版防火墙的Overview信息，主要包含其现所属的VNet名称，public Ip名称 ，专用ip地址。

对现有防火墙执行Deallocate操作，大概耗时7分钟：

$azfw = Get-AzFirewall -Name "<firewall-name>" -ResourceGroupName "<resourcegroupname>"

$azfw.Deallocate()

Set-AzFirewall -AzureFirewall $azfw

Allocate高级版的防火墙，大概耗时12分钟：

$azfw = Get-AzFirewall -Name "<firewall-name>" -ResourceGroupName "<resource-group-name>"

$azfw.Sku.Tier="Premium"

$vnet = Get-AzVirtualNetwork -ResourceGroupName "<resource-group-name>" -Name "<Virtual-Network-Name>"

$publicip = Get-AzPublicIpAddress -Name "<Firewall-PublicIP-name>" -ResourceGroupName "<resource-group-name>"

$azfw.Allocate($vnet,$publicip)

待第7步powershell中的指令执行完成，刷新Portal中防火墙的Overview信息，检查其SKU是否为Premium，Provisioning state为Succeeded，如果状态正常，再点击“Migrate to firewall polcy”处的箭头，选择关联一个已存在的策略，关联上已准备好的那个高级版策略即可，关联成功后在防火墙Overview中可以看到关联的策略名称。

验证业务是否恢复正常。
