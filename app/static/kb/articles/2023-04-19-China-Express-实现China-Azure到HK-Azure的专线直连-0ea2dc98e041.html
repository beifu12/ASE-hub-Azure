Dear all，

同步一个小更新，之前接到国外客户工单，希望将Azure China与Global建立ER连接。

之前我们处理这类需求会建议用户自行联系两地ER供应商确认是否能实现。但目前新推出了“China Express”的服务，能够实现中国区与Azure East Asia，也就是香港，建立ER连接。

但有以下限制：

当前仅在东二部署的专线支持，后续北二可能也会支持，由GDS提供；

香港的服务提供商需为Equinix；

仅支持Azure资源的互通，不支持直接连通本地；

中国移动的国际业务部（solution@cmi.chinamobile.com）会协助实现两端专线的连通，且目前看来后续可能也是仅此一家服务商。

（如果有所了解，这非常类似farfetch的架构）

借助China Express，配合全局对等（使用远程网关），意味着用户将能在Global及Mooncake的大多数虚拟网络间实现更稳定的连接。

根据法规需要Azure China和Azure Global之间是完全独立的数据中心，Azure China也因此没有快速访问Azure Global所有区域的服务。

不过您可以尝试使用中国国移动国际部的China Express的服务，来打通Azure China到Azure香港的专线，进而实现到Global Azure的快速访问。如果您希望使用China Express，具体方案和报价，请联系中国移动国际部或微软的销售。

（来自：119032226000088/NET/H&M Hennes & Mauritz (Shanghai) commercial co., Ltd./SR_2019032114690_[MS-LED]Express Route, Technical posibilitys and how to get started）

As discussed, about the customer requirement that how to set up ExpressRoute from Azure China North to Azure global East Asia. ExpressRoute  supports virtual network access from Azure Global to Azure China regions. CMI (China Mobile International) provides dedicated network connections from China East 2 region (ExpressRoute Shanghai2 peering location) to East Asia region (ExpressRoute Hong Kong peering location). You can create private peering to your virtual networks in these regions and leverage ExpressRoute premium add-on to support global regions connectivity.

For the details, the customer could create the ExpressRoute premium  in the China East2 region, which can connect to the China North region VNet, also could create the ExpressRoute premium in East Asia region, that support global regions connectivity.

The customer should order and set up the separate ExpressRoute circuits in the Azure China East2 region and Global Azure East Asia region for China Express.

ExpressRoute provider in the China East2 is GDS;

ExpressRoute provider in the Azure East Asia should be Equinix

If customer already had ExpressRoute circuit at current peering location, it can’t link China Express circuit.

Then the customer should contact the CMI (China Mobile International) that provides connectivity through service providers. Please contact solution@cmi.chinamobile.com for enquiries.

The China Express cost will cover 3 parts that ExpressRoute China +ExpressRoute HK +Cross Border(CMI).

For the ExpressRoute China and ExpressRoute HK cost, please refer to the below:

https://azure.microsoft.com/en-us/pricing/details/expressroute/

https://www.azure.cn/en-us/pricing/details/expressroute/

For the Cross Border cost, please contact the CMI (China Mobile International)

Notice: Virtual network access from other Azure regions to China regions is supported. Extend connectivity from/to on-prem sites is not supported.
