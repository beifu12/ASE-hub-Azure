Please see the following TSG by leveraging Kusto:

Permission for CSS: Join security group Redmond\OaaSKustoGovUsers via IDweb.

EtwAll logs.

Sample query:

Execute: [Web] [Desktop] [Web (Lens)] [Desktop (SAW)] https://oaasprodmc.chinanorth2.kusto.chinacloudapi.cn/oaasprodmc

let JobID = "<job id>";

let StartTime = datetime(6/22/2020 1:16:00 AM);

let EndTime = datetime(6/29/2020 11:16:00 AM);

EtwAll

| where TIMESTAMP between (StartTime .. EndTime)

| where * contains JobID

| project TIMESTAMP, TaskName, EventMessage, Message

| limit 10000

Collect Automation account ID.

let subId = "<Sub ID>";

let AccountName = "<Account name>";

EtwSubscriptionIdAccountNameAccountId

| where TIMESTAMP > ago(1d)

| where subscriptionId  == subId

| where accountName == AccountName

| distinct accountId

Collect hybrid worker machine name & ID.

let START = ago(1d);

let END = now();

let AAID = "<account ID>";

let ROWLIMIT = 100;

JRDSEtwHybridWorkerPing

| where TIMESTAMP between (START .. END)

| where accountId == AAID

| limit ROWLIMIT

| project TIMESTAMP, workerGroup, machineId, machineName, workerVersion, SourceNamespace
