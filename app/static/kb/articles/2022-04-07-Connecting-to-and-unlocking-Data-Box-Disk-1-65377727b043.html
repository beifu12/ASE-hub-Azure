背景信息

  • Connect to the Data Box Disk:
  • Use the included cable to connect the disk to a Windows/Linux machine running a supported version.
  • For detailed and updated information of this product, refer to: Connect to disks and get the passkey
  • To unlock the disk:
  • Download and extract operating system-specific Data Box Disk unlock tool on the computer used to copy the data to disks.
  • The drive letter assigned to the disk is displayed by the tool. Make a note of the disk drive letter. This is used in the subsequent steps.
  • For detailed and updated information of this product, refer to: Unlock disks on Windows client or Unlock disks on Linux client.

排查思路

  • In the Azure portal, go to General > Device Details and get the passkey.
  • Run the Data Box Disk Unlock tool and supply the passkey. For any disk reinserts, run the unlock tool again and provide the passkey. Do not use the BitLocker dialog or the BitLocker key to unlock the disk.

Connect to the Data Box Disk:

Use the included cable to connect the disk to a Windows/Linux machine running a supported version.

For detailed and updated information of this product, refer to: Connect to disks and get the passkey

To unlock the disk:

In the Azure portal, go to General > Device Details and get the passkey.

Download and extract operating system-specific Data Box Disk unlock tool on the computer used to copy the data to disks.

Run the Data Box Disk Unlock tool and supply the passkey. For any disk reinserts, run the unlock tool again and provide the passkey. Do not use the BitLocker dialog or the BitLocker key to unlock the disk.

The drive letter assigned to the disk is displayed by the tool. Make a note of the disk drive letter. This is used in the subsequent steps.

For detailed and updated information of this product, refer to: Unlock disks on Windows client or Unlock disks on Linux client.
