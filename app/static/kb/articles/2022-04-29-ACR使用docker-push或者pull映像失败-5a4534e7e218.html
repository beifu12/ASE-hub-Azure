排查思路

  • After login, you may use command “az acr check-health --name <acrRegistry>--ignore-errors” to check both environment and target registry.
  • 通过抓包，可以看到是由于您本地发起了reset导致连接断掉。这可以说明是您本地网络的限制导致不能从镜像库pull镜像，相关限制可以联系您的本地网管进行调整。

操作步骤 / 命令

  • Please make sure Docker and Azure CLI (version > 2.0.67) are installed in your environment, then use command “az login” and “az acr login -name <acrRegistry>” to login your container registry.

解决方案

  • 客户使用azure虚拟机pull成功，可以通过抓包确认是否是客户侧网络问题。
  • 您可在本地开启两个窗口，一个用来执行抓包另一个用来执行docker pull，方式为先执行tcpdump –nn –I eth0 icmp,  对0口网卡经过的流量进行抓包（具体请参考您的本地实际情况进行修改），在另一窗口执行docker pull待报错后返回抓包窗口停止抓包。后续您可将包下载到本地，用wireshark工具进行查看与分析。
