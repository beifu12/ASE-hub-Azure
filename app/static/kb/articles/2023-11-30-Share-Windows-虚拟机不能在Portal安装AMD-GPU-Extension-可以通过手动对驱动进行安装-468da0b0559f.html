问题描述：

=======

1. 创建一台Nv4as v4 Windows 11 VM

2. 在Portal上，找到VM的“Extensions + Applications”菜单，点击进入新页面

3. 点击“Add”按钮，在新页面搜索“AMD GPU Driver Extension”

4. 点击AMD GPU Driver Extension，点击下一步，最后点击Create

5. 出现错误

{

"status": "Failed",

"error": {

"code": "ArtifactNotFound",

"message": "The VM extension with publisher 'Microsoft.HpcCompute' and type 'AmdGpuDriverWindows' could not be found."

}

排查步骤：

通过测试可以复现此问题

解决方案*：

==============

通过测试，可以手动安装AMD的驱动，详细步骤可参考此文档：https://learn.microsoft.com/en-us/azure/virtual-machines/windows/n-series-amd-driver-setup#nvv4-series

登录虚拟机，下载驱动文件：https://download.microsoft.com/download/4/1/2/412559d0-4de5-4fb1-aa27-eaa3873e1f81/AMD-Azure-NVv4-Driver-22Q2.exe

点击驱动文件.exe安装驱动：

安装完成后，重启虚拟机
