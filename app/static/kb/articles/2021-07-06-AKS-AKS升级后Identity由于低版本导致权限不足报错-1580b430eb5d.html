原始内容清洗稿（保留备查）

AKS环境为CNI网络模型，系统分配的托管标识, 版本从1.18.17升级为最新版本之后出现了当前报错信息。

可通过查看POD 来查看当前identity version, 若identity为1.6及更低会出现此问题   查看方式如下截图

#kubectl describe pod mic-68974f6cb8-cgxhf

经后台反馈该问题为aad-pod-identity 1.6之前版本的已知问题：

[Known Issue] LinkedAuthorizationFailed with AKS clusters · Issue #753 · Azure/aad-pod-identity · GitHub

可以通过升级aad-pod-identity版本到1.6以上来解决。

例如使用以下命令可以将aad-pod-identity升级到最新的1.8.0:

kubectl create -f https://raw.githubusercontent.com/Azure/aad-pod-identity/master/deploy/infra/deployment-rbac.yaml

如果想选择其他版本，例如1.7.1，可以使用：

kubectl apply -f https://raw.githubusercontent.com/Azure/aad-pod-identity/v1.7.1/deploy/infra/deployment-rbac.yaml

另外需要注意的是，aad-pod-identity 1.6以上版本需要和AGIC 1.2以上版本配合使用，请先确认AGIC在1.2以上版本，可以使用helm list命令查看AGIC版本：
