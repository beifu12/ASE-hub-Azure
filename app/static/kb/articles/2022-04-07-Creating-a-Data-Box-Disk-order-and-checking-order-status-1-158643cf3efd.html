Create Order:

Sign in to:

The Azure portal at this URL: https://portal.azure.com to order Data Box Disk. Or, the Azure Government portal at this URL: https://portal.azure.us.

Take the following steps to order Data Box Disk.

In the upper left corner of the portal, click + Create a resource, and search for Azure Data Box. Click Azure Data Box.

Create

Check if the service is available in your region

Select Data Box Disk

Specify order details

Fill in the shipping information

In the Notification details, specify email addresses.

Review the information Summary related to the order, contact, notification, and privacy terms

Order

For detailed and updated information of this product, refer to: Order Data Box Disk

Checking order status:

After you have placed the order, you can track the status of the order from Azure portal. Go to your order and then go to Overview to view the status. The portal shows the job in Ordered state.

For detailed and updated information of this product, refer to: Track the order
