SR_2020021906964_[MS-LED]10.81.16.105的22端口无法访问

问题描述

虚拟机无法SSH，需要关闭防火墙恢复连接。由于机器代理状态正常，可建议客户使用CLI通过代理在VM内部运行命令或脚本实现关闭防火墙目的。

解决方案：

方法一、使用Run-Command运行命令sudo ufw disable  （我测试成功）

#使用CLI登录Azure账号

az cloud set -n AzureChinaCloud

az login

az account set -s d3c17595-846b-42e1-8e58-dc872136fbd2

#使用run-command关闭防火墙

az vm run-command invoke -g ubuntu -n Ubun16 --command-id RunShellScript --scripts "sudo ufw disable"

参考链接： https://docs.azure.cn/zh-cn/virtual-machines/linux/run-command

方法二、使用custom script运行命令sudo ufw disable （客户测试成功）

#将以下脚本保存并上传到某个公网可以访问的位置，例如Azure Storage blob中，记录url。 如我的脚本存放位置 https://2012unmanagediag.blob.core.chinacloudapi.cn/script/yzinstall2.sh

脚本内容

#!/bin/bash

ufw disable

#运行以下命令关闭防火墙（可在linux CLI中运行，如在windows CLI中运行，需将settings后的引号更改下）

az vm extension set --publisher Microsoft.Azure.Extensions --version 2.0 --name CustomScript --vm-name Ubun16 --resource-group ubuntu --settings '{"fileUris":["https://2012unmanagediag.blob.core.chinacloudapi.cn/script/yzinstall2.sh"],"commandToExecute":"bash yzinstall2.sh"}'

参考链接 https://docs.azure.cn/zh-cn/virtual-machines/extensions/custom-script-linux

----------------------------------

注：在windows CLI中运行 az vm extension set --publisher Microsoft.Azure.Extensions --version 2.0 --name CustomScript --vm-name Ubun16 --resource-group ubuntu --settings '{"fileUris":["https://2012unmanagediag.blob.core.chinacloudapi.cn/script/yzinstall2.sh"],"commandToExecute":"bash yzinstall2.sh"}'

会提示 Expecting property name enclosed in double quotes: line 1 column 2 (char 1)，无法运行。

这是因为引号问题，运行以下命令即可返回结果。

az vm extension set --publisher Microsoft.Azure.Extensions --version 2.0 --name CustomScript --vm-name Ubun16 --resource-group ubuntu --settings "{'fileUris':['https://2012unmanagediag.blob.core.chinacloudapi.cn/script/yzinstall2.sh'],'commandToExecute':'bash yzinstall2.sh'}"
