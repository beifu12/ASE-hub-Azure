简要步骤：

1、为租户启用权限。

Install-Module AipService

Import-Module AipService

Connect-AipService -environmentname azurechinacloud

(Get-AipServiceConfiguration).FunctionalState

Enable-AipService

2、添加“Microsoft 信息保护同步服务”服务主体。

New-AzADServicePrincipal -ApplicationId 870c4f2e-85b6-4d43-bdda-6ed9a579b725 并添加请添加服务所需的相关权限。

另外注意该应用的启用状态：

参考AIP工单：

SR_20211202135568_Microsoft Information Protection Sync Service总是自动禁用，导致AIP功能不可用

Microsoft Azure Information Protection：

New-AzADServicePrincipal -ApplicationId 00000012-0000-0000-c000-000000000000

3、为不同客户端配置 DNS 加密。

Windows：

(Get-AipServiceConfiguration).RightsManagementServiceId

4、安装和配置 AIP 统一标签客户端。

https://www.microsoft.com/download/details.aspx?id=53018

5、在 Windows 桌面应用中配置 AIP。

Windows 上的 AIP 应用需要以下注册表项，用于指向 Azure China 的正确主权云：

注册表节点 = HKEY_LOCAL_MACHINE\SOFTWARE\WOW6432Node\Microsoft\MSIP

名称 = CloudEnvType

值 = 6（默认 = 0）

类型 = REG_DWORD
