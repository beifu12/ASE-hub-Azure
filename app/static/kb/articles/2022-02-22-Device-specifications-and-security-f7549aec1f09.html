问题现象 / 场景

  • The Data Box device is equipped with several 10GbE network interfaces for rapid transfer of data onto or off of the device. Data at rest on the device is encrypted, and the device can only be unlocked for access using a key associated with the customer's Data Box resource in the Azure portal. For import jobs, the device has all data erased at the end of the import process once the upload into Azure storage is complete. For export jobs, the customer themselves can initiate erasure of the Data Box device after they have transferred the data they needed to export and before returning the device to the Azure datacenter.
