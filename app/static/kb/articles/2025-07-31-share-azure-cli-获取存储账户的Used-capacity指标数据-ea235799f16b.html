原始内容清洗稿（保留备查）

存储账户的Used capacity 信息需要从metrics 获取。 以下是以1小时为颗粒度获取的存储账户 的Used capacity 数据。

Set variables

RESOURCE_GROUP="YourResourceGroupName"

STORAGE_ACCOUNT="YourStorageAccountName"

Get the storage account resource ID

STORAGE_ID=$(az storage account show --name $STORAGE_ACCOUNT --resource-group $RESOURCE_GROUP --query "id" -o tsv)

Retrieve the UsedCapacity metric (usage in bytes)

az monitor metrics list --resource $STORAGE_ID --metric "UsedCapacity" --interval PT1H --output table
