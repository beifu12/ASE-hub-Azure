2024.7.20

当拿到一个Azure云中的公共IP时，如何快速找出它包含在哪种Azure Service中？

先从Microsoft中下载最新的Public IP和Service tag文件：(可以看到一个个的IP段，少数是/32的主机IP）

https://www.microsoft.com/en-us/download/details.aspx?id=57062

再使用如下Python脚本，快速找出指定的一个或者多个IPv4、IPv6是属于哪个IP段的：

import json

from ipaddress import ip_address, ip_network

def load_service_tags(filepath):

with open(filepath, 'r') as file:

data = json.load(file)

return data['values']

def find_ip_in_networks(ips, service_tags):

results = {}

for ip_str in ips:

ip = ip_address(ip_str)

matches = []

for service in service_tags:

service_name = service['name']

address_prefixes = service['properties']['addressPrefixes']

for prefix in address_prefixes:

try:

net = ip_network(prefix, strict=False)

if ip in net:

matches.append((service_name, prefix))

except ValueError:

Ignore invalid prefixes

pass

results[ip_str] = matches

return results

获取用户指定的服务标签JSON文件路径

service_tags_file = input("请输入服务标签JSON文件的路径：")

加载服务标签数据

service_tags = load_service_tags(service_tags_file)

获取用户输入的IP地址

ips_input = input("请输入一个或多个IP地址，用逗号分隔：")

ips_to_check = [ip.strip() for ip in ips_input.split(',')]

查找特定IP地址属于哪些服务的IP段

results = find_ip_in_networks(ips_to_check, service_tags)

输出查询结果

for ip, service_matches in results.items():

if service_matches:

print(f"The IP address {ip} is within the following service IP ranges:")

for service_name, ip_range in service_matches:

print(f"Service: {service_name}, IP Range: {ip_range}")

else:

print(f"The IP address {ip} does not match any service IP range.")

使用方法，将上述脚本保存为文件，如ip_check.py，然后执行python3 ip_check.py:
