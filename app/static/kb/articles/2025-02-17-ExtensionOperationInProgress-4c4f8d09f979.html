问题现象 / 场景

  • Error code: ExtensionOperationInProgress
  • Error message: Command execution failed.
  • We have identified that the backup operation failed because changes were made to the Virtual Machine while the operation Create Restore Point was in progress.
  • ErrorCode: ExtensionInstallProviderCOMMemoryQuotaReached

背景信息

  • Recommended Steps for CSS:
  • ExtensionInstallProviderCOMMemoryQuotaReached
  • In the impacted machine, open the Registry Editor by typing regedit in the Run window.
  • Go to the HKEY_LOCAL_MACHINE\System\CurrentControlSet\Control\Session Manager\SubSystems - windows
  • Right-click on Windows shared section and click Modify.
  • Update the value with Windows SharedSection=1024,20480,4096.
  • Once the registry is updated with above value, reboot the server and retry the backup operation.

What is the workaround?

In the impacted machine, open the Registry Editor by typing regedit in the Run window.

Go to the HKEY_LOCAL_MACHINE\System\CurrentControlSet\Control\Session Manager\SubSystems - windows

Right-click on Windows shared section and click Modify.

Update the value with Windows SharedSection=1024,20480,4096.

Once the registry is updated with above value, reboot the server and retry the backup operation.
