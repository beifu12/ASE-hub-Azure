解决方法如下，使用macOS下第三方RDP程序 Remotix 链接成功，Remotix可以试用，所以连接之后可以按照教程修改后使用微软官方RDP链接程序链接

在MACOS远程管理WindowsServer的解决方案：

（1）Click Start>Run , Type gpedit.msc and click "OK" . Result: The Group Policy Editor will open:

（2）In the left hand side bar, expand Computer Configuration>Administrative Templates>Windows Components>Remote Desktop Services>Remote Desktop Session Host    Select "Security"

（3）Change "Require use of specific security layer for remote desktop (RDP) connection" to Enabled" and select "RDP" in the Options pane.

（4）Change "Require user authentication for remote connections by using Network Level Authentication" to "Disabled."

（5）Close Group Policy Editor and reboot the machine for changes to take effect.
