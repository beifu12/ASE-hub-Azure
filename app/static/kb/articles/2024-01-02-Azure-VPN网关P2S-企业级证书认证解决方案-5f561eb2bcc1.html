20231213

P2S连接的场景基本都用自签名证书，有些企业可能需要知名CA根证书作认证，以下提供P2S企业级证书解决方案

根证书配置

以阿里云签发证书为例，下载CA根证书并安装在本电脑的Current User-Personal-Certificates目录下

右键以记事本方式打开.cer文件，将除了首末两行(---BEGIN CERTIFICATE---和---END CERTIFICATE---)的所有内容粘贴到Azure VPN P2S根证书配置处保存

客户端证书配置

签发客户端证书，以Windows系统Powershell方式为例

找到安装在此电脑的CA根证书，记录下对应指纹

Get-ChildItem -Path "Cert:\CurrentUser\My"

用变量$cert记录根证书，标黄部分替换为根证书对应指纹

$cert = Get-ChildItem -Path "Cert:\CurrentUser\My\<THUMBPRINT>"

签发客户端证书，标黄部分改为实际参数, 注意CN格式是用户名@域

$params = @{

Type = 'Custom'

Subject = 'CN=evan@first.wats.xyz'

DnsName = 'first.wats.xyz'

KeySpec = 'Signature'

KeyExportPolicy = 'Exportable'

KeyLength = 2048

HashAlgorithm = 'sha256'

NotAfter = (Get-Date).AddMonths(18)

CertStoreLocation = 'Cert:\CurrentUser\My'

Signer = $cert

TextExtension = @(

'2.5.29.37={text}1.3.6.1.5.5.7.3.2')

}

New-SelfSignedCertificate @params

连接VPN

Azure VPN下载并解压，以WINDOWS为例，双击WindowsAmd64\VpnClientSetupAmd64.exe安装

安装完毕后，系统会生成VPN连接，点击connect即可拨号至Azure VPN网关
