问题现象 / 场景

  • 日志集中有大量的以下报错，从报错来看，无法获取文件的size。

背景信息

  • 删除文件， 并注销账号ww后，profile文件自动压缩。
  • 从日志中可以看到相应的压缩记录，附件是我测试环境的详细日志信息。
  • 此问题应该是系统WMI的问题。

排查思路

  • 搭建环境测试FSlogix磁盘压缩的功能是正常的。
  • 测试账户ww登录后，复制一个大文件后，查看fslogix对应的文件共享中，profile的size变大。
  • 排查：
  • 查看客户提供的日志，发现日志中disk size reduced 都是0MB。
  • 从目前的排查情况来看，主机池里面的VM在执行Get-PartitionSupportedSize -DiskNumber xx时，会有以下Invalid property的报错，报错的code为：0x80041031
  • 如官方文档上的描述，执行磁盘压缩需要使用Get-SupportedSize 方法中的 SizeMin 参数查询 MSFT_Partition API 来确定支持的最小大小。
