2021-06-28

参考工单：SR_20210624104601_[MS-LED]存储帐户的“冷”切换到“存档”

需求：

客户需要将本地数据700T左右，使用Azure Data Box传输到Azure存储，考虑到费用的问题，希望能直接设置为“存档”。如果后期转为“存档”，会产生额外的费用。

和CSS的Sun Wei确认了下，目前Azure Data Box传输到Azure存储暂不支持直接设置为“存档”，

Azure Data Box的PM说这个在他们的roadmap里面但是没有确切的时间表

客户可以使用生命周期管理，将blob设置为“存档”

https://docs.azure.cn/zh-cn/storage/blobs/storage-lifecycle-management-concepts?tabs=azure-portal#examples

测试发现生命周期管理策略设置之后，需要约24小时才能执行。

如下截图中，我的策略是在2021/6/25 上午9点多设置的，发现在2021/6/26上午9:35才执行。
