1，使用Azure Powershell

++++++++++++++++++++++++++++++

$vms = Get-AzVM

foreach ($vm in $vms) {

Get-Azvm --ResourceGroup $vm.ResourceGroupName --Name $vm.Name -Status | select Name, OsName, OsVersion

}

输出结果如下方截图所示（注，此方法需要1，虚拟机需要开机运行；2，虚拟机的代理状态为Ready），下方示例中OS信息为空的VM，皆因虚拟机未开机所致。

2，使用Azure CLI

+++++++++++++++++++++++++++++

vmname=(az vm list --query "[].{vmName:name}" -o table | grep -v ^VmName | grep -v ^---)

vmrg=(az vm list --query "[].{ResourceGroup:resourceGroup}" -o table | grep -v ^ResourceGroup | grep -v ^---)

for ((i=0; i<${#vmname[*]}; i++ )); do  az vm get-instance-view --resource-group ${vmrg[i]} --name ${vmname[i]} --query "{VMName:name, OS:instanceView.osName, OSVersion:instanceView.osVersion}" --output table | grep -v ^VMName; done
