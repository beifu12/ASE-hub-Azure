2026/03/12

通过Portal创建AFD，会遇到一个密钥保管库权限错误：

可以使用powershell来先分配用户托管标识符权限，然后再创建：

Define 变量:

$SUBSCRIPTION_ID="YOUR SUBSCRIPTION_ID "

$RESOURCE_GROUP="AKS"

$LOCATION="chinanorth3"

$USER_ASSIGNED_ID_NAME="afd-user-mi"

$KEYVAULT_NAME="AKSkey"

$AFD_PROFILE_NAME="afd-profile-01"

identity create

az identity create --name $USER_ASSIGNED_ID_NAME --resource-group $RESOURCE_GROUP --location $LOCATION --subscription $SUBSCRIPTION_ID

az identity show --name $USER_ASSIGNED_ID_NAME --resource-group $RESOURCE_GROUP --query id --output tsv

$USER_ASSIGNED_ID_RESOURCE_ID=(az identity show --name $USER_ASSIGNED_ID_NAME --resource-group $RESOURCE_GROUP --query id --output tsv)

$USER_ASSIGNED_ID_CLIENT_ID=(az identity show --name $USER_ASSIGNED_ID_NAME --resource-group $RESOURCE_GROUP --query clientId --output tsv)

echo "Resource ID: $USER_ASSIGNED_ID_RESOURCE_ID"

get keyvault policy

az keyvault set-policy --name $KEYVAULT_NAME --resource-group $RESOURCE_GROUP --object-id $USER_ASSIGNED_ID_CLIENT_ID --certificate-permissions get list --secret-permissions get list --key-permissions get list

create AFD

az afd profile create --profile-name Afd2 --resource-group $RESOURCE_GROUP --sku Standard_AzureFrontDoor --identity-type UserAssigned --user-assigned-identities "$USER_ASSIGNED_ID_RESOURCE_ID"
