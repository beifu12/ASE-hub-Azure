问题现象 / 场景

  • Contact the customer and gather as much information as you can about the issue (e.g. what is the error message on the client, any screenshots, past changes, or any additional relevant information.

背景信息

  • Was it working before?
  • Connect the disk(s) to a different USB port on the host machine (Note: Please ensure the USB port is a USB 3.0 port)
  • Connect the disk(s) to a different host machine. If no other host available confirm if customer has reboot the host.
  • Connect the disk(s) using a different USB cable if multiple disks ordered (make sure customer uses the cable sent with the disk)
  • Use all collected information to engage TA's or raise ICM
  • References:

排查思路

  • Check the USB ports in Device Manager (Note: Be sure to collect a screenshot)
  • Check if the disk(s) are showing as ‘RAW’ or ‘Unallocated’ in Disk Management (Note: Be sure to collect a screenshot)
