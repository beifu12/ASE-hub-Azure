Hi All,

最近AKS相关的工单有所上升，重新整理了登录AKS Node的两种方法及应该搜集哪些日志，请参考。

1、根据官方说明登陆Node，并搜集Node中的日志

=========================

根据Azure官方说明进行操作

https://docs.azure.cn/zh-cn/aks/ssh#create-the-ssh-connection

在一台Linux机器中生成密钥对

下载安装cli

az --version

使用cli登陆Azure Portal

az cloud set -n AzureChinaCloud

az login -u "heliming@microsoftinternal.partner.onmschina.cn"

选择指定的订阅

az account set -s 0b4b20c5-29b3-4dd9-bfdc-40b75f1dc4c9

运行如下命令，将公钥推送到vmss实例

CLUSTER_RESOURCE_GROUP=$(az aks show --resource-group  hlmrge2 --name hlmakse2t1 --query nodeResourceGroup -o tsv)

az vmss extension set  --resource-group $CLUSTER_RESOURCE_GROUP --vmss-name $SCALE_SET_NAME --name VMAccessForLinux --publisher Microsoft.OSTCExtensions --version 1.4 --protected-settings "{\"username\":\"azureuser\", \"ssh_key\":\"$(cat ~/.ssh/id_rsa.pub)\"}"

az vmss update-instances --instance-ids '*' --resource-group $CLUSTER_RESOURCE_GROUP --name $SCALE_SET_NAME

下载aks管理凭据

az aks get-credentials -g hlmrge2 -n hlmakse2t1

登陆ssh帮助器pod

kubectl run -it --rm aks-ssh --image=debian

安装或跟新ssh客户端

apt-get update && apt-get install openssh-client -y

打开一个未连接到容器的新终端窗口，将专用 SSH 密钥复制到帮助程序 Pod 中。 此私钥用来与 AKS 节点建立 SSH 连接。

kubectl cp ~/.ssh/id_rsa $(kubectl get pod -l run=aks-ssh -o jsonpath='{.items[0].metadata.name}'):/id_rsa

返回到与容器建立的终端会话，更新复制的 id_rsa SSH 私钥中的权限，使其成为用户只读的

chmod 0600 id_rsa

与 AKS 节点建立 SSH 连接

ssh -i id_rsa azureuser@10.240.0.4

参考如下操作命令搜集日志：

cd /tmp/

mkdir logsCollection

journalctl -u kubelet > logsCollection/kubelet.log

date > logsCollection/dateOutput.txt

last > logsCollection/lastOutput.txt

cd /var/log/

cp -r azure/ /tmp/logsCollection/

cp -r auth.log* messages* syslog* waagent.log* /tmp/logsCollection/

ll /tmp/logsCollection/

tar zcvf logsCollection.tgz logsCollection/*

sudo chown azureuser:azureuser logsCollection.tgz

使用exit退出VMSS实例的SSH session，返回到aks-ssh pod, 使用scp命令将打包日志拷出到aks-ssh pod：

scp -i id_rsa azureuser@10.*.*.*:/tmp/logsCollection.tgz .

重新打开一个新的未连接到该pod的终端窗口，在新窗口中使用kubectl cp命令将文件从aks-ssh pod拷贝到本地：

kubectl cp aks-ssh:/logsCollection.tgz logsCollection.tgz

将本地的文件拷贝到Pod内部的命令：

kubectl cp /bin/ip ingress-basic/melting-penguin-nginx-ingress-controller-6c4446f4dd-rqlbq:/tmp

2、使用node shell登陆Node #####疑似已不适用于新版本--Jia.xiaoeli

使用node shell登录： https://github.com/kvaps/kubectl-node-shell

安装以及使用：

安装node-shell工具

curl -LO https://github.com/kvaps/kubectl-node-shell/raw/master/kubectl-node_shell

chmod +x ./kubectl-node_shell

sudo mv ./kubectl-node_shell /usr/local/bin/kubectl-node_shell

登录账号并kubectl连接到集群：

az login

az aks get-credentials --resource-group RGChinaN2 --name aks-cluster-cn2

查看集群名称：kubectl get nodes

连接到集群：kubectl node-shell aks-agentpool-12844706-vmss000000
