问题现象 / 场景

  • The NFS shares on a Data Box device have a naming convention based on the storage account(s) that data is being imported to or exported from and the type of data being imported or exported. The syntax for the UNC path to each share is shown below.

背景信息

  • The NFS shares on a Data Box device have a naming convention based on the storage account(s) that data is being imported to or exported from and the type of data being imported or exported. The syntax for the UNC path to each share is shown below.
  • Azure Block blob - //<device IP address>/<storage account name>_BlockBlob
  • Azure Page blob - //<device IP address>/<storage account name>\_PageBlob
  • Azure Files - //<device IP address>/<storage account name>_AzFile
  • Azure Block blob (Archive) - //<device IP address>/<storage account name>_BlockBlobArchive
  • If a Data Box device is being used to import to managed disks, the device will have additional shares with a naming convention based on the resource group selected during the ordering process and the type of managed disk that will be created upon data import. The syntax for these share names is shown below.
  • Premium SSD - //<DeviceIPAddress>/<ResourceGroupName_MDisk>/PremiumSSD
  • Standard HDD - //<DeviceIPAddress>/<ResourceGroupName_MDisk>/StandardHDD
  • Standard SSD - //<DeviceIPAddress>/<ResourceGroupName_MDisk>/StandardSSD
  • The basic steps to connect to an NFS share on the Data Box device from a Linux or Mac OS client are:
  • In the local web UI on the device, go to the "Connect and copy" page. Under "NFS settings", click "NFS client access".
  • Enter the IP address of the NFS client and click "Add". You can configure access for up to 5 NFS clients / IP addresses by repeating this step. When all the IP addresses you want to add have been entered, click OK.
  • For Linux clients, use the following command syntax to mount the NFS share: sudo mount <Data Box device IP>:/<NFS share on Data Box device> <Path to the folder on local Linux computer>
  • For Mac clients, use the following command syntax to mount the NFS share: sudo mount -t nfs -o sec=sys,resvport 10.161.23.130:/Mystoracct_Blob /home/databoxubuntuhost/databox
  • The recommended command line copy tool to use with Data Box from a Linux system is rsync.
  • For more information on using NFS with a Data Box device, please see the links below.
  • Copy data to Azure Data Box via NFS
  • Copy data from Azure Data Box via NFS
  • Microsoft Stream
