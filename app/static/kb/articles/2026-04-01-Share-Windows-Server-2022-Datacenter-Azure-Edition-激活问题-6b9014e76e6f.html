查看客户在同一网络中有激活成功的虚拟机，可以基本排除网络方面的问题。

检查客户的系统日志，发现有以下报错信息，怀疑还是证书方面的问题。

查看客户之前的工单，客户反馈之前运行过检查证书的脚本。

===========================================================

Get the signature

Powershell 5.1 does not include -NoProxy

$attestedDoc = Invoke-RestMethod -Headers @{"Metadata"="true"} -Method GET -Uri http://169.254.169.254/metadata/attested/document?api-version=2018-10-01

#$attestedDoc = Invoke-RestMethod -Headers @{"Metadata"="true"} -Method GET -NoProxy -Uri http://169.254.169.254/metadata/attested/document?api-version=2018-10-01

Decode the signature

$signature = [System.Convert]::FromBase64String($attestedDoc.signature)

Get certificate chain

$cert = [System.Security.Cryptography.X509Certificates.X509Certificate2]($signature)

$chain = New-Object -TypeName System.Security.Cryptography.X509Certificates.X509Chain

if (-not $chain.Build($cert)) {

Print the Subject of the issuer

Write-Host $cert.Subject

Write-Host $cert.Thumbprint

} else {

Print the Subject of each certificate in the chain

foreach($element in $chain.ChainElements) {

}

Get the content of the signed document

$signedCms = New-Object -TypeName System.Security.Cryptography.Pkcs.SignedCms

$content = [System.Text.Encoding]::UTF8.GetString($signedCms.ContentInfo.Content)

Write-Host "Attested data: " $content

$json = $content | ConvertFrom-Json

但是客户反馈运行脚本后提示了证书缺失，他检查证书实际已经安装。

CN=metadata.azure.cn, O="Shanghai Blue Cloud Technology Co., Ltd.", S=Shanghai, C=CN D6D2BA106C4BAB43849DA7AD8070001B2ADD3068 ------------------------ CN=DigiCert Basic RSA CN CA G2, O=DigiCert Inc, C=US ------------------------ Certificate not found: 'CN=DigiCert Basic RSA CN CA G2, O=DigiCert Inc, C=US' Please refer to the following link to download missing certificates: https://learn.microsoft.com/en-us/azure/security/fundamentals/azure-ca-details?tabs=certificate-authority-chains

然后，客户运行了以下脚本disable了 revocation checking

$chain = New-Object System.Security.Cryptography.X509Certificates.X509Chain

$chain.ChainPolicy.RevocationMode = "NoCheck"

$chain.ChainPolicy.VerificationFlags = "IgnoreWrongUsage"

Write-Host "Certificate chain validation failed"

之后发现激活状态正常了。

最终发现客户的设备没有安装DigiCert Basic OV G2 TLS CN RSA406 SHA256 2022 CA1

指导客户手动下载证书安装后，问题解决。
