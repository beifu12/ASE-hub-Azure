Azure AD Rebrand FAQ

Purpose

Azure AD(Azure Active Directory) is being renamed to Microsoft Entra ID. Public announcement happened on July 11th 2023, during Reimagine Secure Access with Microsoft Entra digital event .

This change requires No Customer Action as this is rename of Azure AD(Azure Active Directory) to Microsoft Entra ID. Customers who are using Azure AD today or are currently deploying it in their organizations can continue to use the service without interruption. All existing deployments, configurations, and integrations will continue to function as they do today. All features and capabilities are still available. Licensing, terms, and pricing remain the same. To make the transition seamless, all existing login URLs, APIs, and Microsoft authentication libraries (MSAL) stay the same, as do developer experiences and tooling.

Starting July 11th 2023, customers will see notifications in Administrator portal, on websites, in documentation, and other places where they may interact with Azure AD. We’ll continue to update the name change in our products from Azure AD to Microsoft Entra ID, starting August 15, 2023 till end of calendar year 2023.

This document is intended for internal use only, to help prepare support engineers to help with answers to frequently asked customer question about Azure AD Rebrand.

General/ Customer Facing FAQs

Link to public facing docs article is available.

Support specific - Frequently Asked Questions (FAQ)

This is a collection of frequently asked questions we expect customers might have, related to rebrand.

What is Microsoft Entra?

Answer - Microsoft Entra is the product family name for all identity & network access solutions from Microsoft. It’s part of the Microsoft Security portfolio, which also includes Microsoft Defender for Threat Protection and Cloud Security, Microsoft Intune for Endpoint Management, Microsoft Priva for privacy, Microsoft Purview for compliance, and Microsoft Sentinel for SIEM (Security Information and Event Management). As of July 11th, 2023, Microsoft Entra consists of the following products:

Microsoft Entra ID – generally available (Formerly known as Azure Active Directory (Azure AD))

Microsoft Entra ID Governance – GA July 1, 2023

Microsoft Entra Internet Access – Public Preview

Microsoft Entra Private Access – Public Preview

Microsoft Entra External ID – Public Preview

Microsoft Entra Permissions Management – generally available

Microsoft Entra Verified ID – generally available

Microsoft Entra Workload ID - generally available

Refer to Appendix 1 for more details on Microsoft Entra Product Family.

What is Microsoft Entra ID?

Answer: Microsoft Entra ID is new name for Azure Active Directory or Azure AD. Microsoft Entra ID provides a complete identity and access management solution with integrated security to manage and protect all users and data. Customers can safeguard their organization with a leading cloud identity and access management solution that connects employees, customers and partners to their apps, devices, and data. Refer to Appendix 2 for more information on SKU names How should I refer to Microsoft Entra products and features?

Always keep “Microsoft” and Entra locked together. Do not drop the Microsoft brand name. Example Microsoft Entra ID

Use full product and feature names, do not abbreviate, or use acronyms.

Attribute all features and components to the Microsoft Entra product family.

Examples:

Microsoft Entra Tenant

Microsoft Entra Conditional Access

Microsoft Entra Passwordless

Microsoft Entra Roles

Microsoft Entra Joined

Hybrid Microsoft Entra Joined

Microsoft Entra Registered

For additional guidelines and detailed information about Microsoft Entra branding, please refer to the Microsoft Entra Branding Playbook .

Why is Microsoft changing name of Azure AD? What is the need of rebrand? Why are we doing this? What was the need of new name?

Answer: It’s been a year since we introduced Microsoft Entra – a new identity and access product family for our expanded vision for secure access. At that time Microsoft Entra included Azure Active Directory plus two new products: Microsoft Entra Permissions Management, a cloud infrastructure entitlement management product, and Microsoft Entra Verified ID, a decentralized identity solution.

Since then, we’ve seen strong adoption of our new products, and continued growth in Azure AD adoption with 720,000 customers choosing it as their identity solution. We’ve also added four new products into Microsoft Entra family – ID Governance, Workload ID, Internet Access and Private Access - to deliver a complete toolset for securing access for any identity to any resource.

Unifying all identity and access capabilities under the Microsoft Entra name will make it easier to navigate and use the entire repertoire of products in our expanded portfolio and ensure that you have the strongest protections for any access point.

When is the name change happening?

Answer: The name change will start appearing across Microsoft experiences after 30 days from announcement(on July 11th, 2023). We’ll continue to update the name change in our products from Azure AD to Microsoft Entra ID, starting August 15th, 2023 till end of calendar year 2023. Display names for SKUs and Service Plans will change on September 1, 2023.

Exact dates on product name change I am using in my env – e.g. ADDS

Answer: Most products will change display names between August 15 till end of year 2023. By Mid- July, we will publish a plan and timeline for product name changes across IDNA products.

Do I (support engineer) need to ask or tell my customer proactively about rebrand post July 11th?

Answer: Please share details about rebranding only if customer asks about it.

What does rebrand of Azure AD mean for customer? How will the change impact customers? Do they need to do anything?

Answer: No action is required from customers.

No changes to capabilities, licenses, pricing, service level agreements, APIs, URLs, Microsoft Authentication Library (MSAL), nor developer experiences.

To ensure no service interruption, the following experiences of Azure AD will not change:

URLs For example,

https://api.azrbac.mspim.azure.com/api/v2/privilegedaccess/aadroles/roleassignments

https://api.azrbac.mspim.azure.com/api/v2/privilegedaccess/aadgroups/roleassignmentrequests

APIs / endpoints – for example, the Microsoft Graph API Developer experiences – Microsoft Authentication Libraries, Microsoft Identity Platform (these do not carry the Azure AD name)

The changes will not cause any functionality change or downtime.

There are no changes to any existing deployments or integrations, they will continue to work without interruption.

Product certifications continue to be valid after the product renaming.

An article on the rebranding is available to customers on MS Learn at https://aka.ms/aadrebrandFAQ.

Customer Support (CSS) is aware of the changes and will be prepared to assist customers with any questions.

During 2023, you may see both the current Azure AD name and new Microsoft Entra ID name in support area paths. For self-service support, look for the topic path of “Microsoft Entra” or “Azure Active Directory / Microsoft Entra ID”.

Answer: These names and services aren’t changing:

Microsoft identity platform  – Build applications your users and customers can sign into using their Microsoft identities or social accounts.

Active Directory Federation Services (AD FS)  nor Active Directory Domain Services (AD DS)  nor any feature names for Active Directory.

Azure Active Directory B2C  will continue to be available as an Azure service.

Any deprecated or retired functionality, feature, or service  of Azure Active Directory
