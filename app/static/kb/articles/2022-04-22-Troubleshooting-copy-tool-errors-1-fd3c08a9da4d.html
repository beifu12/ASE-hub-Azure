  • Contact the customer and gather as much information as you can about the issue (e.g. what is the error message on the client, any screenshots, past changes, or any additional relevant information)

背景信息

  • Make sure that the data copied meets requirements (naming convention, size, etc)
  • Collect details about the tool used to copy and OS on the host
  • Name of the tool (if Robocopy or a 3rd party)
  • Ask the customer to send the command or syntaxis used for the copy job
  • If there are parallel jobs running to copy data
  • Make sure no other tool or application is also using the data (scanning tools like antivirus, deduplication, etc)
  • Collect support package and engage TA's or raise ICM
