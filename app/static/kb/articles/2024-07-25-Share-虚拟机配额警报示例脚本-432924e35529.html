Update

Hana Liu

分享一个工单“SR_20240716304870_配额告警功能”，客户咨询Azure是否有Quota的预警功能，比如我们某一个型号的VM使用量达到一个阈值时，发出自动告警?

当前Global Azure官方文档 创建配额警报- Azure Quotas | Microsoft Learn 中提到可以为虚拟机创建配额警报，但是当前中国区没有对应的文档，我本地测试，当前在中国区还不能创建配额警报。

我本地测试做了一个Powershell示例脚本，可以查看并在达到或超过设定的阈值时通过smtp服务器发送警报邮件, 具体请参考如下。

注：高亮部分请根据时间情况修改。

#添加环境变量使之登录到中国区Azure#

Connect-AzAccount -Environment AzureChinaCloud

#如有多个订阅，需要修改默认订阅，请参考如下的命令，高亮部分请使用您的订阅ID进行替换#

Select-AzSubscription -SubscriptionId  “SubscriptionId”

#定义阈值，当前设置的阈值为90%#

$coreThreshold = 0.9

#获取区域列表#

$locations = Get-AzLocation  | Where-Object { $_.Location -ne 'china' -and $_.Location -ne 'global'} | Select-Object -ExpandProperty Location

#遍寻所有区域查看虚拟机配额情况#

foreach ($location in $locations)

{

$usage = Get-AzVMUsage -Location $location | Where-Object { $_.Name.LocalizedValue -like '*vCPUs*' }   #仅筛选了关于vCPUs的项#

$alertInfo = foreach ($item in $usage) {

$name = $item.Name.LocalizedValue

$currentValue = $item.CurrentValue

$limit = $item.Limit

if ($limit -ne 0) #排除配额limit为0的型号,即没有配额的型号#

$threshold = [math]::Round($limit * $coreThreshold)

if ($currentValue -ge $threshold) {

"Usage of $name has exceeded the threshold of $threshold. Current usage: $currentValue."

}

if ($alertInfo) {

$subject = "VM Usage Threshold Exceeded in $location"

$body = $alertInfo -join "`n"  #将一个区域中所有警报信息连起来#

$emailTo = "liu.huan3@oe.21vianet.com"#定义收件人#

$smtpCredential=new-object -typename System.Management.Automation.PSCredential -argumentlist "xxxxx@126.com",(ConvertTo-SecureString "GLTxxxxBG" -AsPlainText -Force) #定义smtp服务器的凭据#

Send-MailMessage -To $emailTo -From "xxxxx@126.com" -Subject $subject -Body $body -SmtpServer "smtp.126.com" -Credential $smtpCredential -Port "25" -UseSsl

#本地使用的测试阈值为1%，测试收到的警报邮件情况#

注：关于使用公共邮箱（比如126邮箱，163邮箱）作为SMTP 服务器的更多说明，请参考如下的截图
