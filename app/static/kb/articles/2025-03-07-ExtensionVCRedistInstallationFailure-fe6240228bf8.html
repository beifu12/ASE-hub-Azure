For extension versions having 1.0.92 or below versions follow these steps

Error Code: ExtensionVCRedistInstallationFailure

Error Message: Snapshot operation failed due to failure in installation of Visual C++ Redistributable for Visual Studio 2012.

Recommended Steps for CSS:

The Backup operation failed due to failure in installation of Visual C++ Redistributable for Visual Studio 2012. To resolve this issue perform the below:

Step 1: Installing Visual C++ Redistributable for Visual Studio 2013

To install Visual C++ Redistributable for Visual Studio 2013, navigate to C:\Packages\Plugins\Microsoft.Azure.RecoveryServices.VMSnapshot\<LatestVersion> folder and run vcredist2013_x64 file.

If you encounter an issue during installation, perform the below steps:

Ensure HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\Msiserver registry key value is set to 3 and not 4 for allowing this service installation.

Restart installation service from the elevated command prompt by running the below command:

MSIEXEC /UNREGISTER

MSIEXEC /REGISTER .

Step 2: If issue still persist after installation then run the below Kusto query

TraceLogMessage

| where TIMESTAMP > ago(1d)

| where TaskId == "0f15d6f0-965c-49fd-90ad-4c649c1ec3e3"

| project PreciseTimeStamp, Message

| where Message contains "Install VCRedist"

| order by PreciseTimeStamp asc

Sample output is given below:

PreciseTimeStamp

Message

2018-11-29 20:10:58.3542005

2018-11-29T20:06:14.6762673Z [Information]: Install VCRedist {isExited = True}{exitCode = 3010}

Here the VCRedist installation is returning exit-code 3010, which usually means (pending reboot) reboot is required to complete the installation, reboot the VM and retry backup operation.

Step 3: Check the VCRedist installation logs (*vcredist*.log files) from customer VM present in path: %appdata%\..\Local\Temp and try performing the below:

Run the below command from the elevated command prompt to set the Reg-key and then trigger the backup operation.

REG ADD "HKLM\SOFTWARE\Microsoft\BcdrAgentPersistentKeys" /v IsVCRedistInstalled /t REG_SZ /d True /f
