问题描述：

编辑设计器的Execute a SQL query的时候报错。

错误代码:“BadRequest”，消息:“Gateway GetPassThroughNativeQueryMetadataAsync - this operation (Execute Native Sql) is currently not supported using an on-prem gateway connection clientRequestId: 2908a941-f53f-4d02-a4d7-4c3ea54cec7b”。 更多诊断信息: x-ms-client-request-id 为“AF971D17-AD26-44AC-87E0-FF18C93954BE”。

问题原因：

使用本地网关连接的 Microsoft Flow 目前不支持“执行 SQL 查询”操作。

已知问题和限制：https://docs.microsoft.com/en-us/connectors/sql/#known-issues-and-limitations
