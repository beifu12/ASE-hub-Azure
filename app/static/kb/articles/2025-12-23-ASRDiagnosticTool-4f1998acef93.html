===============================

Use ASRDiagnosticTool to collect the logs from the Appliance and Windows Source Agents. This tool is available from 9.57 release

Prerequisites

Before using the ASR Diagnostic Tool, ensure the following prerequisites are met:

.NET Framework 4.6.2 is installed on the machine.

Sufficient free space is available on the C:\ drive to store the collected logs.

Below steps(1,2) are applicable only if the ProcessServer version on the appliance is < 9.62

Step 1

Follow the below steps, if ASRDiagnosticTool directory is not found under <CacheDir> on the appliance

Download the ASRDiagnosticTool.zip file from https://aka.ms/ASRDiagnosticTool link

Copy it to the C:\ProgramData\Microsoft Azure\Tools and extract it. Make sure the extracted directory structure is like C:\ProgramData\Microsoft Azure\Tools\ASRDiagnosticTool

Step 2

Follow the below steps, if the CacheDir on the appliance is not the default "E" drive

Open "<ToolDir>:\ASRDiagnosticTool\Config\ApplianceLogs.json" file, search and replace all the instances of "E:\" with "<CacheDir>\"

For example, open "E:\ASRDiagnosticTool\Config\ApplianceLogs.json" file and search and replace all the instances of "E:\" with "M:\". Here "M" is the cache directory on the appliance.

Step 3

Usage

To use the ASR Diagnostic Tool, execute it from the command line, specifying the path to the tool's executable file.

Open command prompt in administration mode

On the appliance

If ProcessServer version >= 9.62

E:\ProgramData\Microsoft Azure\Tools\ASRDiagnosticTool\ASRDiagnosticTool.exe

If ProcessServer version < 9.62

<CacheDir>\ASRDiagnosticTool\ASRDiagnosticTool.exe

On the windows source agent

<AgentInstallDir>\ASRDiagnosticTool\ASRDiagnosticTool.exe

For example:

Appliance :

E:\ASRDiagnosticTool\ASRDiagnosticTool.exe

Windows Source Agent:

C:\Program Files (x86)\Microsoft Azure Site Recovery\agent\ASRDiagnosticTool\ASRDiagnosticTool.exe

SDP Path The logs will be available in the ApplicationData folder, and the full path will be displayed in the application output.

C:\Users\Administrator\AppData\Roaming\ASRDiagnosticLogs-WIN-BQF91C5S04Q-28-11-20-12-34.zip
