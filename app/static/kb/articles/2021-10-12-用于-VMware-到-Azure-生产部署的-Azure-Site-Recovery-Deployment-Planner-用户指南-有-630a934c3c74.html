准备工作：

1、登录到在其中安装了 VMware vSphere PowerCLI 的 VM。

2、请以管理员模式启动 VMware vSphere PowerCLI 控制台

3.确保启用脚本的执行策略。如果已禁用，请以管理员模式启动 VMware vSphere PowerCLI 控制台，并运行以下命令将它启用：

Set-ExecutionPolicy –ExecutionPolicy AllSigned

4、如果系统不将 Connect-VIServer 视为 cmdlet 的名称，则可能需要运行以下命令。

Add-PSSnapin VMware.VimAutomation.Core

5、要获取在 vCenter 服务器/vSphere ESXi 主机上的 VM 的所有名称并将列表存储在 .txt 文件中，请运行下面列出的两个命令。 将 ‹server name›、‹user name›、‹password› 和 ‹outputfile.txt› 替换为输入。

Connect-VIServer -Server <server name> -User <user name> -Password <password>

Get-VM |  Select Name | Sort-Object -Property Name >  “e:\outputfile.txt”

输入完命令后，生产文件：

6、在记事本中打开outputfile文件，另存为 ProfileVMList.txt。 此文件将用作命令行工具的 -VMListFile 参数的输入。

开始分析

创建要分析的 VM 的列表后，可在分析模式下运行该工具。 /？在分析模式下运行该工具所要提供的必需和可选参数列表。
