问题现象 / 场景

  • Azure Data Box POD (also known as Data Box device) is a storage device that customers can rent to transfer terabytes of data into or out of Azure. Each device can store up to 80TB of data for import to or export from Azure. Customers can order a Data Box POD by creating an Azure Data Box resource in the Azure portal, selecting "Data Box" as the product they wish to order, and filling in required information such as shipping address and storage account name.

原始内容清洗稿（保留备查）

Azure Data Box POD (also known as Data Box device) is a storage device that customers can rent to transfer terabytes of data into or out of Azure. Each device can store up to 80TB of data for import to or export from Azure. Customers can order a Data Box POD by creating an Azure Data Box resource in the Azure portal, selecting "Data Box" as the product they wish to order, and filling in required information such as shipping address and storage account name.

An overview of the Data Box device and service can be found at this link: https://docs.microsoft.com/en-us/azure/databox/data-box-overview.
