原始内容清洗稿（保留备查）

近期在处理Sentinel Analytics rule工单时，需要查询对应rule运行结果的具体信息，可以通过如下kusto语句查询：

cluster('securityinsightsmc.chinaeast2.kusto.chinacloudapi.cn').database('SecurityInsightsMooncake').ServiceFabricOperations

| where env_time >= datetime(2024-12-13 00:00) and env_time <= datetime(2024-12-31 23:59)

| where customData has "9d32173d-10d6-4f3e-a98b-9535c4cf0708" //workspace ID

| where customData has "352512e8-50c7-442e-8fd4-1748f4049526" // rule ID

| where operationName contains "ServiceBusJobQueueListener.ProcessMessageAsync"

| project env_time,operationId, operationName,resultType,durationMs,customData
