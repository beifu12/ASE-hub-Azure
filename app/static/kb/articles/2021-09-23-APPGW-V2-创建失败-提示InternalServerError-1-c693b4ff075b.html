问题现象：

用户多次创建v2的应用程序网关报错，为InternalServerError

报错内容：

{ "id": "/subscriptions/f09aa8b1-0c1b-4608-8af1-58e06b882a36/resourceGroups/UC-UAT/providers/Microsoft.Resources/deployments/Microsoft.ApplicationGateway-20191106225440/operations/41E33C3B71EF15A8", "operationId": "41E33C3B71EF15A8", "properties": { "provisioningOperation": "Create", "provisioningState": "Failed", "timestamp": "2019-11-06T15:13:07.0159718Z", "duration": "PT14M34.0912204S", "trackingId": "8dabe15f-d41b-4a51-9775-f90696acad72", "statusCode": "Conflict", "statusMessage": { "status": "Failed", "error": { "code": "ResourceDeploymentFailure", "message": "资源操作完成时的终端预配状态为“Failed”。", "details": [ { "code": "InternalServerError", "message": "发生错误。", "details": [] } ] } }, "targetResource": { "id": "/subscriptions/f09aa8b1-0c1b-4608-8af1-58e06b882a36/resourceGroups/UC-UAT/providers/Microsoft.Network/applicationGateways/uc-paas-agw-uat", "resourceType": "Microsoft.Network/applicationGateways", "resourceName": "uc-paas-agw-uat" } }}

问题原因：

根据排查最终用户应用程序网关部署虚拟网络VNET-bmwFGProd-116设置自定义DNS服务器10.6.156.4, 10.6.156.5，DNS服务器位于本地数据中心，通过ExpressRoute线路通信。

解决方案：

SKU V2应用程序网关在创建过程中需要通过"nfvmcmainbjs.blob.core.chinacloudapi.cn"下载网关实例镜像文件，查询创建失败日志，域名"nfvmcmainbjs.blob.core.chinacloudapi.cn"解析失败导致创建超时失败。建议在本地DNS服务器中增加配置（例如配置递归查询），使DNS服务器可以成功解析域名"nfvmcmainbjs.blob.core.chinacloudapi.cn"。
