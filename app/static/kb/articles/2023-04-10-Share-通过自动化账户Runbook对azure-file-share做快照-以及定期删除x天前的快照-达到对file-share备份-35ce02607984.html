问题描述：

=======

如何实现Azure File  SMB存储，通过runbook自动化创建和删除快照

解决方案*：

==============

1，对Azure file创建快照，请参考如下Powershell 脚本命令：

###请将黄色标黄部分替换为您的实际资源值，其中“jiaxiaolei”为automation account credential.

+++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++

$Cred = Get-AutomationPSCredential -Name "jiaxiaolei";

Add-AzAccount -Credential $Cred -EnvironmentName AzureChinaCloud;

Select-AzSubscription -SubscriptionId "5e3124ff-22ad-4638-9c1c-645aa97017d1"

$resourceGroup = "leoVaultNorth2"

$storageAccountName = "leocentos7diag"

$storageAccount = Get-AzStorageAccount -ResourceGroupName $resourceGroup -Name $storageAccountName

$ctx = $storageAccount.Context

$shareName = "testprice"

$share = Get-AzStorageShare -Context $ctx -Name $shareName

$snapshot = $share.CloudFileShare.Snapshot()

2，删除N天前的Azure file快照，请参考如下Powershell 脚本命令：

+++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++

Select-AzSubscription -SubscriptionId "xxxxxx"

Generate Snapshot List

$SnapshotList = Get-AzStorageShare -Context $ctx | Where-Object {$_.Name -eq $ShareName -and $_.IsSnapshot -eq $true -and $_.SnapshotTime -lt ([datetime]::UtcNow.AddDays(-4))}

Delete Snapshots older than 4 days

foreach ($Snapshot in $SnapshotList)

{

Remove-AzStorageShare -Share $Snapshot.CloudFileShare -Verbose -Force

}
