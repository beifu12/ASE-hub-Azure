Here is another way that you need to upgrade the AKS to 1.30 and take a taint for the nodepool.

Use node taints in an Azure Kubernetes Service (AKS) cluster - Azure Kubernetes Service | Azure Docs

az aks nodepool add

--resource-group $RESOURCE_GROUP_NAME

--cluster-name $CLUSTER_NAME

--name $NODE_POOL_NAME

--node-count 1

--node-taints "disk.csi.azure.com/agent-not-ready:NoExecute"

--no-wait

User startup taint removal feature :when CSI driver is started up from aks 1.30, it will remove the taint disk.csi.azure.com/agent-not-ready:NoExecute
