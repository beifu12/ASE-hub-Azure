  • Copy the Appliance key from the newly created Recovery Services Vault

If Appliance configuration fails with below error, please follow the below mentioned remediation steps:

Error Message

{"ScenarioName":"Configuration","OperationName":"RegisterVMwareAppliance","Result":"Error","ErrorCode":60214,"ErrorCodeName":"VmwareSiteCreationTemplateDeploymentFailed","Message":"VMware site creation has failed. \n\r\nUnable to create resource "vmwaresite" of type "Microsoft.OffAzure/VMwareSites" required to start discovery. \n\r\nStatusCode: "BadRequest" \n\r\nDetails: "Deployment ErrorCode: ConflictingSpnDetails Error Message: The given spn details do not match the details already present for this site.

Possible Causes

This can happen if the appliance configuration fails in-between and Vmware/Physical site got created by that time and before retrying configuration, if the customer deletes the AAD apps then we try to update the Vmware/Physical site with new AAD app details resulting in conflicting SPN details.

Remediation Steps

Please create a new Recovery Services Vault

Cleanup the browser cache in the appliance

Copy the Appliance key from the newly created Recovery Services Vault

Proceed with Appliance configuration with the copied Appliance key
