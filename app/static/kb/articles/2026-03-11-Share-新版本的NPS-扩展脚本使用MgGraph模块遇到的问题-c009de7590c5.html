新版本NPS扩展安装后，里面的脚本使用的模块已经更新为MgGraph，由于大家所知的原因，当前MgGraph模块当前在Azure China不能直接使用用户名密码认证登录，因此需要做些更改。大家遇到相同问题，可参考此工单步骤：SR_20241224331594_NPS Server - User unable to get Azure AD access token

+++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++

0, Create a certificate from your Windows client, you can custom define the below variable in yellow:

$certname = "leograph03"

$cert = New-SelfSignedCertificate -Subject "CN=$certname" -CertStoreLocation "Cert:\CurrentUser\My" -KeyExportPolicy Exportable -KeySpec Signature -KeyLength 2048 -KeyAlgorithm RSA -HashAlgorithm SHA256

Export-Certificate -Cert $cert -FilePath "C:\Users\leo\Desktop\cert\$certname.cer"

$mypwd = ConvertTo-SecureString -String "qwexxxxx" -Force -AsPlainText

Export-PfxCertificate -Cert $cert -FilePath "C:\Users\leo\Desktop\cert\$certname.pfx" -Password $mypwd

1, Login Azure portal and register a  new Microsoft Entra ID application, such as Test_microsoft_graph, and then upload the above xxx.cer certificate to the application.
