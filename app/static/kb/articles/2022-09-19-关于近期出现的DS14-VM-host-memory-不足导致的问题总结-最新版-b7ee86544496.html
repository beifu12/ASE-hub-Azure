系统日志记录有针对数据盘的I/O读写错误

虚拟机重启后症状消失

定位问题

虚拟机及平台其他指标在问题发生时间段无异常

Findings部分记录Host内存不足

Events部分记录Event 2，Error Code为C0000017，表示STATUS_NO_MEMORY。在记录Event 2的相同时间，虚拟机系统日志开始记录I/O相关的报错（如以上症状部分的示例）

备注：如果再Findings部分没有记录，但是在timeline看到event2,可以F12看error code c0000017

缓解措施

Portal发起对虚拟机的重新部署使虚拟机迁移至一个健康节点，可以暂时缓解此问题。在这个过程中如果其他节点由于内存不足导致DS14虚拟机长时间无法开启，在得到客户同意后请联系WASU对虚拟机触发Service Healing使虚拟机迁移至健康节点（请告知WASU这个操作是经过产品组确认的并且得到了Azure CXP的预授权）。
