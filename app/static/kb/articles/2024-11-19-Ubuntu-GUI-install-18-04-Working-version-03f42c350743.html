2018/10/11

之前有TSG教我们怎么用Ubuntu 18.04 GUI. 但是，那个GUI太慢。

这个TSG安装更好的GUI。

1. 首先创建一台Ubuntu 18.04的虚拟机.

创建完成后使用你的ssh app (Xshell, putty, etc.) 登陆虚拟机，依次执行下面的命令（高亮部分）

2. 安装ubuntuDesktop: sudo apt-get install ubuntu-desktop -y

3. 下载这个脚本：wget https://azuresupport.blob.core.chinacloudapi.cn/tools/Std-Xrdp-Install-0.2.zip

4. 安装unzip：sudo apt install unzip

5. 解压脚本：unzip Std-Xrdp-Install-0.2.zip

6. 添加可执行权限: chmod +x Std-Xrdp-Install-0.2.sh

7. 运行脚本: ./Std-Xrdp-Install-0.2.sh

8. ARM下的虚拟机如果配置了NSG，则需要添加NSG 3389的入站规则，如果是经典虚拟机，则需要为虚拟机添加remote desktop（3389）终结点。

9. 完成后我们可以用mstsc直接用Public IP进行连接

10. 登陆后输入用户名密码:

11. 好了。
