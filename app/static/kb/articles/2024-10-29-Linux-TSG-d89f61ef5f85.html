Linux TSG

Endorsed Distributions are versions of Linux who Microsoft has partnered with a vendor to make available in Azure.

Here is the list: http://azure.microsoft.com/en-us/documentation/articles/virtual-machines-linux-endorsed-distributions/.

Each endorsed distribution, when the VM is spun up, has a stamp on the hard drive that indicates the vendor.

You can see this stamp or tag in our tooling.

How do I tell if this version of Linux is an endorsed distribution?

You need to use the BillingContext tag and look for the vendor name.

Example: Linux_IaaS_SUSE. If the vendor name (Open Logic, Canonical, Oracle) is listed, then it is an Endorsed Distribution.

In ACIS:

Get the DeploymentID for the deployment that contains the VM in question. This is available in Azure Portal.

Navigate to ACIS.

Select Group: Deployment Management and Operation: Get Deployment by Deployment ID (TSQ).

Enter the Deployment ID from step #1.

Find the appropriate RoleInstance you are investigating.

Find the setting for BillingContext for the role instance. Use FIND and search for "Linux."

Note the Billing Context will be in one of two forms:  <BillingContext>BillingContext> | <VMSize>

When you find that BillingContext.

In MDS:

The BillingContext is part of UsageResouceKind. Look for the tag: BillingContext=Windows_IaaS

In FCClient:

BillingContext is in GetTenantDeploymentProgress. Look for the tag: BillingContext=Windows_IaaS

Check with Patrick the various billing tags for Premium images
