最终定位到您的存储账户在之前有一个关联资源，“用户分配类型的托管标识”被删除。

该资源缺失，导致存储账户丢失部分依赖资源，但是关联依然存在，所以会导致此问题发生，和迁移无关。

一、检查命令

$storage = Get-AzStorageAccount -ResourceGroupName "资源组名称" -Name "存储账户名称"

if ($null -eq $storage.Identity -or $storage.Identity.Type -eq "None") {

Write-Host "此存储账户未启用托管身份"

} else {

Write-Host "已启用托管身份，类型: $($storage.Identity.Type)"

}

二、用户分配的托管标识与关联命令

首先获取用户分配的标识ID

$userAssignedIdentity = Get-AzUserAssignedIdentity -ResourceGroupName "Your-Identity-RG" -Name "Your-User-Assigned-Identity"

设置存储账户使用该用户分配标识

Set-AzStorageAccount -ResourceGroupName "Henry-Infra" -Name "watsai" `

-AssignIdentity `

-IdentityType UserAssigned `

-UserAssignedIdentityId $userAssignedIdentity.Id

三、清空托管标识identity：

Set-AzStorageAccount -ResourceGroupName "资源组名称" -Name "存储账户名称" -Identity "None"
