原始内容清洗稿（保留备查）

On August 31, 2022, all 1.x versions of Azure AD Connect will be retired because they include SQL Server 2012 components that will no longer be supported. Our customers need upgrade to the most recent version of Azure AD Connect (2.x version) by that date .

If our customers run a retired version of Azure AD Connect, it might not function as expected. They also might not have the latest security fixes, performance improvements, troubleshooting and diagnostic tools, and service enhancements. If they require support, we will not be able to provide them with the level of service their organization needs.

You can upgrade your Azure AD Connect server from all supported versions with the latest versions:

https://docs.microsoft.com/en-us/azure/active-directory/hybrid/whatis-azure-ad-connect-v2

https://docs.microsoft.com/en-us/azure/active-directory/hybrid/reference-connect-version-history#20280

Please also be noted that AAD Connect v2 are not supported to install on Windows server 2008r2/2012/2012r2. This means customer must upgrade Windows server before upgrading AAD Connect in place or build new Windows server directly.

If customer chooses to install a new AAD Connect, you may refer to the following docs to assist customer on the new AAD Connect setup:

https://docs.microsoft.com/en-us/azure/active-directory/hybrid/how-to-connect-import-export-config
