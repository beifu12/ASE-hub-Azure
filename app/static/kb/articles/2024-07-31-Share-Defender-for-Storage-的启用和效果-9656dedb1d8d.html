Hi All:

产品组已经确认当前Defender for Storage (经典版)在中国区已经可用，但需要通过Azure Powershell 或Azure CLI 来启用，但是在门户（无论是Defender For Cloud 下还是在存储账户下）都看不到对应的选项。就如何开启以及开启后的效果，请参考如下：

参考工单：SR_20240712304312_Defender for Storage 中国区北3可以用吗？如果可以，如何开启？以及相关费用

关于如何启用请参考Global Azure 官方文档  https://learn.microsoft.com/zh-cn/azure/defender-for-cloud/defender-for-storage-classic-enable 。

关于如何验证Defender For Cloud 经典版的效果，请参考如下：

根据Global Azure 官方文档，Defender for Storage（经典版）会不断分析 Azure Blob 存储、Azure 文件存储和 Azure Data Lake Storage 服务生成的数据流。 当检测到潜在的恶意活动时，将生成安全警报。

截图来源：Global Azure 官方文档 https://learn.microsoft.com/zh-cn/azure/defender-for-cloud/defender-for-storage-classic

测试可以通过MicroBurst 对特定的存储账户名称进行blob-hunting 攻击，可以捕获到攻击字典中的公共访问级别是容器下的Blob。

注：请将测试存储账户的TLS最低版本调整为1.0，否则无法成功捕获blob。

参考文档： https://techcommunity.microsoft.com/t5/microsoft-defender-for-cloud/protect-your-storage-resources-against-blob-hunting/ba-p/3735238
