Multiple Nginx Ingress Controller in AKS Cluster

需求： 在一个AKS中部署的应用程序（Application）分别通过Internal和External Nginx Ingress暴露出去，配置方法如下：

分别创建两个Nginx Ingress Controller，一个External Nginx Ingress(使用Azure External LB)；一个Internal Nginx Ingress（使用Azure Internal LB）。部署脚本参考如下，注意给这2个Controller设置不同的ingressClassName和controllerValue，并分别放置在不同的namespace: 没有限定Nginx ingress controller所watch的namespace，但因为两者的classname、controllervalue不同，它会识别出来不是自己的配置变更会ignore掉不会冲突，如只是classname不同，controllervaule不指定，也没有限定watch的namespace，则会冲突，Ingress所获取IP会变来变去:

REGISTRY_NAME=testaksacr

SOURCE_REGISTRY=k8sgcr.azk8s.cn

CONTROLLER_IMAGE=ingress-nginx/controller

CONTROLLER_TAG=v1.2.1

PATCH_IMAGE=ingress-nginx/kube-webhook-certgen

PATCH_TAG=v1.1.1

DEFAULTBACKEND_IMAGE=defaultbackend-amd64

DEFAULTBACKEND_TAG=1.5

#az acr import --name $REGISTRY_NAME --source $SOURCE_REGISTRY/$DEFAULTBACKEND_IMAGE:$DEFAULTBACKEND_TAG --image $DEFAULTBACKEND_IMAGE:$DEFAULTBACKEND_TAG

Add the ingress-nginx repository

#helm repo add ingress-nginx https://kubernetes.github.io/ingress-nginx

Set variable for ACR location to use for pulling images

ACR_URL=testaksacr.azurecr.cn

Use Helm to deploy an NGINX ingress controller

Install nginx ingress controller for external traffic

helm install nginx-ingress-external ingress-nginx/ingress-nginx \

--version 4.1.3 \

--namespace ingress-external \

--create-namespace \

--set controller.ingressClassResource.name=nginx-external \

--set controller.ingressClassResource.controllerValue="k8s.io/external-ingress-nginx" \

--set controller.replicaCount=1 \

--set controller.nodeSelector."kubernetes\.io/os"=linux \

--set controller.image.registry=$ACR_URL \

--set controller.image.image=$CONTROLLER_IMAGE \

--set controller.image.tag=$CONTROLLER_TAG \

--set controller.image.digest="" \

--set controller.image.repository=$SOURCE_REGISTRY/$CONTROLLER_IMAGE \

--set controller.admissionWebhooks.patch.nodeSelector."kubernetes\.io/os"=linux \

--set controller.service.annotations."service\.beta\.kubernetes\.io/azure-load-balancer-health-probe-request-path"=/healthz \

--set controller.admissionWebhooks.patch.image.registry=$ACR_URL \

--set controller.admissionWebhooks.patch.image.image=$PATCH_IMAGE \

--set controller.admissionWebhooks.patch.image.tag=$PATCH_TAG \

--set controller.admissionWebhooks.patch.image.digest="" \

--set defaultBackend.nodeSelector."kubernetes\.io/os"=linux \

--set defaultBackend.image.registry=$ACR_URL \

--set defaultBackend.image.image=$DEFAULTBACKEND_IMAGE \

--set defaultBackend.image.tag=$DEFAULTBACKEND_TAG \

--set defaultBackend.image.repository=$SOURCE_REGISTRY/$DEFAULTBACKEND_IMAGE \

--set defaultBackend.image.digest=""

Install nginx ingress controller for internal traffic

helm install nginx-ingress-internal ingress-nginx/ingress-nginx \

--namespace ingress-internal \

--set controller.ingressClassResource.name=nginx-internal \

--set controller.ingressClassResource.controllerValue="k8s.io/internal-ingress-nginx" \

--set defaultBackend.image.digest="" \

-f internal-ingress.yaml
