Linux 计算机的威胁防护

安全中心通过使用适用于 Linux 的 Log Analytics 代理，收集和扩充 auditd 记录，auditd 位于主线内核中。并将其聚合到事件中。 安全中心会持续对使用云和本地 Linux 计算机上的恶意行为的分析。 这些活动可能表明计算机正在受到攻击或已被破坏。

有关 Linux 警报的列表，请参阅警报引用表。

https://docs.azure.cn/zh-cn/security-center/alerts-reference#alerts-linux

本次验证如下安全攻击检测项目：

详细可以通过下载 Azure 安全中心 Playbook：Linux 检测来模拟 Linux 警报。

以下是模拟操作：首先需要建立2台测试VM

• VM1: Kali Linux 由于模拟暴力破解SSH

• VM2: 使用Ubuntu 16.04 LTS 模拟被攻击的肉机 (有关支持的版本参考：https://docs.microsoft.com/en-us/azure/security-center/security-center-os-coverage).

VM2 设置使用密码验证SSH登陆，需要配置好Security Center agent 以及公共IP地址，同时建立五个用户用于测试。

2台虚拟机均可以SSH访问，实际使用中建议使用安全中心的建议使用JIT功能减少SSH暴力破解的可能性。
