2025/12/01

作为知名的服务网格产品，istio具有强大的流量管理功能，而Istio addon具有和原生istio类似的功能，istio也支持支持原生K8S Gateway API发布流量。

Kubernetes Gateway API Ingress for Istio Service Mesh Add-on for Azure Kubernetes Service (AKS) (preview) - Azure Kubernetes Service | Microsoft Learn

1、安装istio addon

(1) 添加Az AKS extension ,并查看istio mesh add-on版本

az extension add --name aks-preview

az extension update --name aks-preview

az aks mesh get-revisions --location <location> -o table

#这里使用CN3区域示例.注意addon与AKS版本的对应关系

(2) 安装Istio addon

az aks mesh enable -g aks-20251117 -n aks20251117-2 --revision asm-1-26

az aks show -g aks-20251117 -n aks20251117-2 --query 'serviceMeshProfile.mode'

确保安装成功

确认Istio Pod能正常运行

kubectl get pods -n aks-istio-system

2，安装Managed Gateway Api CRDs

az feature register --namespace "Microsoft.ContainerService" --name "ManagedGatewayAPIPreview"

az aks update -g aks-20251117 -n aks20251117-2 --enable-gateway-api

确认crds安装成功：

kubectl get crds | grep "gateway.networking.k8s.io"

3、使用基于Istio addon 的K8S gateway API 发布服务

(1) 安装后端服务，default namespace 中安装httpbin服务

kubectl apply -f https://raw.githubusercontent.com/istio/istio/release-1.26/samples/httpbin/httpbin.yaml

（docker.io的镜像在国内可能不能访问，如不能访问，建议要将docker.io的镜像导入到自己的ACR）

(2)使用K8S Gateway API 发布服务

apiVersion: gateway.networking.k8s.io/v1

kind: Gateway

metadata:

name: httpbin-gateway

spec:

gatewayClassName: istio

listeners:

  • name: http

port: 80

protocol: HTTP

allowedRoutes:

namespaces:

from: Same

---

kind: HTTPRoute

name: http

namespace: default

parentRefs:

  • name: httpbin-gateway

hostnames: ["fuzlgatewayapi.azurecn.cn"]

rules:

  • matches:
  • path:

type: PathPrefix

value: /get

backendRefs:

  • name: httpbin

port: 8000

（3）确认可以接入流量

kubectl get service httpbin-gateway-istio

#查看对外发布的external service IP

或者从门户查看对外的LB service

然后做好DNS解析，测试访问

http://fuzlgatewayapi.azurecn.cn/get
