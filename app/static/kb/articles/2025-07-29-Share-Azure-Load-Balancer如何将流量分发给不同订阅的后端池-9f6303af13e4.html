问题描述：

=======

如果负载均衡器和后端池不在一个订阅下，如何实现后端池被负载均衡器负载呢？

系统环境/应用程序信息：

===============

Azure Load Balancer

解决方案*：

==============

Azure Load Balancer只有在创建了不为空的后端池之后才具备VNet属性，且同一Load Balancer如果它有多个后端池，这些后端池必须属于同一VNet。

经测试当前要实现Load Balancer与后端池分别属于不同的订阅，推荐使用Azure CLI工具进行创建。如下指令供您参考：

先az login 登录Azure，然后选择Subscription B，在Subscription B中创建一Load Balancer:

Create a resource group in Azure Subscription B

az group create --name 'tianResourceGroupLB' --location chinanorth3

Create a load balancer

az network lb create --resource-group tianResourceGroupLB --name tianLoadBalancer --sku Standard --public-ip-address tianPublicIP   --frontend-ip-name myFrontEnd --backend-pool-name BackendPool1 --tags 'IsRemoteFrontend=true'
