使用 SAML2.0 标识提供者 （IdP） 进行单一登录

https://docs.azure.cn/zh-cn/entra/identity/hybrid/connect/how-to-connect-fed-saml-idp

首先确认如下3步是否成功完成：

1. Register Azure Entra ID as a service provider (SP) with the IdP of your organization. Use the SAML metadata https://nexus.partner.microsoftonline-p.cn/federationmetadata/saml20/federationmetadata.xml

It is recommended that you always import the latest Microsoft Entra metadata when configuring your SAML 2.0 identity provider. （Microsoft Entra ID does not read metadata from the identity provider.）

2.Set up a trust between your SAML identity provider and Microsoft Entra ID

$BrandName = "Sample SAML 2.0 IDP"

$LogOnUrl = "https://WS2012R2-0.contoso.com/passiveLogon"

$LogOffUrl = "https://WS2012R2-0.contoso.com/passiveLogOff"

$ecpUrl = "https://WS2012R2-0.contoso.com/PAOS"

$MyURI = "urn:uri:MySamlp2IDP"
