Lately we are seeing some cases with Windows 2012R2 and Windows 2016 images where customers are getting errors when trying to install the Az PowerShell module such as:

WARNING: Unable to download from URI 'https://go.microsoft.com/fwlink/?LinkID=627338&clcid=0x409' to ''.

'NuGet'. The package provider requires 'PackageManagement' and 'Provider' tags. Please check if the specified package

has the tags.

It appears on these images TLS1.2 is disabled by default but is required.  In these cases there is a simple workaround to force TLS1.2 on the session.

In admin PowerShell, run the following to check if TLS 1.2 is enabled:

PS C:\Users\javan> [Net.ServicePointManager]::SecurityProtocol

Ssl3, Tls

The example above shows that only TLS v1.0 (no version) is enabled.

We can force TLS 1.2 with the following:

PS C:\Users\javan> [Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12

PS C:\Users\javan>

Then check again to confirm TLS 1.2:

Tls12

After this the Az module should install successfully.
