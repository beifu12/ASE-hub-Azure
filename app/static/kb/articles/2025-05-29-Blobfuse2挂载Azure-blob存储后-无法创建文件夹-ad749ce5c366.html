##问题描述：

客户通过Blobfuse2挂载Azure Blob存储后，挂载没有报错，但是创建文件夹时，提示No such file or directory

$ cd /mnt_blob

$ mkdir 123

$ mkdir: cannot create directory ‘123’: No such file or directory

##问题排查：

排查发现，客户的存储账号启用了NFSv3，因此开启了分层存储。

官方文档在blobfuse v1中提到了如果是ADLS account需要添加option --use-adls=true

https://learn.microsoft.com/en-us/azure/storage/blobs/storage-how-to-mount-container-linux?tabs=RHEL#mount

测试添加这个选项后，问题解决。

blobbfuse2 mount /mnt_blob --config-file=/etc/blobfuse2.yaml --use-adls=true
