一句话摘要

To create a Data Box order, customers must have an Azure subscription of the type MCA (Microsoft Customer Agreement), EA (Enterprise Agreement), CSP (Cloud Solution Provider), MPN (Microsoft Partner Network), or Microsoft Azure Sponsorship.

问题现象 / 场景

  • To create a Data Box order, customers must have an Azure subscription of the type MCA (Microsoft Customer Agreement), EA (Enterprise Agreement), CSP (Cloud Solution Provider), MPN (Microsoft Partner Network), or Microsoft Azure Sponsorship.

背景信息

  • Order Azure Data Box for Import

  • Microsoft Stream

排查思路

  • In most cases the customer will want to create a Data Box order through the Azure portal. To do this, they will sign into the Azure portal, select "Create a resource", search for "Azure Data Box", and then click "Create". The customer can then select either the "Import to Azure" or "Export from Azure" transfer type, choose the type of device to order (Data Box device, Data Box Heavy, or Data Box Disk), and set other options such as Azure subscription, resource group, and the storage account(s) to import data to or export data from. The customer can either choose to use the default security settings for Data Box, or they can choose to set up their own encryption keys and passwords. After the customer enters their shipping address and submits the order, they will be able to track the order status through the Azure portal. If they need to cancel an order, they can do so as long as the order has not yet reached the "Processed" status.
  • Further information on ordering Data Box devices through the Azure portal can be found at the links below.

操作步骤 / 命令

  • It is also possible to order Data Box devices and track order status using the Azure CLI or Azure PowerShell. Some customers who have a need to create large numbers of Data Box orders may choose to use one of these methods so that they can manage the ordering process using scripts instead of the Azure portal UI. For more information on ordering a Data Box using the Azure CLI, please see this link: Order Data Box for Import - Azure CLI.
