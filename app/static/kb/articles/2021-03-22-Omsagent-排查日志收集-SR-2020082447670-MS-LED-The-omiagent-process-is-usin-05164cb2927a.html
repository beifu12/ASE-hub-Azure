SR_2020082447670_[MS-LED]The omiagent process is using 100% cpu.

通过排查日志，发现您虚拟机中的omsagent有问题。

Syslog中有很多找不到omi相关文件的报错，已经服务stop的报错：

建议您将omsagent重新安装一下：

具体步骤如下：

1）从相关虚拟机上依次卸载omsagentforlinux和linuxDiagnostic扩展。

2）ssh到相关虚拟机，通过以下的命令清除omsagent安装包和相关。

for CentOS Linux, Oracle Linux, RHEL, SLES

sudo rpm -e omsconfig omsagent scx omi

sudo rm -f /etc/opt/microsoft/omsagent/conf/omsagent.conf

Debian, Ubuntu

sudo dpkg -P omsconfig omsagent scx omi

3）重新连接虚拟机到log analytics workspace。
