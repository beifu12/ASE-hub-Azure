最开始学习做测试时会有时候规划IP会进到虚拟机修改接口IP，但实际这种操作是不可以的。修改IP还是要在门户网络接口处修改，由Cloud-Init等组件去操作修改。

今天协助同事解决工单20240806308388问题时发现了更好的实现方案，无需重置NIC。如何为Azure Windows VM 重置网络接口- Virtual Machines | Microsoft Learn

问题现象：

方法总结：使用串行控制台，进入SAC后进入CMD，使用netsh命令重新修改接口为DHCP

1、SAC>cmd

2、SAC>ch -si 1

回车进入认证（域部分根据实际情况，无则回车）

3、查看当前IP信息：ipconfig /all

4、查看接口：netsh interface show interface

5、设置接口为DHCP自动获取：netsh interface ip set address name="Ethernet" source=dhcp

6、查看当前获取接口的的详细IP信息：ipconfig /all

修改完成，正常RDP链接。

备注：

使用运行命令功能，直接敲命令修改接口为DHCP，实际测试无法运行， 考虑到此功能依托于网络。网络不通则无法使用。
