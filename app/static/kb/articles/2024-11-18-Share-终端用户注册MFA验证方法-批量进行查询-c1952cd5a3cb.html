问题描述：

=======

终端用户如何自主注册MFA

解决方案*：

==============

当前Azure China还不支持终端用户自主启用MFA. 您可建议终端用户可以通过下方连接使用O365账号登录后，提前添加用于MFA认证的登录方式：

https://account.activedirectory.windowsazure.cn/proofup.aspx?proofup=1

通过下方Powershell脚本命令导出的结果报告中可看到用户具体注册的MFA方法。

++++++++++++++++++++++++++++++++++++++++++++++++++

Install-Module MSOnline -Force

Connect-MsolService -AzureEnvironment AzureChinaCloud

$Users = Get-MsolUser

foreach ( $user in $Users ) {

$StrongMethods = $user.StrongAuthenticationMethods.MethodType

foreach($Method in $StrongMethods) { $user.UserPrincipalName + "  :  "+ $Method }

}
