下载并解压缩 AzFilesHybrid zip文件，运行 .\CopyToPSPath.ps1 并导入文件中模块

Import-Module -Name AzFilesHybrid

PowerShell登录Azure(须具有存储帐户所有者或参与者 Azure 角色权限。)

设置存储账号名称以及存储账号所在资源组。执行命令将存储服务加入到本地DS

#Define parameters

$ResourceGroupName = "zhangwx"

$StorageAccountName = "zhangsa"

Register the target storage account with your active directory environment

Join-AzStorageAccountForAuth `

-ResourceGroupName $ResourceGroupName `

-StorageAccountName $StorageAccountName `

-DomainAccountType "ComputerAccount"

加入后可以在计算机中看到该设备

登录Portal查看存储账号，在设置中验证已经启用本地目录的Identity-based验证

接下来为文件共享设置角色，该角色根据命令提示有三种

Storage File Data SMB Share Reader,

Storage File Data SMB Share Contributor,

Storage File Data SMB Share Elevated Contributor

使用的用户为本地的用户且同步到AAD。

使用设置权限的账户登录本地成员机，验证端口后，即可成功挂载（注意不要使用管理员运行命令窗口）

验证使用没有设置权限的账号登录则直接报错。
