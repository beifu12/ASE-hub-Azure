参考工单：SR_20241025321771_Does 21Vianet MS Entra Connect support MS Entra Kerberos deployment?

部署Microsoft Entra Kerberos

部署 Entra ID Connect https://learn.microsoft.com/zh-cn/entra/identity/hybrid/connect/how-to-connect-install-roadmap

安装 AzureADHybridAuthenticationManagement 模块：

https://learn.microsoft.com/zh-cn/entra/identity/authentication/howto-authentication-passwordless-security-key-on-premises#install-the-azureadhybridauthenticationmanagement-module

[Net.ServicePointManager]::SecurityProtocol = [Net.ServicePointManager]::SecurityProtocol -bor [Net.SecurityProtocolType]::Tls12

Install-Module -Name AzureADHybridAuthenticationManagement -AllowClobber

创建Kerberos服务器对象

运行以下 PowerShell 命令以同时在本地 Active Directory 域和 Microsoft Entra 租户中创建新的 Microsoft Entra Kerberos 服务器对象。

获取可用云的列表 Get-AzureADKerberosServerEndpoint ， 默认为China，无需修改。

Specify the on-premises Active Directory domain. A new Microsoft Entra ID Kerberos Server object will be created in this Active Directory domain.

$domain = $env:USERDNSDOMAIN

Enter an Azure Active Directory Global Administrator username and password.

$cloudCred = Get-Credential -Message 'An Azure Active Directory user who is a member of the Global Administrators group for Microsoft Entra ID.'

Enter a Domain Administrator username and password.

$domainCred = Get-Credential -Message 'An Active Directory user who is a member of the Domain Admins group.'

Create the new Microsoft Entra ID Kerberos Server object in Active Directory and then publish it to Azure Active Directory.

Set-AzureADKerberosServer -Domain $domain -CloudCredential $cloudCred -DomainCredential $domainCred

查看并验证 Microsoft Entra Kerberos服务器

Get-AzureADKerberosServer -Domain $domain -UserPrincipalName admin@xxxxx.partner.onmschina.cn
