Cisco ASA防火墙VPN对接Azure实例

ASA:

型号5525

软件版本：v9.8(2) **不能低于V9.8

配置方式：IPSEC VTI

Azure:

环境：官方默认

配置方式：基于路由模式(routeBased)

ASA配置示例：

P1

crypto ikev2 policy 10

encryption aes-256

integrity sha

group 2

prf sha

lifetime seconds 86400

crypto ikev2 enable outside

P2

crypto ipsec ikev2 ipsec-proposal AES-256

protocol esp encryption aes-256

protocol esp integrity sha-1

!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!

crypto ipsec profile PROFILE1 //PROFILE1为自定义名称，在后面tunnel中调用

set ikev2 ipsec-proposal AES-256 //此处调用上面定义的AES-256

!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!

interface Tunnel 10 //创建虚拟隧道接口

nameif primary_vti

ip address 169.254.0.10 255.255.255.0 //接口地址**此处烦请标注下在Azure中的名称或者表达方式

tunnel source interface outside //应用在外部接口

tunnel destination 42.159.205.xx //Azure VPN网关地址

tunnel mode ipsec ipv4

tunnel protection ipsec profile PROFILE1 //此处调用上方定义PROFILE1

!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!

tunnel-group 42.159.205.xx type ipsec-l2l //VPN形式

tunnel-group 42.159.205.xx ipsec-attributes //VPN属性

ikev2 remote-authentication pre-shared-key p@ssw0rd //预共享秘钥

ikev2 local-authentication pre-shared-key p@ssw0rd

route vti <remote-subnet> <remote-mask> <ip-address-on-the-remote-tunnel-interface> //路由配置方式

示例：

route primary_vti 192.168.100.0 255.255.255.0 169.254.0.1 1 //下一跳地址与tunnel中配置的接口地址相对应,如有多个网段，需写多条

*****无需做免NAT配置
