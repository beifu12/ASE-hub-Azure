2023-01-12

NVIDIA Tesla GPU 在 Windows 环境下可以配置为 Tesla 计算集群（Tesla Compute Cluster，简称 TCC）模式或 Windows 显示驱动模型（Windows Display Driver Model，简称 WDDM）模式。

两种模式有不同适用场景。

TCC：该模式下，GPU 完全用于计算，不能作为本地显示输出。

WDDM：该模式下，GPU 既用于计算又用于本地显示输出。

切换至 WDDM 模式命令：nvidia-smi -dm 0

切换至 TCC 模式命令：nvidia-smi -dm 1

在任务管理器的性能标签中显示GPU，需要切换到WDDM模式。

官方文档中提供是Tesla原生驱动，只支持TCC模式。

官方文档https://docs.azure.cn/zh-cn/virtual-machines/windows/n-series-driver-setup

驱动程序https://us.download.nvidia.com/tesla/451.82/451.82-tesla-desktop-winserver-2019-2016-international.exe

我们尝试运行命令nvidia-smi -dm 0切换到WDDM模式，可以看到是不支持的。

经查找资料，需要安装NVIDIA GRID vGPU驱动才能支持WDDM模式。

您可以安装下以下文档中的grid系列的驱动。

https://github.com/Azure/azhpc-extensions/blob/master/NvidiaGPU/resources.json

比如https://download.microsoft.com/download/2/a/3/2a316e62-3be9-4ddb-ae8e-c04b6df6e22d/441.66_grid_win10_server2016_server2019_64bit_international.exe

我这里测试下来是OK的。我测试的是Win10和Windows Server 2019。

相关截图如下：

驱动安装成功：

安装成功后，使用nvidia-smi命令，可以看到已经是WDDM模式了。

切换到TCC，也是可以的，需要重启生效。

在WDDM模式下，可以看到任务管理器的性能标签中是有GPU的。

Win10的进程标签里面也是可以看到GPU和GPU engine的情况的。注:我在Windows Server 2019中的进程标签里面没有看到GPU和GPU engine，应该是兼容性的问题。
