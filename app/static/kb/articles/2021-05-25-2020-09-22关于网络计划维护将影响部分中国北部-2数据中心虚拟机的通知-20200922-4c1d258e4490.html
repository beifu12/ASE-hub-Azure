[English Version]

Scheduled network maintenance may affect one or more of your virtual machines in China North 2

Dear Azure customer,

You're receiving this notice because you currently use Azure Virtual Machines.

An upcoming maintenance update will affect virtual machines (VMs) in China North 2, from 11 October 2020 16:00 CST until 17 October 2020 14:00 CST. During this planned maintenance window, IaaS virtual machines will be migrated to newer network hardware. Please expect each VM to be unavailable for up to 15 minutes after initiating the maintenance. Operating system and data disks will be retained, but temporary disks will be reset.

See a list of your affected VMs at the bottom of this message.

For more control over when your VMs will be affected, migrate your deployments using the Azure portal or PowerShell by following the steps below. You must complete the migration prior to 11 October 2020 16:00 CST.

Migrate using the Azure portal

For both Classic and Azure Resource Manager (ARM) VMs:

Log into the Azure portal and navigate to the VMs you want to migrate.

Select “Stop” to stop and deallocate the VM. Please ensure the VM status has transitioned to “Stop (deallocated)".

Select “Start” only after the previous change in status has completed.

For VM scale sets:

Log into the Azure portal and navigate to the VM scale sets.

Select a VM scale set and select “Instances” from the left-side settings menu.

Select the VM you want to migrate.

Select “Deallocate” to stop and deallocate the VM. Please ensure the VM status has transitioned to “Stop (deallocated)”.

Migrate using PowerShell

In Azure PowerShell, invoke the command to stop an Azure VM without a “StayProvisioned” flag.

Example: Stop-AzVM -ResourceGroupName " ResourceGroupName" -Name "VirtualMachineName"

Learn more about stopping an Azure VM.
