https://portal.microsoftgeneva.com/s/A217BDD3

====Internal only:

Follow below steps convert the DNS PacketData

( validated to work on Ubuntu 18.04 LTS)

Run cmd in ubuntu: sudo apt update && sudo apt install python python-pip

Python’s dnslib - Install it with sudo -H pip install dnslib

Once the above is done, copy the below script into a text file and call it “decodens.py”:

#/usr/bin/python

#coding: utf-8

import sys

import dnslib

packethex = sys.argv[1] # This is the binary in hex encoding

packet = packethex.decode('hex') # Packet decoded from hex

dnspacket = dnslib.DNSRecord.parse(packet) # Parse binary and convert it into human readable strings

print(dnspacket) # Print output

Python3:

#!/usr/bin/python3

packet = bytes.fromhex(packethex) # Packet decoded from hex

Make it executable by running “chmod +x decodens.py”

run it passing the binary blob as the only parameter:
