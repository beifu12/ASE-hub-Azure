根据沟通请将以下测试总结反馈客户：

在Linux安装P2S连接需要使用strongSwan, Ubuntu 17.0.4支持 strongSwan GUI，配置步骤参考文档https://docs.microsoft.com/zh-cn/azure/vpn-gateway/point-to-site-vpn-client-configuration-azure-cert#install

Ubuntu 16.0.10 不支持 strongSwan GUI（下面一篇小兵的测试文档其实是可以的）。 如果想要使用 Ubuntu 16.0.10，则必须使用命令行。测试使用命令行如下反复测试P2S连接失败。

apt-get install strongswan-ikev2 strongswan-plugin-eap-tls

apt-get install libstrongswan-standard-plugins

sudo sed -i 's/\sload =.*/ load = no/g' /etc/strongswan.d/charon/{af-alg,ctr,gcrypt}.conf

/etc/ipsec.conf

config setup

conn azure

keyexchange=ikev2

type=tunnel

leftfirewall=yes

left=%any

leftauth=eap-tls

leftid=%client # use the DNS alternative name prefixed with the %

right=azuregateway-00112233-4455-6677-8899-aabbccddeeff-aabbccddeeff.cloudapp.net # Azure VPN gateway address

rightid=%azuregateway-00112233-4455-6677-8899-aabbccddeeff-aabbccddeeff.cloudapp.net # Azure VPN gateway address, prefixed with %

rightsubnet=0.0.0.0/0

leftsourceip=%config

auto=add

尝试使用Windows Server建立P2S连接，Linux 服务器与Windows Server建立连接通过NAT实现与VPN 网关连接。在测试过程中发现，Windows Server实现NAT转换是基于网卡的，可以Linux 服务器可以实现通过Windows Server NAT转换访问Internet。但是Windows Server在建立P2S连接时会建立PPP连接获得P2S连接地址，但是Windows Sever 不支持通过该地址实现NAT 和流量转发。
