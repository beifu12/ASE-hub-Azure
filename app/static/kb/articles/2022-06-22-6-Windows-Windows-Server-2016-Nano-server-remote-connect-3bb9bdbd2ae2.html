在一台Windows客户端 运行管理员模式PowerShell，启用PSremoting

Enable-PSRemoting

设置登陆的用户名，密码（创建虚拟机设置的用户名、密码）

$cred = get-credential

将Nano server IP地址添加到Client机器的TrustedHosts列表下（或者替代黄色标记为*）

Set-Item WSMan:\LocalHost\Client\TrustedHosts "42.159.83.225"

登陆

Enter-Pssession -ComputerName "42.159.83.225" -port 5985 -Credential $cred

退出登陆

Exit-PSSession
