---Azure 应用程序网关支持自定义SSL策略，

自定义 SSL 策略定义允许你选择以下三种协议之一作为网关的最低 SSL 协议版本：TLSv1_0、TLSv1_1、TLSv1_2。

如果未定义任何 SSL 策略，这 3 个策略（TLSv1_0、TLSv1_1、TLSv1_2）会全部启用。

Birthday attacks against TLS ciphers with 64bit block size vulnerability

TLS 64位分组密码生日攻击(CVE-2016-2183)，我认为此应在Azure层TLS中上修改才能完成，此issue需要Azure同事支持。

---参考文档中描述，https://feedback.azure.com/forums/169385-web-apps/suggestions/11158626-disable-tls1-0，为了防止CVE-2016-2183, CVE-2016-6329需要移除TLS_RSA_WITH_3DES_EDE_CBC_SHA cipher

TLS_RSA_WITH_3DES_EDE_CBC_SHA 存在于TLSv1_0中，可以通过关闭TLS1.0或者配置自定义SSL策略

具体请参考文档：https://docs.azure.cn/zh-cn/application-gateway/application-gateway-configure-ssl-policy-powershell

UDP Constant IP Identification Field Fingerprinting Vulnerability (does not apply to dev)

'The UDP implementation in Linux 2.4.x kernels keeps the IP Identification field at 0 for all non-fragmented packets, which could allow remote attackers to determine that a target system is running Linux.'

我认为这个不是安全的bug漏洞。一般在Linux Kernel 2.4.x上出现（好像这个是十年前发布的），目前我们后端的SUSE内核已升级到4.4了。请Azure同事确认。

---- 如描述该漏洞是关于Linux Kernel 2.4.x 内核的，Application gateway 是部署在Windows Server 内核上的。
