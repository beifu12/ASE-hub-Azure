Latest Update

2021-Jun-25

问题复现步骤：

创建一个https的listener，其证书从key vault拉取。可以看到，证书会被自动命名为listener name+"vaultcert"。

打开这个listener并且编辑其证书，创建一个新的证书并且从Key Vault选择。

提交后即出现报错。

F12错误返回代码400，并能看到如下错误信息：

{

"error": {

"code": "InvalidRequestFormat",

"message": "Cannot parse the request.",

"details": [

"code": "DuplicateResourceName",

"message": "Resource /subscriptions//resourceGroups//providers/Microsoft.Network/applicationGateways/ has two child resources with the same name (mylistenervaultCert)."

}

]

错误产生原因：

第二个从Key Vault拉取的证书也会被命名为listener name+"vaultcert"，与之前已经存在的证书重名。

Workaround:

勾选Renew or edit selected certificate来修改已经存在的证书。这样新的证书会覆盖旧的证书，而不是添加一个新证书。
