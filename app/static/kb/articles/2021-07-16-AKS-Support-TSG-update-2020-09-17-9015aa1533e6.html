Hi All,

Here’s the update for this week.

Nodepool shows user mode while it is actually system mode.

Issue appears on AKS Cluster 1.15.x and persists after upgrading to 1.16.13. Newly creating AKS 1.16.13 would not reproduce the issue

ICM:  https://portal.microsofticm.com/imp/v3/incidents/details/205541037/home

Label“kubernetes.azure.com/mode: system”of system nodepool can be get by kubectl describe command.

Doc: https://docs.azure.cn/zh-cn/aks/use-system-pools

Misunderstanding “kubelet is posting ready status.” message in BBM while agent node is already in not ready state.

//Black box monitoring for cluster

cluster("akscn").database("AKSprod").BlackboxMonitoringActivity

| where PreciseTimeStamp > ago(4d)

| where fqdn contains "fqdn"

| where state != "Healthy"

| project PreciseTimeStamp, state, provisioningState, reason, agentNodeCount, msg, resourceGroupName, resourceName, underlayName

| order by PreciseTimeStamp asc

provisioningState:        Succeeded
