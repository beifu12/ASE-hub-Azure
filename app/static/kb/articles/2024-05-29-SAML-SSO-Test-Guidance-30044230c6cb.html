2024/05/07

Here’s the KB of testing SAML SSO with non-gallery application (reference: Configure SAML-based single sign-on using Microsoft Graph - Microsoft Graph | Microsoft Learn). (No UI for now) The configuration steps are as below for your reference:

Create AAD SaaS Application and Service Principal with ClaimsX-Ray identifier and ReplyUrl set

Connect-AzureAD -AzureEnvironmentName AzureChinaCloud

$appName = "xuhuanSAMLAppTest"

$samlApp = New-AzureADApplication -DisplayName $appName `

-IdentifierUris "urn:microsoft:adfs:claimsxray" `

-ReplyUrls https://adfshelp.microsoft.com/ClaimsXray/TokenResponse

-SamlMetadataURL http://mynewapp.example5.com/metadata.xml `

New-AzureADServicePrincipal -AccountEnabled $true `

-AppId $samlApp.AppId `

-AppRoleAssignmentRequired $true `

-DisplayName $appName `

-Tags {WindowsAzureActiveDirectoryIntegratedApp},{WindowsAzureActiveDirectoryCustomSingleSignOnApplication}

Set SAML as the single sign-on mode in the service principal

PATCH https://microsoftgraph.chinacloudapi.cn/v1.0/servicePrincipals/64f8add3-be9e-4d7c-813c-a63fae19227c

Content-type: application/json

{

"preferredSingleSignOnMode": "saml"

}

Configure a self-signed certificate that Azure AD can use to sign a SAML response.

POST https://microsoftgraph.chinacloudapi.cn/v1.0/servicePrincipals/64f8add3-be9e-4d7c-813c-a63fae19227c/addTokenSigningCertificate

"displayName":"CN=xuhuansamlxraytest",

"endDateTime":"2025-01-25T00:00:00Z"

Assign users to the service principal

Test SAML SSO through the following link and you would get saml token as below if succeeds.

https://account.activedirectory.windowsazure.cn/applications/testfedaratedapplication.aspx?servicePrincipalId=<spObjectId>&tenantId=<tenantId>
