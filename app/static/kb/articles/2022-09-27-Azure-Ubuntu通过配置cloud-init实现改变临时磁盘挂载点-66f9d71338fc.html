Azure Ubuntu通过配置cloud-init实现改变临时磁盘挂载点 --Johnny Lee

默认情况下ubuntu虚拟机把/mnt作为了临时磁盘的挂载点

如果遇到必须将数据盘挂载到/mnt下目录的情况就会出现冲突。

解决方案如下:

由于ubuntu的云虚拟机使用cloud-init管理，所以默认使用修改Azure Linux 代理 (waagent)的方法一旦在portal上停止虚拟机就会失效。（Centos以及Free BSD可以通过修改waagent来实现相关配置）

以下是waagent不能生效的参数：

•Provisioning.Enabled 在使用 cloud-init 执行预配任务的 Ubuntu 云映像上默认为“n”。

•以下配置参数对使用 cloud-init 来管理资源磁盘并交换空间的 Ubuntu 云映像没有影响：

•ResourceDisk.Format

•ResourceDisk.Filesystem

•ResourceDisk.MountPoint

•ResourceDisk.EnableSwap

•ResourceDisk.SwapSizeMB

所以我们只能通过修改Cloud-init对应的配置文件来实现相关功能。

本篇我们就着重来介绍一下修改临时磁盘的挂载点/mnt，然后将数据磁盘挂载到/mnt下。
