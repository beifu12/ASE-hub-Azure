Update

2024-04-26

今天接到一个单子，客户使用storage account key连接azure file报错“The specified network password is not correct”。

1，经检查，key是正确的，可以通过storage explorer使用此key连接到存储并访问azure file。

2，从ASC上看到存储账户file有如下配置，经过对比测试查询，客户是配置文件共享安全性为“最大安全性”导致此配置。

3，根据如下文档描述，“如果删除了 NTLMv2，则无法使用存储帐户密钥装载 Azure 文件共享。”，修改回默认“最大兼容性”可以正常连接。

https://docs.azure.cn/zh-cn/storage/files/files-smb-protocol?tabs=azure-portal#smb-security-settings
