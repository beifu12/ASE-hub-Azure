问题描述：

==============

ASR Azure to Azure 复制项目创建后提示以下报错：

“Failed to create service principal for automation account MSStoreCh-nis-asr-automationaccount.”

问题原因：

目标可用性集与目标 VM 不在同一个资源组中。

解决方案：

新建可用性集并让其加入到目标 VM 所属的同一资源组中，然后重新启用复制即可成功。

另外，需要强调的是建议提前创建好目标可用性集，以免自动创建过程中出现异常报错。
