问题现象 / 场景

  • PAYG instances register using a different tool "registercloudguest". An instance that was originally BYOS cannot register as a PAYG instance unless it is switched to PAYG via Azure hybrid benefit. If the customer was originally a BYOS image (which we suspect they were BYOS) then the registration code they are using has expired and they need to renew thier license.

PG 原文：

If this instance was a BYOS instance, then it requires registration via a license code using "SUSEConnect" - however we know that the registration code being used is expired. The expired license would require that you reach out to your SUSE account manager to renew your license.

PAYG instances register using a different tool "registercloudguest". An instance that was originally BYOS cannot register as a PAYG instance unless it is switched to PAYG via Azure hybrid benefit. If the customer was originally a BYOS image (which we suspect they were BYOS) then the registration code they are using has expired and they need to renew thier license.

Product Support Lifecycle | SUSE

长期服务包支持 | SUSE

通过与产品组沟通确认，我们的PAYG 镜像是不包括LTSS许可的。
