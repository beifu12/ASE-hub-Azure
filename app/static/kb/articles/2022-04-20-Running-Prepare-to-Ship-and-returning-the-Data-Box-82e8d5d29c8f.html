背景信息

  • To start Prepare to Ship, in the device web UI, go to Prepare to Ship and click on "Start Preparation".
  • During the Prepare to Ship process, the Data Box shares will be taken offline and will not be accessible. Please ensure that all data to be imported is copied onto the shares prior to running Prepare to Ship. If there is more data that needs to be copied to the device, you can stop Prepare to Ship, unlock the device, copy the additional data, and then run Prepare to Ship again.

Prepare to Ship may take anywhere from a few hours for smaller data sets to several days for data sets containing many millions of files and/or blobs.

原始内容清洗稿（保留备查）

When using Data Box to import data into Azure, before return shipping the device back to the Azure datacenter, the customer must run the Prepare to Ship process. This process validates the data by:

Ensuring that checksums are generated for all files

Checking that all data conforms to Azure naming conventions

Checking that files and blobs are not too large for Azure storage file / blob size limits

Checking that all container and share names conform to Azure naming conventions

This process is required to prevent potential data upload failures due to data that does not conform with Azure storage requirements and limits.

To start Prepare to Ship, in the device web UI, go to Prepare to Ship and click on "Start Preparation".

During the Prepare to Ship process, the Data Box shares will be taken offline and will not be accessible. Please ensure that all data to be imported is copied onto the shares prior to running Prepare to Ship. If there is more data that needs to be copied to the device, you can stop Prepare to Ship, unlock the device, copy the additional data, and then run Prepare to Ship again.

The length of time required for Prepare to Ship to run depends on the amount of data the customer has written to the Data Box and the number of individual files and blobs. Prepare to Ship may take anywhere from a few hours for smaller data sets to several days for data sets containing many millions of files and/or blobs.

If Prepare to Ship completes with the status "Scan completed with errors", the customer should resolve these errors before returning the device. To see what errors have occurred, unlock the device and go to the Connect and Copy page to download the issues list. Information on how to correct issues identified by Prepare to Ship can be found in the Troubleshooting Prepare to Ship page of this OneNote. After correcting these issues, the customer will need to run Prepare to Ship again to validate that all errors have been resolved.

After the Prepare to Ship process completes without errors, the customer can proceed with shipping the Data Box back to the Azure datacenter for data import. The steps for return shipping of a Data Box device vary by country. More information on return shipping can be found at this link: Ship Data Box back.

For more information on Prepare to Ship and the return shipping process, please see this link: Return Azure Data Box and verify data upload to Azure.
