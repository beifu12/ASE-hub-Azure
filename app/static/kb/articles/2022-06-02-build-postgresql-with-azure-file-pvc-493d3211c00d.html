使用如下yaml 可以复现客户的问题

cat azure-file-sc2.yaml

kind: StorageClass

apiVersion: storage.k8s.io/v1

metadata:

name: cx-disk2

provisioner: kubernetes.io/azure-file

mountOptions:

  • dir_mode=0777
  • file_mode=0777
  • uid=000
  • gid=000
  • mfsymlinks
  • cache=strict
  • actimeo=30

parameters:

skuName: Standard_LRS

cat azure-file-pvc2.yaml

apiVersion: v1

kind: PersistentVolumeClaim

spec:

accessModes:

  • ReadWriteMany

storageClassName: cx-disk2

resources:

requests:

storage: 5Gi

cat cx-pvc-files2.yaml

kind: Pod

name: cx-pg2

containers:

  • name: cx-pg2

image: postgres:latest

cpu: 100m

memory: 128Mi

limits:

cpu: 250m

env:

  • name: POSTGRES_USER

value: pgbench

  • name: PGUSER
  • name: POSTGRES_PASSWORD

value: admin123

  • name: PGBENCH_PASSWORD

value: superpostgres

  • name: PGDATA

value: /var/lib/postgresql

PostgreSQL does not work with Azure file. This is because PostgreSQL requires hard links in the Azure File directory, and since Azure File does not support hard links the pod fails to start.
