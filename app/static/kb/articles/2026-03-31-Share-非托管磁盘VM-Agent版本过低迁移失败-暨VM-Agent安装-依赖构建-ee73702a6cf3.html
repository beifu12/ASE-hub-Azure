关联跟进的一个工单：SR_20260328401433_非托管磁盘迁移到托管磁盘 代理问题

1、其中一台是Centos7，升级并迁移成功采用的命令如下：

sudo systemctl stop waagent

cd /tmp

rm -rf WALinuxAgent-2.15.0.1 v2.15.0.1.tar.gz

curl -LO https://github.com/Azure/WALinuxAgent/archive/refs/tags/v2.15.0.1.tar.gz

tar xzf v2.15.0.1.tar.gz

cd WALinuxAgent-2.15.0.1

sudo python setup.py install --force

sudo systemctl daemon-reload

sudo systemctl start waagent

waagent --version

2、其中一台由于是Centos6.5，升级并迁移成功采用的命令如下：

sudo service waagent stop

rm -rf WALinuxAgent-2.14.0.1 v2.14.0.1.tar.gz

curl -LO https://github.com/Azure/WALinuxAgent/archive/refs/tags/v2.14.0.1.tar.gz

tar xzf v2.14.0.1.tar.gz

cd WALinuxAgent-2.14.0.1

sudo chkconfig waagent on

sudo service waagent start
