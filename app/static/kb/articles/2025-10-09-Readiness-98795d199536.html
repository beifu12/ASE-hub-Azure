Introduction

Azure Front Door (AFD) is a modern, cloud-native content delivery network (CDN) and application acceleration platform that provides secure, scalable, and high-performance delivery of web applications. As part of Microsoft’s commitment to expanding Azure services in sovereign cloud regions, this private preview introduces AFD capabilities in the Azure China, enabling customers to evaluate and validate core CDN and security features tailored to local compliance and infrastructure requirements.

Please note:

AFD is available in China North 3 and China East 3.

Only AFD standard and premium SKU’s are supported in Azure China.

There are China-specific configurations such as ICP filing for custom domains and some limitations that are not supported in Azure China yet. Details are captured in this documentation.

This document outlines the scope of the preview, known limitations, diagnostic tooling, and pricing guidance. It is intended for technical teams responsible for CDN configuration, security policy enforcement, and performance optimisation in the China Azure region.

Supported Scenarios

The following features are in scope for validation during the private preview:

CRUD operations for AFD resources:

AFD Profiles (custom create only)

AFD Endpoints

Custom domains with ICP filing

Routes

Caching and Compression

Secrets (Bring Your Own Certificate only)

SKU upgrade

Log scrubbing

Origin Groups and Origins

Private Link (ChinaNorth3 and ChinaEast3 only)

Security Policies

Rule Sets and Rules

Metrics

Out of Private Preview Scope

The following features are not included in the private preview:

Reports

Security Report

Diagnostic Logs

Azure Recommendations/Advisor

CRUD operations for WAF resources

Known Limitations

The following limitations apply to the Azure China deployment of AFD during the private preview:

No Quick Create Support

Due to ICP requirements, quick creation of AFD profiles is not supported. All resources must be created through the custom create.

Domain Requirement for Endpoint Association

At least one domain must be associated with a route and the endpoint during creation. Endpoints cannot be associated directly to routes without a domain.

No Managed Certificate Support

Only Bring Your Own Certificate (BYOC) is supported. Managed certificates are not available in Azure China.

Private Link Availability

Private Link support is limited to ChinaNorth3 and ChinaEast3 regions. Only Storage, Azure Container App are supported as the PL origins.

WAF Portal Limitations

The WAF portal experience is not available. Users must configure WAF policies through AFD security policies.

Private Preview Limitation only

Supports only API version 2024, custom cipher suite and origin authentication using managed identity is unsupported.

Diagnostic log is not available yet, but you can refer to Metrics.
