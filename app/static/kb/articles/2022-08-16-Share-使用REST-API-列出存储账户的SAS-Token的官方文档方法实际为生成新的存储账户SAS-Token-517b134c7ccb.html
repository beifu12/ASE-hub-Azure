下载安装Postman:

下载Postman 工具并安装，下载地址：

https://www.postman.com/downloads/

操作之前需要建立Collection

再建立Request，并选择存放在之前建立的Collection 下

2，通过Chrome 浏览器登录Portal后，获取认证信息Bearer Token：

3，然后在Postman Request 中，输入URL 中根据自己的信息替换（{}部分）并填入（management.chinacloudapi.cn为Azure China的api管理URL,不要用之前文档中那个）：

POST

https://management.chinacloudapi.cn/subscriptions/{subscriptionId}/resourceGroups/{resourceGroupName}/providers/Microsoft.Storage/storageAccounts/{accountName}/ListAccountSas?api-version=2021-09-01

在Body中选择“Raw” ---“JSON” ,然后配置具体的SAS Token参数，如下方信息。详细的参数信息，您可参考文档：https://docs.microsoft.com/en-us/rest/api/storagerp/storage-accounts/list-account-sas?tabs=HTTP#code-try-0

{

"signedServices": "b",

"signedResourceTypes": "s",

"signedPermission": "r",

"signedProtocol": "https,http",

"signedStart": "2017-05-24T10:42:03.1567373Z",

"signedExpiry": "2017-05-24T11:42:03.1567373Z",

"keyToSign": "key1"

}
