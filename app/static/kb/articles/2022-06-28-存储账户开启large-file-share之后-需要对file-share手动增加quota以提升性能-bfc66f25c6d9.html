一句话摘要

客户开启了large file share，但是file share拷贝时IOPS被限制在1000左右。

问题现象 / 场景

  • 客户开启了large file share，但是file share拷贝时IOPS被限制在1000左右。

背景信息

  • 客户开启了large file share，但是file share拷贝时IOPS被限制在1000左右。
  • 经测试，只要quota增加到大于5 TiB，file share的max IOPS会提升到10000。
  • 参考文档：Azure 文件可伸缩性和性能目标 | Microsoft Docs
  • 操作方法：
  • 首先将Maximum Capacity提升到100 TiB
  • 参考文档：创建 Azure 文件共享 - Azure Files | Microsoft Docs
  • 增加quota至大于5 TiB
