Nancy

官网提到从AKS 1.19+版本Azure将不再支持安装托管dashboard，官网链接：使用 Web 仪表板管理 Azure Kubernetes 服务群集 | Azure Docs

测试结果：

若在低于1.19版本集群上已经启用dashboard，然后再对其升级到1.19，dashboard使用不会受到影响。

若直接在新创建的1.19版本集群上启用dashboard会报错提示已经弃用。

经测试，可按照如下步骤在新建AKS 1.19+上启用dashboard：

1)部署dashboard UI：

kubectl apply -f https://raw.githubusercontent.com/kubernetes/dashboard/v2.0.0/aio/deploy/recommended.yaml

2)创建Service Account和Clusterrolebinding的yaml并应用：

[root@111myimagevnetvm zhangnan]# cat adminuser.yaml

apiVersion: v1

kind: ServiceAccount

metadata:

name: admin-user

namespace: kubernetes-dashboard

[root@111myimagevnetvm zhangnan]# kubectl apply -f adminuser.yaml

[root@111myimagevnetvm zhangnan]# cat clusterrolebinding.yaml

apiVersion: rbac.authorization.k8s.io/v1

kind: ClusterRoleBinding

roleRef:

apiGroup: rbac.authorization.k8s.io

kind: ClusterRole

name: cluster-admin

subjects:

  • kind: ServiceAccount

[root@111myimagevnetvm zhangnan]# kubectl apply -f clusterrolebinding.yaml

3)获取Bearer Token

kubectl -n kubernetes-dashboard get secret $(kubectl -n kubernetes-dashboard get sa/admin-user -o jsonpath="{.secrets[0].name}") -o go-template="{{.data.token | base64decode}}"

4)登录dashboard：

浏览器访问该URL并输入Token：http://localhost:8001/api/v1/namespaces/kubernetes-dashboard/services/https:kubernetes-dashboard:/proxy/

数据可以正常加载：
