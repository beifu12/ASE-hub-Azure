原始内容清洗稿（保留备查）

yum groupinstall  "X Window System"  -y

yum install gnome-*  -y

yum install  tigervnc-server tigervnc-server-module libXfont pixman xterm –y

4   vi  /etc/sysconfig/vncservers   #编辑VNC的配置文件加入下面两行

VNCSERVERS="1:root"

VNCSERVERARGS[1]="-geometry 1024x768"

startx      #启动x windows

vncpasswd  # 设定在本地使用vncviewer连接VM时 的密码，连续输入两次

vncserver :1  #启动vnc连接实例

chkconfig vncserver on   #设置开机下次开机自动运行VNC server

VNC server第一个连接默认监听5901 端口，需要在portal上设置VM的NSG规则，添加入站策略，放行5901端口

登录portal依次点击虚拟机-名称----网络接口---网络接口名称---网络安全组，然后点击入站安全规则---添加

在本地使用vncviewer 连接VM
