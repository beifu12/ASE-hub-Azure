需求：通过automation定期导出AAD login日志到本地进行保存。

大致操作分为：

1．需要将本地或者虚拟机注册到automation的混合辅助角色组

2．将本地或者虚拟机安装对应powershell模块

3．编辑automation的runbook

4．测试运行

详细操作(我测试使用的虚拟机)：

1）详细参考文档：https://docs.azure.cn/zh-cn/automation/automation-windows-hrw-install#manual-deployment

为log analytics开启自动化账户解决方案。

2）连接虚拟机到log analytics。

然后到log analytics中查询是否存在该虚拟机的心跳，如果存在说明连接已经成功。

Heartbeat

| where Category == "Direct Agent"

| where TimeGenerated > ago(30m)

3）然后到虚拟机内部，进行hybrid registration。

浏览到 C:\Program Files\Microsoft Monitoring Agent\Agent\AzureAutomation\ 并注意 version 子文件夹。

在管理员模式下打开 PowerShell 会话，并运行以下命令以导入模块。

cd "C:\Program Files\Microsoft Monitoring Agent\Agent\AzureAutomation\<version>\HybridRegistration"

Import-Module .\HybridRegistration.psd1

然后执行注册命令：

Add-HybridRunbookWorker –GroupName "nancytest" -Url "https://ab76be4d-a22b-40c5-8fad-0d46dxxxx.agentsvc.sha2.azure-automation.cn/accounts/ab76be4d-a22b-40c5-8fad-0d46db33f68a" -Key "zl2P4tXNUeKywYQYGFexH782wYEyUA50xxxxxo+QwEzBntB+rGpTGxqDFl+eMqiXqwIE2j505lg=="

##Url和Key到自动化账户的“键”页面获取。

可以看到已经注册完成。

安装测试需要用到模块。

我这里安装了az和AADpreview模块。

也可以从本地拷贝模块到虚拟机然后导入使用。

1）先在自动化账户创建好凭据

2）创建powershell工作流，然后编辑如下内容，定期保存到根据日期区分的文件中。

workflow exportaadloginlog

{

$Cred = Get-AutomationPSCredential -Name "zhangnan";

Connect-AzureAD -Credential $Cred -AzureEnvironmentName AzureChinaCloud;

$name=(get-date).AddHours(8).ToString("yyyy-MM-dd-HH-mm")

Get-AzureADAuditSignInLogs -All $true | Export-CSV "C:\AzureADAuditSignInLogs$name.CSV" -NoTypeInformation -Encoding UTF8

}
