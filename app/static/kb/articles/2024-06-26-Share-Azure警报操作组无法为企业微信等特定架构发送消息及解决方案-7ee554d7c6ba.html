问题现象 / 场景

  • 客户在Azure monitor警报操作组中添加Webhook调用企业微信机器人后，无法在企业微信中接收到警报信息。
  • Azure 警报发送的请求 Body中并没有msgtype参数，导致企业微信无法接收到信息：
  • 企业微信对msgtype参数属于特定架构，Azure警报负载无法满足此特定架构。

问题描述：

========

客户在Azure monitor警报操作组中添加Webhook调用企业微信机器人后，无法在企业微信中接收到警报信息。

排查过程：

先对操作组进行测试，看到使用样例警报内容，对Webhook操作是成功的。

进一步排查，企业微信消息文本接口中"msgtype"参数是必须的：

发送应用消息 - 文档 - 企业微信开发者中心 (qq.com)

Azure 警报发送的请求 Body中并没有msgtype参数，导致企业微信无法接收到信息：

配置 Webhook 以获取活动日志警报 - Azure Monitor | Azure Docs

解决方案：

企业微信对msgtype参数属于特定架构，Azure警报负载无法满足此特定架构。

对于特定架构接口，需要使用逻辑应用来操作。

在操作组中先调用逻辑应用，在逻辑应用中封装msgtype参数，之后由逻辑应用调用企业微信。

在工单中客户调用自己的接口后封装可以成功调用到企业微信。
