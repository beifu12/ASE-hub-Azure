HI All,

遇到客户需要使用AAD认证的方式使用Bastion登录VM，和大家分享一下具体使用方法

=== AAD认证前提条件===

支持的 Windows Server 2019 Datacenter 和更高版本，Windows 10 1809 和更高版本，Windows 11 21H2 更高版本

确保 VM 网络配置允许通过 TCP 端口 443 对以下终结点进行出站访问

https://enterpriseregistration.partner.microsoftonline.cn：用于设备注册。

http://169.254.169.254：Azure 实例元数据服务终结点。

https://login.chinacloudapi.cn：用于身份验证流。

https://pas.chinacloudapi.cn：用于 Azure RBAC 流。

3. 为 VM 启用 Azure AD 登录

Azure 门户（创建 Windows VM 时）。

Azure CLI，在创建 Windows VM 或使用现有 Windows VM 时。

4. 为 VM 配置角色分配

虚拟机管理员登录：分配了此角色的用户可以使用管理员权限登录到 Azure 虚拟机。

虚拟机用户登录：分配了此角色的用户可以使用常规用户权限登录到 Azure 虚拟机。

5. 通过 Azure AD 使用密码/有限无密码身份验证登录

仅允许从 Windows 10 或更高版本的电脑远程连接到已联接到 Azure AD 的 VM，而这些电脑需已注册了 Azure AD

联接到 Azure AD 或向 VM 所联接到的同一目录进行了混合 Azure AD 联接。 此外，对于使用 Azure AD 凭证的 RDP，用户必须属于两个 Azure 角色之一，即虚拟机管理员登录或虚拟机用户登录。

===Bastion配置和命令===

为Bastion启用本机客户端支持

客户端加入AAD. 在客户端和Azure VM上都启用了NLA

Bastion运行连接命令

az network bastion rdp --name "azz" --resource-group "0522" --target-resource-id "/subscriptions/88f28261-7c20-44dd-914f-1ce7ac0e76d2/resourceGroups/0522/providers/Microsoft.Compute/virtualMachines/a123321"
