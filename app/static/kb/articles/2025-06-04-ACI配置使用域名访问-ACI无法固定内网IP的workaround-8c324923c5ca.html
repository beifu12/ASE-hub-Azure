根据文档说明：容器组的静态 IP 地址 - Azure Container Instances | Azure Docs ，

如果容器组停止、启动或重启，容器组的专用 IP 可能会发生更改，ACI的内网IP无法固定。

为了应对ACI内网地址发生变化，可以考虑配置通过域名访问ACI，当ACI发生重启时，容器通过运行CLI命令，自动更新Private DNS zone中的容器域名和地址的映射关系。

大概思路如下：

1、创建一个Private DNS zone ,并将这个DNS zone关联到需要访问ACI的VNet，这个Private DNS zone的域名是ACI的自定义域

2、在容器组中包含一个运行CLI命令的容器custom container，该custome container支持运行Azure CLI命令，以及获取当前容器的内网IP

3、在启动容器的时候，运行custom container中提前设置好的CLI脚本，这个CLI脚本检查当前ACI Private IP，更新Private DNS zone中的A记录，将容器实例的域名，更新为最新的容器实例的Private IP

如何配置custom container ,参考：

1、通过CLI创建一个服务主体，用于custom conatiner中的CLI程序登录Azure，服务主体需要有操作Private DNS Zone以及ACI的权限，这里将ACI以及Private DNS zone部署在同一个资源组，因此完成对资源组的授权即可

az ad sp create-for-rbac --scopes /subscriptions/c1fe03e6-ff80-4d91-824d-ba495a000792/resourceGroups/cn3rg --role Contributor --name foraci -o json

记录下appid， password, tenant

2、创建script，用于获取ACI的IP以及更新Private DNS zone,以下脚本只是参考，脚本中的变量，我们将通过容器的变量传递给脚本

#!bin/bash

az cloud set -n AzureChinaCLoud

echo "Logging into Azure..."

az login --service-principal -u $SP_APPID -p $SP_PASSWORD --tenant $SP_TENANT

echo "Get ACI IP address..."

ACI_IP=$(az container show --name $ACI_INSTANCE_NAME --resource-group $RG --query ipAddress.ip --output tsv)

echo "ACI_IP is:" $ACI_IP

while [ -z $ACI_IP ] || [ "$ACI_IP" = "0.0.0.0" ] || [ "$ACI_IP" = "" ]

do

sleep 2

done

echo "Finally ACI_IP is" $ACI_IP

echo "Deleting old record if there was one"

az network private-dns record-set a delete -n $HOSTNAME -z $DNS_ZONE_NAME -g $DNS_RG -y

echo "Creating a new DNS record..."

az network private-dns record-set a create -n $HOSTNAME -z $DNS_ZONE_NAME -g $DNS_RG

az network private-dns record-set a add-record --record-set-name $HOSTNAME -z $DNS_ZONE_NAME -g $DNS_RG -a $ACI_IP

while true

DNS_IP=$(az network private-dns record-set a show -g $DNS_RG -n $HOSTNAME -z $DNS_ZONE_NAME --query aRecords[0].ipv4Address --output tsv)

if [ $DNS_IP != $ACI_IP ];then

echo "DNS_IP is not equal ACI_IP, Need restart"

break

fi

echo "DNSIP:$DNS_IP == ACI_IP:$ACI_IP, Next check"

sleep 120

echo "done"

exit 0
