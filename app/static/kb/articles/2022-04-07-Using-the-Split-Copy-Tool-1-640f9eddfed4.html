Split and copy data to disks

This optional procedure may be used when you are using multiple disks and have a large dataset that needs to be split and copied across all the disks. The Data Box Split Copy tool helps split and copy the data on a Windows computer.

Take the following steps to spit and copy the data

On your Windows computer, ensure that you have the Data Box Split Copy tool downloaded and extracted in a local folder.

Open File Explorer. Make a note of the data source drive and drive letters assigned to Data Box Disk.

Identify the source data to copy

Go to the folder where the software is extracted. Locate the SampleConfig.json file in that folder. This is a read-only file that you can modify and save.

Modify the SampleConfig.json file.

Provide a job name.

Supply a source path

Enter the drive letters corresponding to the target disks

Provide a path for the log files.

To validate the file format, go to JSONlint. Save the file as ConfigFile.json.

Open a Command Prompt window.

Run the DataBoxDiskSplitCopy.exe

Enter to continue the script.

When the dataset is split and copied, the summary of the Split Copy tool for the copy session is presented.

Verify that the data is split across the target disks.

If the copy session fails, then to recover and resume, use the following command:

DataBoxDiskSplitCopy.exe PrepImport /config:<configFile.json> /ResumeSession
