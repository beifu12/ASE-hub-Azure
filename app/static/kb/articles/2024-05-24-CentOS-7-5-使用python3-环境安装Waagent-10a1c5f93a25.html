Python 2.7 到2020年会End Of Life，由于有些系统的waagent使用的是python2 的版本。届时估计会有升级需求吧。

https://www.python.org/dev/peps/pep-0373/

之前使用setup.py方式安装第三方库的方式测试安装Waagent，如果系统环境为python2 ，waagent则会使用python2运行。如果为python3，Waagent则会通过python3 运行。

OneNote 链接：使用NVidia官方链接提供方法为CentOS 系统安装NVidia驱动

经过测试，通过手动使用python3进行升级安装waagent.  waagent会使用Python3运行。我的测试过程如下：

当前环境python配置：

编译安装python3.5

$ sudo yum install yum-utils

$ sudo yum-builddep python

$ curl -O https://www.python.org/ftp/python/3.5.0/Python-3.sys5.0.tgz

$ tar xf Python-3.5.0.tgz

$ cd Python-3.5.0

$ ./configure

$ make

$ sudo make install

$ python3 –version

安装路径为/usr/local/bin/python3.5

安装后下载waagent安装文件，并修改默认的python 路径

sudo ln -sf /usr/local/bin/python3/python3.6 /usr/bin/python

本篇文章来源于 Linux公社网站(www.linuxidc.com) 原文链接：https://www.linuxidc.com/Linux/2017-04/142916.htm

使用入下命令升级waagent

git clone https://github.com/Azure/WALinuxAgent.git

cd WALinuxAgent/

python setup.py install

sudo service waagent restart

升级后重启waagent服务

这时waagent的python版本已经变成3.5

查看运行进程以及日志，未发现异常。
