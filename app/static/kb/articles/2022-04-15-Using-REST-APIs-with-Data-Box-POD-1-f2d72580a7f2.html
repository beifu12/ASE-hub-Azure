背景信息

  • Customers can use the REST APIs to connect to a Data Box device over HTTP or HTTPS and copy blob data for import to Azure blob storage using Azure Storage Explorer, AzCopy, or a similar copy tool. The basic steps for connecting to the Data Box via REST using Azure Storage Explorer from a Windows PC are:
  • In the Data Box local web UI under "Connect and copy", click on the REST button.
  • Copy the information under Storage Account Name, Storage Account Key, and Blob Service Endpoint.
  • On the Windows PC, open the file C:\Windows\System32\drivers\etc\hosts in Notepad.
  • In the hosts file, add a line containing the Data Box device IP address and the blob service endpoint obtained from the Data Box web UI, then save the hosts file. See reference image below.
  • After performing these steps, in Storage Explorer you can expand the Data Box storage account and create new containers under Blob Containers, then copy data into these containers in order to import it into Azure blob storage.
  • For more information on using the REST APIs with Data Box devices, including information on using AzCopy with Data Box and on connecting via REST from a Linux client, please see the link below.

排查思路

  • If using HTTPS to connect to the Data Box, you will need to download a certificate from the Data Box job in the Azure portal and import it on the Windows client. To do this, go to the Data Box order information in the Azure portal, navigate to General - Device Details, and under Device Credentials click on the API Access tab. Then click the Download button to download the certificate. Once it is downloaded, you can right-click on the certificate and select "Install certificate". In the Certificate Import Wizard, choose Local Machine as the Store Location and place the certificate in the store named "Trusted Root Certification Authorities". Click Next and then Finish to install the certificate.
  • In Azure Storage Explorer, go to the Edit menu and click on Target Azure Stack. After changing this setting, clost and reopen Storage Explorer. Then open the Connect to Azure Storage dialog and choose the option for "Use a storage account name and key". On the next page, enter the storage account name, storage account key, and for the storage domain enter "mydataboxno.microsoftdatabox.com". If using HTTP, check the box for "Use HTTP", or to use HTTPS leave this box unchecked. Click Next and then Connect to finish connecting to blob storage on the Data Box.
