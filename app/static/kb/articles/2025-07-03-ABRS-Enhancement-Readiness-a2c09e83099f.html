Log gathering

Source -linux:

Navigate to the below location and gather the Guest Agent and Extension log files.

/var/lib/waagent/*.xml

/var/log/waagent.log

/var/log/azure/*

/var/log/azure/Microsoft.Azure.RecoveryServices.VMSnapshotLinux/<LatestVersion>/*

如果是waagent问题：

在 /etc/waagent.conf 文件中，找到以下行：Enable verbose logging (y|n)

将 Logs.Verbose 值从 n 更改为 y。

保存更改，然后遵循本部分前面所述的步骤重启 waagent。

Source VM high churn的情况下收集日志：

There is an in-build script to collect Linux Server logs for ASR: /usr/local/ASR/Vx/bin/collect_support_materials.sh

Please run this script in the source VM and it will create a package such as“support-materials-JDVPVI01-Oct_30_04_21_31.tar.gz”

或者直接拷贝下面的log：

/var/log/AzureRcmCli*.log

/var/log/svagents*.log

/var/log/srcTelemetry*.log

/var/log/s2*.log
