First, ensure TLS 1.2 for PowerShell gallery access.

[Net.ServicePointManager]::SecurityProtocol = [Net.ServicePointManager]::SecurityProtocol -bor [Net.SecurityProtocolType]::Tls12

Install the AzureADHybridAuthenticationManagement PowerShell module.

Install-Module -Name AzureADHybridAuthenticationManagement -AllowClobber

Set-AzureADKerberosServerEndpoint -TargetEndpoint 1

Specify the on-premises Active Directory domain. A new Microsoft Entra ID

Kerberos Server object will be created in this Active Directory domain.

$domain = $env:USERDNSDOMAIN

Enter an Azure Active Directory Hybrid Identity Administrator username and password. 如下输入Global admin 帐号

$cloudCred = Get-Credential

Create the new Microsoft Entra ID Kerberos Server object in Active Directory

and then publish it to Azure Active Directory.

Use the current windows login credential to access the on-premises AD. 登录域控执行

Set-AzureADKerberosServer -Domain $domain -CloudCredential $cloudCred

Get-AzureADKerberosServer -Domain $domain -CloudCredential $cloudCr

使客户端计算机可以获得具有 Microsoft Entra PRT 和完整的 Active Directory TGT，并可同时访问云和本地资源。
