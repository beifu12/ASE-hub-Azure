通常情况下FW创建出来的第一个IP由于跟pirvate IP绑定了导致无法删除（并且被使用在了跟平台层面的通信）：

如果使用删除FW的方式进行删除IP，客户并不愿意接受，这时候可以通过重启FW的方式来删除该IP：

假设FW 有两个publicIP，一个是publicip1,另一个是publicip2：

Stop the firewall

$azfw = Get-AzFirewall -Name "*" -ResourceGroupName "*"

$azfw.Deallocate()

Set-AzFirewall -AzureFirewall $azfw

Start the firewall

$vnet = Get-AzVirtualNetwork -ResourceGroupName "Network_Group" -Name "***"

$publicip = Get-AzPublicIpAddress -Name "publicip2" -ResourceGroupName "***"

$azfw.Allocate($vnet, @($publicip))

备注：该方法前提是客户不能有跟publicip1相关的防火墙规则，如果有的话再操作之前应提前删除相关规则。
