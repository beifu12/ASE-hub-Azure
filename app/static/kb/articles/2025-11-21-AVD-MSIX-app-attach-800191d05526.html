Below are the steps for setting up the MSIX app lab.

Intro

MSIX app attach is an application layering solution that allows you to dynamically attach apps from an MSIX package to a user session. The MSIX package system separates apps from the operating system, making it easier to build images for virtual machines. MSIX packages also give you greater control over which apps your users can access in their virtual machines. You can even separate apps from the master image and give them to users later.

Steps

Follow doc to set up MSIX packaging environment

Follow doc to Create an MSIX package. Pay attention to below items.

Create a self-signing certificate for test purpose.

$cert = New-SelfSignedCertificate -CertStoreLocation Cert:\LocalMachine\My -DnsName 'yourdomainname' -Type CodeSigningCert -Verbose

$secPassword = ConvertTo-SecureString -String 'yourpassword)' -Force -AsPlainText

$certPath = "Cert:\LocalMachine\My\$($Cert.Thumbprint)"

Export-PfxCertificate -Cert $certPath -FilePath 'C:\temp\CodeSigning.pfx' -Password $secPassword

Use MSI installer for example, select the certificate created in previous step.

Following MSIX packages will be created. Then follow doc to install the self-signed certificates in your session hosts.

Follow doc to create a Azure File Share for MSIX image (created in next step). It’s roughly the same procedure as setting up file share for FSLogix Profile. Use

Create an AD DS security group and add computer accounts for all session hosts as member of the group. Then sync it to Azure AD.

Create an Azure File Share and join the storage account to AD DS. You can use the same storage account for FSLogix.

Assign Storage File Data SMB Share Contributor role to both AVD users and session hosts.

Grant NTFS permissions on the file share to the AD DS group and AVD users.

Select a session host, follow doc to prepare an MSIX image on it. Then upload the VHD file to Azure File Share created in previous step.

Follow doc to add MSIX image to host pool

Follow doc to publish MSIX apps to app group
