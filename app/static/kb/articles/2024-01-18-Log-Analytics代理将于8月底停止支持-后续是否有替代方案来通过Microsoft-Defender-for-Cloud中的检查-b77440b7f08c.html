Update

Jia.xiaolei

Log Analytics代理将于8月底停止支持，后续是否有替代方案来通过Microsoft Defender for Cloud中的检查项 "Log Analytics agent should be installed on virtual machines"

Log Analytics agent将被Azure monitor Agent取代：https://docs.azure.cn/zh-cn//azure-monitor/agents/agents-overview  后续您可以通过：https://docs.azure.cn/zh-cn/azure-monitor/agents/data-collection-rule-azure-monitor-agent?tabs=portal AMA 将资源链接到Log Analytics workspace.

下方截图是我之前的一个测试用例，可以看到安装了AMA代理的VM，在Defender的检查项目“Log Analytics agent should be installed on virtual machines”中会被列到“Not applicable resources”下。

后续为VM安装AMA代理，即可以将VM置于“不适用”的资源中，不会影响这个检查策略“Log Analytics agent should be installed on virtual machines”的分数；

或

后续如果平台没有移除这个检查策略，也可以手动禁用这个检查策略“Log Analytics agent should be installed on virtual machines”；
