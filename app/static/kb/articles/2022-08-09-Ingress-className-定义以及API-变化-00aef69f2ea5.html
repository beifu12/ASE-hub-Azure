ingress的定义有两个重要的变化：

1、第一个是ingressClassName的定义方式已经有变化，需要定义在spec字段中

2、第二个是ingress 的API版本发生变化，beta版API将不支持

如下两个工单的问题都是AKS升级之后ingress访问不了的问题。

TechnicalPoint

SR_20220802181005_AKS 集群负载连接不通

Ingress 中ingressClassName在1.19以及以后的集群中建议定义在spec字段中，在annotation中定义的方式已经弃用：

https://kubernetes.io/docs/concepts/services-networking/ingress/

我们使用ingress-nginx 4.0.13 在AKS 1.24 上测试，在annotations中指定className的情况下，会报错

ingress class annotation is not equal to the expected by Ingress Controller" 与客户报错一致，而且ingress无法访问，在spec中指定className则无此问题

SR_20220705175609_Ingress Controller is not working after the AKS upgrade
