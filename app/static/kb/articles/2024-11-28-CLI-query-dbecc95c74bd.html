CLI query

LiHantao

当我们使用az cli命令来查询某些资源信息时，默认会以json的格式进行输出，它会把所有的信息详细展示出来，虽然完整但并不适合我们快速查看某一项属性，如下：

az vm show -g resourcelht -n cen73

[lihantao@cen73-new ~]$ az vm show -g resourcelht -n cen73

{

"additionalCapabilities": null,

"availabilitySet": null,

"diagnosticsProfile": {

"bootDiagnostics": {

"enabled": true,

"storageUri": "https://resourcelhtdiag872.blob.core.chinacloudapi.cn/"

}

},

"hardwareProfile": {

"vmSize": "Standard_A1"

"id": "/subscriptions/43f0bd4b-1b42-4efc-a0fa-0bd19834d2ba/resourceGroups/resourcelht/providers/Microsoft.Compute/virtualMachines/cen73",

"identity": null,

"instanceView": null,

"licenseType": null,

"location": "chinanorth",

… …

我们可以通过--query 参数来添加筛选条件，只输出我们希望看到的数据

az vm show -g resourcelht -n cen73 --query '[name,storageProfile]'

但是当需要查看的属性比较多的时候，输出可能还是不太友好，可以再将结果定义为字典，为每一项属性定义名称

az vm show -g resourcelht -n cen73 --query '{VMName:name, StorageProfile:storageProfile}'

当我们查询的结果为阵列，需要搜索指定条件的某一个对象的属性，则可通过下面的命令来检索

az vm list -g resourcelht --query "[?name=='cen73']"

同样，我们也可以在后面追加条件来指定只输出某些属性

az vm list -g resourcelht --query "[?name=='cen73'].[name, storageProfile]"

az vm list -g resourcelht --query "[?name=='cen73'].{VMName:name, StorageProfile:storageProfile}"

此外，当我们只知道某一属性中包含某个字段时，可以借助contains()函数来进行查询

az vm list -g resourcelht --query "[?contains(id, 'cen73')].{VMName:name, StorageProfile:storageProfile}"

最后，为了使结果更加直观，我们还可以用sort_by()函数来让结果按某一属性进行排序，效果如下

az vm list --query "[].{VMName:name, VMId:id}" -o table

az vm list --query "sort_by([].{VMName:name, VMId:id}, &VMName)" -o table
