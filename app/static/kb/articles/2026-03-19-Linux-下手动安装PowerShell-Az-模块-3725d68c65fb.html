直接通过 Install-Module -Name Az 安装模块有时会很慢 参考：https://github.com/PowerShell/PowerShellGallery/issues/171

Window 下可以通过msi安装包安装，Linux 下可以参考如下方式手动安装

CentOS 7.9为例测试 首先安装PowerShell 7以及AZ 模块

Register the Microsoft RedHat repository

curl https://packages.microsoft.com/config/rhel/7/prod.repo | sudo tee /etc/yum.repos.d/microsoft.repo

Install PowerShell

sudo yum install --assumeyes powershell

安装后可以查看成功安装

Start PowerShell

pwsh

$PSVersionTable.PSVersion

其他发行版本可以参考：

https://learn.microsoft.com/en-us/powershell/scripting/install/installing-powershell-on-linux?WT.mc_id=thomasmaurer-blog-thmaure&view=powershell-7.3&viewFallbackFrom=powershell-7

安装PowerShell 的Az 模块

Install-Module -Name Az -Scope CurrentUser -Repository PSGallery -Force

这里可能需要等待一段时间从PSGallery 下载安装模块

由于网络原因，可能会卡住

如果实在下载不动可以选择手动安装

mkdir -p /tmp/azcmdlets

cd /tmp/azcmdlets

wget https://github.com/Azure/azure-powershell/releases/download/v9.3.0-January2023/Az-Cmdlets-9.3.0.36817.tar.gz -O az.tar.gz

#最新下载连接参考https://github.com/Azure/azure-powershell/releases/latest

tar -xzf /tmp/azcmdlets/az.tar.gz -C /tmp/azcmdlets

pwsh /tmp/azcmdlets/InstallModule.ps1
