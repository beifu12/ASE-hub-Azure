ER线路如果资源组在东一北一，需要迁移到其他区域，目前不支持跨 Azure 区域迁移 Azure ExpressRoute 实例。所以需要在目标 Azure 其他区域中 创建新的 ExpressRoute 线路和新的 ExpressRoute 网关。

创建ER线路流程：

需要用户联系线路供应商，新建ER线路，参考文档：

快速入门 - 创建和修改 ExpressRoute 线路 - Azure 门户 | Azure Docs

创建的时候，资源组一定不能是东1和北1：

在线路的“概述”页上，可以找到“服务密钥”。 向服务提供商提供服务密钥，以便完成预配流程。 服务密钥对于线路是唯一的。

当连接服务提供商正在为你启用线路时，线路将更改为以下状态：

提供程序状态：预配

线路状态：已启用

若要使用 ExpressRoute 线路，该线路必须处于以下状态：

提供程序状态：已预配

配置对等：

需要确认好 ER线路的互连接口的地址段，VLANID，本地ASN号码，

Azure侧的ASN是12076，

配置 ExpressRoute 线路的对等互连 - Azure 门户 | Azure Docs

ER连接创建后与ER网关进行连接

1）必备条件

参考文档： https://docs.azure.cn/zh-cn/expressroute/expressroute-howto-linkvnet-portal-resource-manager

2）     开始预配： 选择“连接”>“添加”，打开“添加连接”页面

3）  输入连接的名称，然后选择“下一步: 设置 >”。

4）   选择要链接到线路的虚拟网络中的网关，然后选择“查看 + 创建”。 然后在验证完成后，选择“创建”。

5）    成功配置连接之后，连接对象会显示连接的信息。

如果运营商为您提供的是2层接入，那就需要您在本地设备上配置路由信息：

Azure ExpressRoute：路由器配置示例 | Azure Docs

以上配置完成后，就有两条ER线路从用户本地连接到Azure云，然后用户可以按照以下方法来切换ER线路：

创建新的 ExpressRoute 线路 | Azure Docs

如果已通过第 3 层服务提供商拥有 ExpressRoute 线路，请在 Azure 门户中的订阅下创建新线路。 与服务提供商合作，将流量无缝切换到新线路。 服务提供商取消预配旧线路后，请从 Azure 门户将其删除。

如果你是通过第 2 层服务提供商或 ExpressRoute 直接端口而拥有 ExpressRoute 线路，则本文档的其余部分适用。
