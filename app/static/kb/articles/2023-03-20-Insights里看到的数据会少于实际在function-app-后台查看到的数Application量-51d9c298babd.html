问题现象 / 场景

  • 经过研究，发现为什么“从Application  Insights里看到的数据会少于实际在function app 后台查看到的数量。  例如： 从12/16 02：00-03：00 (UTC)时间，客户发送了2000条，在application insight 显示的是1731 条，在function app 查看后台数据是2000条。” 是因为Application Insights中采样/Sampling这个功能的存在。 由于这个sampling功能，Application Insights不一定会提取(ingest)全部的数据，需要结合采样速率。 具体请参考文档：  Azure Application Insights 中的遥测采样 - Azure Monitor | Azure Docs

经过研究，发现为什么“从Application  Insights里看到的数据会少于实际在function app 后台查看到的数量。  例如： 从12/16 02：00-03：00 (UTC)时间，客户发送了2000条，在application insight 显示的是1731 条，在function app 查看后台数据是2000条。” 是因为Application Insights中采样/Sampling这个功能的存在。 由于这个sampling功能，Application Insights不一定会提取(ingest)全部的数据，需要结合采样速率。 具体请参考文档：  Azure Application Insights 中的遥测采样 - Azure Monitor | Azure Docs

Azure Function默认引入了自适应采样。  参考文档: https://docs.azure.cn/zh-cn/azure-monitor/app/sampling#adaptive-sampling

我们从平台日志看到当前Application Insights abinbevddcn-proai的采样率为86.1194。

用户可以对照文档和以下query语句查一下sampling RetainedPercentage。

requests

| where cloud_RoleName == "abinbevddcn-o9tocontroltowerapi-profa"

| summarize RetainedPercentage = 100/avg(itemCount) by bin(timestamp, 1h), itemType

Start time:   2021-12-16T02:10:00+00:00

End Time:  2021-12-16T03:00:00+00:00

若要关闭自适应采样，可以参考：
