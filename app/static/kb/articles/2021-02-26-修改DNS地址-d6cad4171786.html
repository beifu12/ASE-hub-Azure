创建修改DNS脚本


/etc/init.d/renewdns.sh

#!/bin/sh

# Start/stop the &lt;renewdns/testScript&gt; daemon.

#

### BEGIN INIT INFO

# Provides:         &lt;renewdns/testScript&gt;

# Required-Start:    $all

# Required-Stop:

# Default-Start:     2 3 4 5

# Default-Stop:

# Short-Description: &lt;Change Azure Auto inject DNS server IP&gt;

### END INIT INFO

if [ -e /etc/resolv.conf ];then

sed -i 's/nameserver.*/nameserver 8.8.8.8/g' /etc/resolv.conf

else

echo 'change ip failed'

fi

创建启动systemd服务

/etc/systemd/system/renewdns.service

[Unit]

Description=renewdnsip service

After=network.target

After=NetworkManager-wait-online.service

After=nis-domainname.service

After=dbus-org.freedesktop.resolve1.service

[Service]

Type=idle

PIDFile=/opt/renewdns/pid

ExecStart=/bin/sh /etc/init.d/renewdns.sh

ExecStop=/bin/kill -s TERM $MAINPID

PrivateTmp=true

RemainAfterExit=yes

[Install]

WantedBy=multi-user.target

重载服务

systemd daemo-reload

添加开机启动

systemctl enable renewdns.service

通过reslov.conf可以查看到已经修改了。

配置的思路是让开机启动加载完平台自动化的一些服务插件以后在启动该脚本服务。类型如果选择一次性服务那么systemd无法保证你的服务在他们启动完成后再启动（猜测systemd并行加载，顺序不是固定的，type为idle为等你们都忙完我在干活）
