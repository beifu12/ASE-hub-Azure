原始内容清洗稿（保留备查）

关于对虚拟机流量的监控，可以采用这两个工具：nload和ifto。关于这两个工具的安装，参考：

1、CentOS安装

启用Epel的源

yu install epel-release

Yum 安装nload和iftop

Yum install nload -y

Yum install iftop -y

2、Ubuntu安装

如果是Ubuntu虚拟机可以直接

Apt-get install nload

Apt-get install iftop

下面介绍这两个工具的使用方法，建议在root权限下使用

nload

安装nload 之后，直接执行nload ，可以显示incoming和outgoing总的流量情况

其中：Curr表示当前的下载/上传速度

Avg表示从开机到现在平均的下载/上传速度

MIN/MAX: 表示从开机到现在平均的最大/最小 下载/上传速度

Ttl:表示虚拟机开启到现在总的下载和上传的数据总量

调整Azure的监控，使监控从1/6  21:35开始， 统计数据到1/9 16:22（CST）

从Azure的流量监控看，从1/6 21:35开始到1/9 16:22虚拟机总共输出364MB，输入700MB，共1.06GB的数据。但是这部分流量是付费的流量，虚拟机内网通信的流量不会计入到监控中。

也就是说从虚拟机里面看，网卡的输出/输入 流量均大于监控显示的流量。因此这是一个正常的情况。

iftop

直接执行iftop -P -n 可以显示哪些Ip正在与虚拟机进行通信，以及通信速度和端口信息

中间的<= =>这两个左右箭头，表示的是流量的方向。=>表示发送。<=表示接收

最右侧的三个小列，这些实时参数分别表示外部IP连接到本机 2s 10s 40s 平均流量值

TX：发送流量

RX：接收流量

TOTAL：总流量

Cum：运行iftop到目前时间的总流量

peak：运行iftop到目前时间流量峰值
