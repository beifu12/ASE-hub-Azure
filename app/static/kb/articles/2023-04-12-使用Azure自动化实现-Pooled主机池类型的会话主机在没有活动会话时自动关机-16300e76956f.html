经测试，可以使用Azure自动化实现Pooled主机池类型的会话主机在没有活动会话时自动关机。

自动化账户登录，请您参考：

https://docs.azure.cn/zh-cn/automation/create-run-as-account

获取主机池Session，请您参考：

https://docs.microsoft.com/en-us/powershell/module/az.desktopvirtualization/get-azwvdusersession?view=azps-7.5.0

获取主机池Host信息，请您参考：

https://docs.microsoft.com/en-us/powershell/module/az.desktopvirtualization/get-azwvdsessionhost?view=azps-7.5.0

脚本的编写已经超出了Azure 的支持范围，但是为了您更好的体验，以下自动化脚本供您参考。

注：请将黄色部分替换为您环境中的值，并在测试环境中充分测试后再用于生产环境。

$cred = Get-AutomationPSCredential -Name 'zhanglihong'

Connect-AzAccount -Credential $cred -Environment azurechinacloud

Set-AzContext -SubscriptionId "5a-1d78d16bc519"

$HostPoolName = "win10sharepool1"

$ResourceGroupName = "wvd"

#obtain all sessionhosts in the hostpool

$SessionHosts = Get-AzWvdSessionHost -HostPoolName $HostPoolName -ResourceGroupName $ResourceGroupName

foreach($SessionHost in $SessionHosts)

{

#if the session count of the sessionhost is 0, stop the VM

if ($SessionHost.Session -eq 0)

Stop-AzVM -Id $SessionHost.ResourceId -Force;

Write-Output "Host“ $SessionHost.ResourceId “has no session, stopped successfully"

}

#if the session count of the sessionhost > 0

if ($SessionHost.Session -gt 0)

#obtain all the sessions of the sessionhost

$UserSessions = Get-AzWvdUserSession -HostPoolName $HostPoolName -ResourceGroupName $ResourceGroupName -SessionHostName $SessionHost.Name.Split("/")[1]

#if contains one Active session, do nothing; else stop the VM.

if ($UserSessions.SessionState -contains "Active" )

Write-Output "Host“ $SessionHost.ResourceId “has active session"

else

Write-Output "Host“ $SessionHost.ResourceId “has no active session, stopped successfully"
