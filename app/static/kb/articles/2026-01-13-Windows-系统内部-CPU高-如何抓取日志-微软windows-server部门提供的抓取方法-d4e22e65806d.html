Windows 系统内部 CPU瞬时冲高并迅速回落这个是正常现象，只有持续保持在高占用率才可能需要去进一步排查的。我们可以抓取日志的时候，尽量可以让问题复现得越明显。

在问题发生时需要抓取以下日志，以下是具体步骤：

===============

//Perfmon

以管理员身份运行CMD并运行命令：

Logman.exe create counter Perf-1Seconds -f bincirc -max 4000 -c "\LogicalDisk(*)\*" "\Memory\*" "\Network Interface(*)\*" "\PhysicalDisk(*)\*" "\Cluster CSV File System(*)\*" "\Cluster CSV Volume Manager(*)\*" "\SMB Client Shares(*)\*" "\SMB Server\*" "\SMB Server Shares(*)\*" "\SMB Server Sessions(*)\*" "\SMB Direct Connection(*)\*" "\Server\*" "\Server Work Queues(*)\*" "\System\*" "\Process(*)\*" "\Processor(*)\*" "\Cache\*" "\Cluster CSV Volume Cache(*)\*" "\Cluster CSV Coordinator(*)\*" "\Cluster Storage Hybrid Disks(*)\*" "\Cluster Storage Cache Stores(*)\*" "\ReFS(*)\*" "\Storage Spaces Write Cache(*)\*" "\Storage Spaces Virtual Disk(*)\*" "\Storage Spaces Tier(*)\*" "\RDMA Activity(*)\*" “\Hyper-V Virtual Network Adapter(*)\*” “\Hyper-V Virtual Network Adapter Drop Reasons(*)\*” "\Hyper-V Hypervisor Virtual Processor(*)\*" "\Hyper-V Virtual Storage Device(*)\*" "\Hyper-V Hypervisor Logical Processor(*)\*" "\Cluster Disk Counters(*)\*" -si 00:00:01 -o C:\PerfMonLogs\Perf-1Second.blg

开启性能日志

Logman start Perf-1seconds

问题复现后3-5分钟停止性能日志

Logman stop Perf-1seconds

//WPR

以管理员身份运行CMD，并运行：

md c:\temp

WPR.exe -start CPU -start DiskIO -start FileIO -start Network

3分钟后运行以下命令停止wpr

WPR.exe -stop c:\temp\WaitAnalysis.etl

//TSS

之后再抓取TSS日志，请参考下面的步骤。

a.  从以下地址下载TSS工具：

下载网址：

https://aka.ms/getTSS

检查下载的TSS.ZIP的属性，如果有以下显示，请先解除锁定：

b.  在C盘根目录下创建一个目录C:\SetupReport，并将TSS工具解压到其中

c.  以管理员权限打开一个PowerShell窗口，并使用命令以下命令切换到C:\Setupreport\TSS

cd C:\Setupreport\TSS

运行示例截图：

d.  运行以下的命令：

Set-ExecutionPolicy -scope Process -ExecutionPolicy RemoteSigned -Force

.\TSS.ps1 -CollectLog DND_SetupReport -AcceptEula

如果有Eula界面弹出，请阅读其中信息，并选择是否接受。

注：如果选择不接受的话，脚本会停止运行。

e.  脚本会运行10-20分钟 (根据机器性能而定)，运行结束后，屏幕会有以下的输出：

f.  日志文件会默认打包并保存C:\MS_DATA，将C:\MS_DATA下TSS开头的压缩包发送给我们。
