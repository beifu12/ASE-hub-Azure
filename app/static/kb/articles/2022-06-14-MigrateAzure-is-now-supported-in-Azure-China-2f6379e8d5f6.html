背景信息

  • Please note that Azure Migrate is now supported in Azure China
  • What has changed?
  • Customers can create projects in Azure China via the respective URLs mentioned in the docs below. For creating the project in Azure China geography, the metadata storage location for this will be China North 2.
  • Doc links:
  • What's new in Azure Migrate - Azure Migrate | Microsoft Docs
  • Supported geography: Azure Migrate support matrix - Azure Migrate | Microsoft Docs
  • URL access needed for Azure Migrate appliance setup: Azure Migrate appliance - Azure Migrate | Microsoft Docs
  • URL access needed for replication appliance setup Azure Migrate replication appliance - Azure Migrate | Microsoft Docs
  • For assessments, only Azure VM assessment is supported in Azure China, and support for following will be added in upcoming releases (based on availability of the respective Azure products in the region):
  • Ultra-disk recommendation in Azure VM assessment
  • Azure SQL assessment
  • Azure App Services assessment
