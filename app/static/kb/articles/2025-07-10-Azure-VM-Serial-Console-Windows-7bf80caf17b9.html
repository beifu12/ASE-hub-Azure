本期向大家介绍几个可以使用Azure Serial Console解决的Windows VM的问题，以下用例操作系统为Windows Server 2022

一，在串行控制台中使用 CMD 或 PowerShell

连接到串行控制台。 如果成功连接，则提示为 SAC>：

输入 cmd 以创建具有 CMD 实例的通道；

输入 ch -si 1 或按 <esc>+<tab> 快捷键切换到运行 CMD 实例的通道；

按 Enter，然后输入具有管理权限的登录凭据；

输入有效凭据后，将打开 CMD 实例；

若要启动 PowerShell 实例，请在 CMD 实例中输入 PowerShell ，然后按 Enter。

二，防火墙配置有误，导致无法RDP登录，通过Azure Serial Console关闭Windows防火墙

在防火墙入站规则中未允许RDP连接，如：

通过Azure Serial Console关闭Windows系统防火墙；

三，检查/启动RDP服务

登录Azure Serial Console，在CMD命令行执行“sc query termservice”检查RDP服务状态；

在CMD命令行执行“sc start termservice”启动RDP服务；

再次检查RDP服务状态，查看、确认服务是否已经启动成功；

四，在操作系统内部为网卡配置了错误的IP地址，导致虚拟机无法RDP连接登录

在Windows操作系统内部为网卡配置了IP地址，如：

在Azure Serial Console切换到Powershell命令行下，执行“Get-NetIPConfiguration”命令查看当前网卡配置，注意红线标出的参数；

Update 实际工单中 如果客户是禁用了网卡，那么使用 Get-NetIPConfiguration 看不到禁用的网卡，需要使用如下命令查看网络接口：

netsh interface show interface

然后使用 netsh interface set interface name="<interface name>" admin=enabled 启用网卡

查看Azure portal上虚拟机网卡配置，执行如下命令，为网卡重新配置IP地址

New-NetIPAddress -InterfaceIndex “13” -IPAddress 10.1.0.4 -PrefixLength 24 -DefaultGateway 10.1.0.1

五，进入Windows系统安全模式

在管理命令提示符下运行以下命令：

bcdedit /set {bootmgr} displaybootmenu yes

bcdedit /set {bootmgr} timeout 10

bcdedit /set {bootmgr} bootems yes

通过Azure portal的Azure Serial Console处重启VM；

按F8选择安全模式，或其他选项执行
