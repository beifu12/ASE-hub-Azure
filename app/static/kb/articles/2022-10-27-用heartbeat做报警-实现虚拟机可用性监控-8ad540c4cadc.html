通过Log analytic 语句：

// Display the VM's reported availability during the last day.

Heartbeat

| where Computer == "centos751"

| summarize heartbeat_count = count() by bin(TimeGenerated, 1min)

// bin is used to set the time grain to 1 minutes

| extend alive=iff(heartbeat_count > 0, true, false)

| sort by TimeGenerated asc

// sort the results by time (ascending order)
