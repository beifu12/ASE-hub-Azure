请新建用户并向其授予权限，添加 Azure AD DS 管理员。使用AADDS作为WVD的域服务，节点池虚拟机加入到AADDS。

在中国东2或中国北2创建和部署常规用途 v2 Azure 存储帐户，然后启用“Azure 文件存储的 Azure Active Directory 身份验证”。

需要为每个用户分配一个具有适当访问权限的角色。如选择“访问控制 (IAM)”。在“添加角色分配”选项卡中，从角色列表中选择适当的内置角色。 至少需要选择“存储文件数据 SMB 共享参与者”，帐户才能获得适当的权限。

本地管理员权限，RDP登录session host 虚拟机，登录 VM 后，以管理员身份运行命令提示符运行如下命令，先挂载Azure 共享，然后为挂载的文件设置NTFS权限。

net use <desired-drive-letter>: \\<storage-account-name>.file.core.chinacloudapi.cn\<share-name> /user:azure\<storage-account-name> <storage-account-key>

如：

通过运行以下命令：

icacls <mounted-drive-letter>: /grant <user-email>:(M)

icacls <mounted-drive-letter>: /grant "Creator Owner":(OI)(CI)(IO)(M)

icacls <mounted-drive-letter>: /remove "Authenticated Users"

icacls <mounted-drive-letter>: /remove "Builtin\Users"

可允许 Azure 虚拟桌面用户创建自己的配置文件容器，同时阻止其他用户访问其配置文件容器。

再新建Multi-String Value名为 VHDLocations，设置文件共享的url
