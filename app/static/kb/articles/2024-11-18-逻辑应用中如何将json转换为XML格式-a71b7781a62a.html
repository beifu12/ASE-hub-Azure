如何将JSON字符串解析或拼接成规定的XML格式，

JSON格式示例：

{"BATCHNO":"21411YZE36","BUDAT":"20210506","KOSTL":"1A0005","LFART":"ZLF","LIFNR":"600001","ZWMSNO":"210506003388","VBELN":"0106855584","KUNWE":"600002","SPART":"10","ARTNR":"F0000101","WRBTR":"10.00"}

需要解析的XML文档格式要求：

<?xml version="1.0" encoding="UTF-8"?>

<ns0:ZFI_DOC_OTMS xmlns:ns0="urn:sap-com:document:sap:rfc:functions">

<ET_OTMS>

<item>

<BATCHNO>21411YZE35</BATCHNO>

<BUDAT>20210426</BUDAT>

<KOSTL>1A0005</KOSTL>

<LFART>ZLF</LFART>

<LIFNR>600001</LIFNR>

<ZWMSNO>210426003388</ZWMSNO>

<VBELN>0106855583</VBELN>

<KUNWE>600002</KUNWE>

<SPART>10</SPART>

<ARTNR>F0000101</ARTNR>

<WRBTR>10.00</WRBTR>

</item>

</ET_OTMS>

</ns0:ZFI_DOC_OTMS>

通过排查客户这种格式直接转XML有问题需要添加一个根：

这里测试了一下，您的json文件需加一个根：

{"item":{"BATCHNO":"21411YZE36","BUDAT":"20210506","KOSTL":"1A0005","LFART":"ZLF","LIFNR":"600001","ZWMSNO":"210506003388","VBELN":"0106855584","KUNWE":"600002","SPART":"10","ARTNR":"F0000101","WRBTR":"10.00"}}

而您要添加的其他字符串可以通过concat函数合并：

表达式中函数的参考指南 - Azure Logic Apps | Azure Docs

concat('<?xml version="1.0" encoding="UTF-8"?>',xml(json(variables('test'))))

之后就可以转换正您需要的xml形式了。
