Hi All:

最近有客户问当前文件共享超过预配容量的80%时发送通知，做了些测试，给大家同步一下。

测试发现通过Get-AzMetric，对于标准存储账户，不能拆分各个File Share，只能取所有文件共享使用量的和。

示例命令：

#查看存储账户下所有文件共享的使用量#

Get-AzMetric -ResourceId "/subscriptions/1447ccf1-xxxx-xxxx-xxxx-2f370d142fa6/resourceGroups/hanasa/providers/Microsoft.Storage/storageAccounts/hanasa/fileServices/default" -MetricName "FileCapacity" -AggregationType Total

#查看存储账户下单个文件共享的使用量#

Get-AzMetric -ResourceId "/subscriptions/1447ccf1-xxxx-xxxx-xxxx-2f370d142fa6/resourceGroups/hanasa/providers/Microsoft.Storage/storageAccounts/hanasa/fileServices/hanatest" -MetricName "FileCapacity" -AggregationType Total

在公网链接https://www.saoniuhuo.com/question/detail-2687528.html?sort=new&page=1 中有人提到了与1中类似的情况，并提出可以使用Azure 存储文件SDK的方式来查看文件共享的使用量，我本地测试测试了一下是可以，然后做了如下的脚本。

$accountName = "hanasa"

$accountKey = "7R4sMu7BsWhRXuzOamlJ1m4vd1goxxxxxxxq1OOKbu+bUtthfq50Puuk++AStECnu2Q=="  #存储账户密钥#

$shareName = "hanatest"  #需要监视的文件共享#

$limit = 0.1  #警报阈值#

$toAddress = "liu.huan3@oe.21vianet.com"  #收件人地址#

$emailSubject = "File Share $shareName usage exceeded the limit"

$emailBodyTemplate = "The current usage of File Share {0} is {1} GB, which has exceeded the {2}% of the quota {3} GB ."

$ctx = New-AzStorageContext -StorageAccountName $accountName -StorageAccountKey $accountKey

$share = Get-AzStorageShare -Name $shareName -Context $ctx

$client = $share.ShareClient

获取文件共享的统计数据

$stats = $client.GetStatistics()

$shareUsageInBytes = $stats.Value.ShareUsageInBytes

$shareUsageInGiB = $shareUsageInBytes/1024/1024/1024

Write-Host "The file share usage is $shareUsageInGiB GB."

获取配额

$QuotaGiB = $share.Quota

Write-Host "The file share quota is $QuotaGiB GB."

计算使用量百分比

$usagePercentage = $shareUsageInGiB / $QuotaGiB

检查使用量是否超过阈值%

if ($usagePercentage -gt $limit) {

$emailBody = [string]::Format($emailBodyTemplate, $shareName, $shareUsageInGiB, $limit*100 ,$QuotaGiB )

发送警报邮件

$smtpCredential=new-object -typename System.Management.Automation.PSCredential -argumentlist "xxxxx@126.com",(ConvertTo-SecureString "VZPPxxxxTGBZGD" -AsPlainText -Force) #定义smtp服务器的凭据，绿色高亮部分为126邮箱SMTP授权码 #

Send-MailMessage -To $toAddress -From "xxxxx@126.com" -Subject $emailSubject -Body $emailBody -SmtpServer "smtp.126.com" -Credential $smtpCredential -Port "25" -UseSsl

Write-Host "email sent to the $toAddress already "

} else {

Write-Host " not reach the limit, current usgae is $shareUsageInGiB, the quota is $QuotaGiB"

}
