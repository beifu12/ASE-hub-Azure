如下是测试反馈：

首先使用如下powershell 命令行创建一个根证书，多个客户端证书：

$rootParams = @{

Type                = 'Custom'

Subject             = 'CN=Root Cert@marketing.contoso.com'

KeySpec              = 'Signature'

KeyExportPolicy      = 'Exportable'

KeyUsage             = 'CertSign'

KeyUsageProperty     = 'Sign'

KeyLength            = 2048

HashAlgorithm        = 'sha256'

NotAfter             = (Get-Date).AddMonths(24)

CertStoreLocation    = 'Cert:\CurrentUser\My'

}

$rootCert = New-SelfSignedCertificate @rootParams

Export-Certificate -Cert $rootCert -FilePath "$env:USERPROFILE\Desktop\RootCert.cer"

$clientCount = 5

$domain = 'marketing.contoso.com'

1..$clientCount | ForEach-Object {

$clientName = "Client$_@$domain"

$clientParams = @{

Subject             = "CN=$clientName"

DnsName             = $clientName

KeySpec             = 'Signature'

KeyExportPolicy     = 'Exportable'

KeyLength           = 2048

HashAlgorithm       = 'sha256'

NotAfter            = (Get-Date).AddMonths(18)

CertStoreLocation   = 'Cert:\CurrentUser\My'

Signer              = $rootCert

TextExtension       = @('2.5.29.37={text}1.3.6.1.5.5.7.3.2')

$clientCert = New-SelfSignedCertificate @clientParams

$pfxPath = "$env:USERPROFILE\Desktop\$clientName.pfx"

$password = ConvertTo-SecureString -String "Password123" -Force -AsPlainText

Export-PfxCertificate -Cert $clientCert -FilePath $pfxPath -Password $password  #

然后在证书管理平台找到这个根证书并导出cert 证书上传到VPN 网关
