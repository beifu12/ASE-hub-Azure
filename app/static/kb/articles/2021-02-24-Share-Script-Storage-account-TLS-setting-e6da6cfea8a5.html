The following Azure PowerShell command is used to set the separate storage account TLS for your reference：

==============================================

$rgName = "<resource-group>"

$accountName = "<storage-account>"

Read the MinimumTlsVersion property.

(Get-AzStorageAccount -ResourceGroupName $rgName -Name $accountName).MinimumTlsVersion

Update the MinimumTlsVersion version for the storage account to TLS 1.2.

Set-AzStorageAccount -ResourceGroupName $rgName `

-AccountName $accountName `

-MinimumTlsVersion TLS1_2

Below is my test environment settings for your reference:

I have tested the following script to enable TLS1.2 for all storage accounts in a subscription, just for your reference:

$subscription = Get-AzSubscription

foreach ($sub in $subscription) {

Set-AzContext -SubscriptionId $sub.id

$resourcegroup = Get-AzResourceGroup

foreach ($rg in $resourcegroup) {

$storageaccount = Get-AzStorageAccount -ResourceGroupName $rg.resourcegroupname

foreach ($sa in $storageaccount) {

Set-AzStorageAccount -ResourceGroupName $rg.resourcegroupname -AccountName $sa.StorageAccountName -MinimumTlsVersion TLS1_2

}
