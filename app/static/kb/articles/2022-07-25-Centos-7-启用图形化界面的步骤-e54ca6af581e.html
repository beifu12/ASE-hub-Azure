测试环境：

[root@centos70 ~]# uname -a

Linux centos70 3.10.0-123.20.1.el7.x86_64 #1 SMP Thu Jan 29 18:05:33 UTC 2015 x86_64 x86_64 x86_64 GNU/Linux

操作步骤：

yum groupinstall "X Window System"

yum install gnome-classic-session gnome-terminal nautilus-open-terminal control-center liberation-mono-fonts

设置默认启动图形化

unlink /etc/systemd/system/default.target

ln -sf /lib/systemd/system/graphical.target /etc/systemd/system/default.target

安装vnc server

yum install tigervnc-server –y

配置vnc

cp /lib/systemd/system/vncserver@.service /etc/systemd/system/vncserver@:1.service

vi /etc/systemd/system/vncserver@:1.service

测试中使用root用户进行登陆。请对以上配置文件信息进行如下修改

ExecStart=/sbin/runuser -l root -c "/usr/bin/vncserver %i"

PIDFile=/root/.vnc/%H%i.pid

重启systemd

systemctl daemon-reload

设置vnc用户密码

vncpasswd

启动vnc并设置开机启动

[root@centos70 ~]# systemctl start vncserver@:1.service

[root@centos70 ~]# systemctl enable vncserver@:1.service

虚拟机内部查看vnc的侦听端口后，并在azure端启用相应端点

[root@centos70 ~]# netstat -anop|grep vnc

tcp 0 0 0.0.0.0:5901 0.0.0.0:* LISTEN 33802/Xvnc off (0.00/0/0)

tcp6 0 0 :::5901 :::* LISTEN 33802/Xvnc off (0.00/0/0)
