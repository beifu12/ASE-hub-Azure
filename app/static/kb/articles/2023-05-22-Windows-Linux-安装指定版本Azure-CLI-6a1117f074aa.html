默认情况下我们通过yum \ apt \ msi 从官网获得的都是最新版本Azure CLI，但是由于某些原因（如API版本过高，中国区无法使用潜在问题等），我们可能需要旧版本的Azure CLI 本文主要介绍如何安装指定版本Azure CLI

Azure cli github：https://github.com/Azure/azure-cli/releases

针对 CentOS：

所有历史版本RPM包都可以在此下载：https://packages.microsoft.com/yumrepos/azure-cli/

安装命令 rpm -ivh xxxxx.rpm

注意：CentOS下需要提前安装python2-virtualenv

针对Ubuntu：

我没有找到Deb 安装列表，不过基于CentOS 和 Ubuntu的通用性，可以使用 alien 命令将 RPM包转换成 Deb 包

之后使用 dpkg -i xxxx.deb 进行安装

针对Windows：

Windows版本下载URL格式如下：https://azurecliprod.blob.core.windows.net/msi/azure-cli-2.1.0.msi

我们只需更改版本编号即可。https://azurecliprod.blob.core.windows.net/msi/azure-cli-2.0.71.msi
