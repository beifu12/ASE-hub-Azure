可以通过Azure PowerShell + Azure automation 执行定时快照或者azcopy 复制file share中的文件到其他Azure file中以起到备份的作用。

以下是通过Azure PowerShell + Azure automation 定时获取快照，并删除4天以前的快照。

具体脚本如下：

$Cred = Get-AutomationPSCredential -Name "cmtest";

Add-AzAccount -Credential $Cred -EnvironmentName AzureChinaCloud;

Select-AzSubscription -SubscriptionName "VM-Caomengruiqing (21v)";

创建新快照

New-AzRmStorageShare -ResourceGroupName "AZ-100-C2" -StorageAccountName "afsync01" -Name "a01" -Snapshot

清除4天前的快照

$storageAccount = Get-AzStorageAccount -ResourceGroupName "AZ-100-C2" -Name "afsync01" -ErrorAction Stop

$snapshotList = Get-AzStorageShare -Context $storageAccount.Context

$snapshotList = $StorageAccount | Get-AzStorageShare

$snapshotRetentionDays = 4

foreach ($snapshot in $snapshotList) {
