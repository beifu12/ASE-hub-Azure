默认Let's encrypt 签发的是EC加密，

目前azure CDN 只支持RSA算法，

Azure CDN HTTPS 加速服务- 客户自有证书| Azure Docs

sudo apt update

sudo apt install certbot

指定 --key-type rsa

sudo certbot certonly --rsa-key-size 2048 \

-d tangxin.azurecn.cn \
