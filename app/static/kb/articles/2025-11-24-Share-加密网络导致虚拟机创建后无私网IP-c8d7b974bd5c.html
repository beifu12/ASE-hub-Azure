问题现象 / 场景

  • 当前页面显示VM状态running，boot diagnostic中截屏能显示登陆界面，但是properties中agent status unknown.

背景信息

  • Gao Xieen
  • 问题情况：
  • 机器可能出现的情况：
  • 创建新的虚拟机会一直卡住。
  • 问题原因：
  • 由于虚拟网络加密功能目前仍在preview。导致虚拟机内部不能获得内网IP，因此不能完成预配置。
  • 参考：
  • 什么是 Azure 虚拟网络加密？ - Azure Virtual Network | Azure Docs
  • 在虚拟机网络的属性中，关闭虚拟网络加密。
  • 调查和测试过程：
  • 请参考以下的演示。
  • 在虚拟网络的安全设置中找到加密选项。
  • 开启网络加密。
  • 部署到对应已经启用加密的网络中。
  • 此时虚拟机创建会一直卡住。
  • Boot Diagnostics 会一直处于黑屏。
  • Redeploy这台机器。
  • 此时可以使用serial console登入。但是会发现IP和DNS地址丢失。
  • 将虚拟机尝试停止。
  • 禁用网络加密。
  • 尝试开机
  • 此时网络恢复。
  • Ip获取正常。
  • 恢复的虚拟机是没有安装agent的。可以后续RDP到虚拟机中安装。
  • 后续测试在该网络中在创建一个新的虚拟机。
  • 建立正常。

  • 可以查看 boot diag，但是没有网络。
