分享一个知识点，如何查看AKS 集群是使用的是服务主体还是托管标识？具体是使用的用户分配的托管标识，还是系统分配的托管标识。

Onenote 链接：

通过Azure CLI，更多请参考官方文档链接： https://docs.azure.cn/zh-cn/aks/use-managed-identity#determine-which-type-of-managed-identity-a-cluster-is-using

示例命令

#查看AKS 托管标识#

az aks show --name myAKSCluster--resource-group myResourceGroup--query identity --output json

如果群集使用托管标识，则 type 属性的值将为 SystemAssigned 或 UserAssigned。

如果群集正在使用服务主体，则 type 属性的值为 null。

#查看AKS 集群服务主体#

az aks show --name myAKSCluster--resource-group myResourceGroup--query servicePrincipalProfile --output json

如果群集使用服务主体，则会返回服务主体的Client ID
