Enabling cert auto rotate should be supported when certs are uploaded as PEM (To be verified)

对于上个月updates中提到的下述tips，鉴于相关风险，相应的request（“Back-to-origin IP list merge/simplify request”  ）与PM沟通后加入Non-standard operation process/非标操作流程。

We return all the back-to-origin IP lists from all providers, including backups.

A rough summary of the number of back-to-origin IP lists per provider is as follows:

Baidu: 120+

BaiShan: 100+

KingSoft: 300+

Tecent: 500+

Since providers have already provided IP blocks, we cannot merge them further.

If customer is concerned about the length, we suggest engaging PG team. We can switch the customer’s provider to Baidu or BaiShan and exclude all backups for them.

Though the IP list contains backups, we suggested customers to periodically refresh the list since there stands a chance that providers change their back-to-origin list.
