安装完了Remote Desktop Licensing服务的License提示报错：

The remote session was disconnected because there are no Remote Desktop License Servers available to provide a license.

解决方法：

1.  "Use the specified Remote Desktop license server     Enabled"

Under 'license server to use - enter the FQDname/IP of the servery you're trying to connect to:

"<RD License server internal ip address>"

2.  "Set the Remote Desktop licensing mode     Enabled" - Under "Specify the Licensing mode..."

"Per Device/Per User"
