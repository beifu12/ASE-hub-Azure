2024.6.8

关联工单：SR_20240418289277_Azure backup center中的SQL Server in Azure VM备份无法发现数据库

问题描述：

用户在Azure Backup Center中发现SQL Serer in Azure VM，其中一个VM中的数据库不能被发现；只能显示一个数据库被Found；近期删除了的数据库在备份中显示的又还存在。

问题原因： 不明。

问题解决： 参考Azure文档，给NT AUTHORITY\SYSTEM添加了sysadmin role分配了sysadmin角色。

问题排查：

确认问题现象，该VM中只有一个DB Found：

备份Items中查看已经被发现的数据库备份状态显示又是Healthy的， unhealthy的DB实际已在SQL Server中删除;

用户同时反馈之前类似的问题，通过将该Vault的soft delete禁用，然后停用此SQL server的保护，然后再重启添加该SQL Server（重新注册）；将问题解决了；但这次用户希望能够查找一下原因。

同时用户通过将SQL Server的自动防护设置为OFF，然后重新发现DB，但依旧显示只有一个DB被Found。
