1.使用Cli无交互式登陆订阅:

az login Azure china subscription with the following command

Change to Azure China cloud environment

az cloud set --name AzureChinaCloud

#use xxx@xxx.partner.onmschina.cn login

az login -u 'xxx@xxx.partner.onmschina.cn'

Create a service principal (It will show the appId password and tenant, please copy these value)

az ad sp create-for-rbac --name ptsp21525

logout the current user “xxx@xxx.partner.onmschina.cn”

az logout

Login using the created service principal

az login --service-principal --username appId --password xxxxxxxxxx --tenant xxxxxxxxxxxx

2.使用AZ PowerShell无交互式登陆订阅:

$client_id = "fbxxxxxxxxxxxxxxxxxxxx99c"

$client_secret = "5gxxxxxxxxxxxxxxxxxxxxG"

$tenant_id = "b3xxxxxxxxxxxxxxxxxxxx9b"

$SecurePassword = ConvertTo-SecureString "$client_secret" -AsPlainText -Force

$credentials = New-Object System.Management.Automation.PSCredential($client_id, $SecurePassword)

#Login to Azure China

Connect-AzAccount -Credential $credentials -ServicePrincipal -Tenant $tenant_id –Environment AzureChinaCloud

3.无交互式PowerShell登陆AAD

#1. 首先使用Service principal来登陆订阅

#2.成功登陆订阅后通过获取的token来登陆AzureAD：

#get AzAccount login context

$ctx = Get-AzContext

#get AzAccount login token

$token = Get-AzAccessToken -ResourceUrl https://graph.chinacloudapi.cn

#login Azuread

Connect-AzureAD -AadAccessToken $token.Token -AccountId $ctx.Account.Id -TenantId $ctx.Tenant.Id -AzureEnvironmentName AzureChinaCloud
