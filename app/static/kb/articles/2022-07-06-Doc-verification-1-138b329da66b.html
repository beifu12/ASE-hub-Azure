  • 3. The estimated SLA is up to 5 business day for disk preparation. Cx may not be willing to wait for so long. Can Cx get an option in portal to push the dispatch in case of some urgent situation so backend can priority the order?
  • During communicating with Operation team, I was told that once the disks are ready, Customer will wait 1 ~ 2 working days to let DC apply for security record. The security record is for the situation that people who pick up or drop off package will enter DC gate. But in China, carrier usually pick up and drop off package around the gate where DC operator will take the package to. So, it does not require the security record. Thus, once operation team acknowledged the pickup request and provided the Authorization code in Portal, Customer should have been able to contact DC operator to pick up the disk.
  • Another question is about the working time of DC operator. For MS managed shipment, DC operator says Fedex doesn’t work during weekend. But for self-managed shipment, the available time is still business day. This didn’t help to save the shipment time comparing to MSM.
