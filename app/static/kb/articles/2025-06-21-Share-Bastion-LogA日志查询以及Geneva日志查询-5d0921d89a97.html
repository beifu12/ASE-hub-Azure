Bastion 的日志查询和其他产品一样，需要先在诊断设置中启用logA才能查询。

查询语句参考如下：

MicrosoftAzureBastionAuditLogs

//| project TimeGenerated, OperationName, Message, SessionStartTime, ClientIpAddress

| sort by TimeGenerated desc

示例：

支持查询的字段：

Azure Monitor Logs reference - MicrosoftAzureBastionAuditLogs - Azure Monitor | Microsoft Learn

该日志中的错误信息只会显示登录失败，不会显示登录失败原因。
