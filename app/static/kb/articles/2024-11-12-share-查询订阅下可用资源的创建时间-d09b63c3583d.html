UI可以使用“资源浏览器”来查询Azure资源的创建时间，下面关键步骤供参考：

进入资源浏览器

展开订阅，资源组，部署，点击需要查询的资源并展开后点击操作

在显示的json信息查询操作是create的timestamp即为资源创建时间

Use REST API Postman（Updated from 左大）

参考：Resources - List - REST API (Azure Resource Management) | Microsoft Learn

安装Postman程序，如上文档使用的链接是对应全球版Azure的资源，可以替换为中国区的终结点如下：

https://management.chinacloudapi.cn/subscriptions/替换订阅ID/resources?api-version=2021-04-01&$expand=createdTime
