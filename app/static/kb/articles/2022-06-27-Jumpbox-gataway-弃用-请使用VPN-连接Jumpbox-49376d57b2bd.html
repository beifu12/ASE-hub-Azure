申请JIT，或者直接使用BJS20SPARE01. CME.GBL 或者 SHA20SPARE01.CME.GBL 测试

连接Jumpbox

4.1 直接通过JIT 申请的Jumpbox 权限， 并下载RDP文件的，可以直接使用RDP 连接，不需要修改任何配置。

注2：可以将申请的JIT 的RDP 文件保存在特定的位置，不用每次都下载，后续如果申请同一Jumpbox, 可以使用之前对应Jumpbox名称的RDP 文件。

4.2 使用 Remote Desktop Connection (mstsc) 连接

运行 mstsc，输入Jumpbox 名称 -->  Show Options --> Advanced  --> Settings --> 勾选 "Automatically detect RD gateway server settings" 取消勾选“Use These RD Gateway Server settings”--> OK--> connect

4.2 使用Remote Desktop Connection Manger 连接

选择根组 --> 右键“属性” --> Gateway Settings -->  去掉勾选的“Use a TS Gateway server”

下面的所有的子组以及Jumpbox  --> 右键“属性” --> Gateway Settings -->   勾选“Inherit from parent ”

使用完成后，建议从Jumpbox logoff , 然后断开VPN
