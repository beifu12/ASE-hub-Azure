Hi Team,

I’d like to share this approach for how to get the VFP stateful flow table, it’s useful when you need debug datapath related issue.

Tools: FcShell

Parameters: Cluster-ID, Node-ID, Container-ID,InterFaceMac(optional if there is only one vNIC)

Command: (Get-Fabric Cluster-ID).FabricConnection.NetworkManagementService.GetVfpFiltersForContainer('Node-ID','Container-ID','InterfaceMac','VFP_DEFAULT_LAYER_STATEFULL','','',''

,'','','','list-flow','').VfpContainerConfiguration.VfpRules

Example:

(Get-Fabric sha20prdapp03).FabricConnection.NetworkManagementService.GetVfpFiltersForContainer('0bb60521-27b0-4cf9-865f-492225891c91','afc3fb07-9d17-4434-a56c-df31e43e0111','','VFP_DEFAULT_LAYER_STATEFULL','','',''

,'','','','list-flow','').VfpContainerConfiguration.VfpRules > c:\netshare\flow.txt

Outputs:

Switch        : External

Port          : External_0003FF024FD7

MacAddress    : 0003FF024FD7
