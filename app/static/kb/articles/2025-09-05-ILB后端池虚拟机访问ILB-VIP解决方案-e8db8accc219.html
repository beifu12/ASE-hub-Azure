一句话摘要

ILB后端池的机器，如果访问ILB VIP，肯定会遇到时通时不通的问题。引起这个问题的原因就是当后端池的机器访问ILB时，如果ILB将访问的流量映射到该服务器本身，那么由于该流的源目IP都是该服务器本身，因此这是一个环回口的数据包，该服务器将不会向外回复该数据包，造成访问失败。因此后端池中的虚拟机访问ILB VIP肯定会遇到时通时不通的现象。所以要避免后端池中的虚拟机访问ILB VIP。但是在有的应用场景中，后端池中的虚拟机需要访问ILB VIP。

（2）Windows虚拟机配置方法

i)配置物理网卡

1、 打开命令行，输入ipconfig /all查看虚拟机的IP地址和子网掩码和DNS

2、 打开以太网属性，选择“使用下面的IP地址”，填入第一步看到的虚拟机的IP

3、 点击高级，添加IP地址。我的环境中添加的IP地址为192.168.2.100，掩码设置为32位。

此时虚拟机可能会失去远程连接，如果重试仍然连接不上，请重启后再次尝试连接。

或者

ii)配置环回口

如果不方便在物理网卡做修改，可以将VIP添加到环回口. 说明如下：

添加ILB VIP：

netsh int ip add address "Ifindex" VIP MASK

netsh int ip add address 1 192.168.2.100 255.255.255.255 16

然后将物理网卡和环回口全部设置成weakhost模式

netsh interface ipv4 set interface ‘IFindex’ weakhostreceive=enabled

netsh interface ipv4 set interface 1 weakhostreceive=enabled

netsh interface ipv4 set interface 1 weakhostsend=enabled

netsh interface ipv4 set interface 12 weakhostreceive=enabled

netsh interface ipv4 set interface 12 weakhostsend=enabled
