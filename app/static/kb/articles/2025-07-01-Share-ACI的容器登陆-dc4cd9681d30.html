目前我们可以将bash命令传入。

请参考文档：az container | Microsoft Learn

需要使用Azcli 先登录到订阅中。

但是由于API 版本的问题我们无法在最新的Az cli中运行此命令。

经过我的测试，该命令可以在 2.63.0的版本中使用。

参考文档： 如何在 Docker 容器中运行 Azure CLI | Microsoft Learn

使用以下的命令创建一个名为azcliold的容器，并指定2.63.0的版本运行。tail -f /dev/null 是一个保持容器运行的占位命令

sudo docker run -d --name azcliold mcr.microsoft.com/azure-cli:2.63.0-cbl-mariner2.0 tail -f /dev/null

查看容器运行。

使用以下的命令进入容器中的bash。

sudo docker exec -it azcliold bash

接着就可以使用以下的命令进入到容器实例中。

az container exec --exec-command "/bin/bash" --name <容器实例名称>--resource-group <资源组名称>
