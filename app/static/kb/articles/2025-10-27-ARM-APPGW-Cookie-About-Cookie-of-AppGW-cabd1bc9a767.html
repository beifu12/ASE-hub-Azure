Answer zhangliang’s question, what is the expiry time for waf affinity cookie?

First let us see what is the cookie type?

There are 2 different types of cookies: Session cookies and persistent cookies

If a cookie does not contain an expiration date, it is considered a session cookie. Session cookies are stored in memory and never written to disk. When the browers closes the cookie is permanently lost from this point on.

If the cookie contains an expiration date, it is considered a persistent cookie. On the date specified in the expiration, the cookie will be removed from the disk.

There are several different fields a cookie can contain, seperated by semicolons. Definitions are below:

expires:

expires="Wdy, DD-Mon-YYYY HH:MM:SS GMT"

Determines when the cookie is to be deleted.

Thereby there are Session cookies and persistent cookies.

And if there is no expiry time, it is considered to be session cookie.

It is identified from my dump:

Our WAF generates session cookie which means this is temporary cookie for the client, when the client close the session or the browser is closed, the cookie is removed.

If the same client initiate a new request to web app server, WAF will attach a new session cookie to “remember” this distribution(let’s say it is distributed to server1, backend pool has server1,2,3), the subsequent requests from this client in this session, will be directed to server1 consistently.
