2026/2/5

在处理 Web 交互相关问题时，我们通常会通过 Wireshark 抓包来分析请求与响应过程。但当前大多数访问都基于 HTTPS，抓到的报文内容会被 TLS 加密，Wireshark 默认只能看到 TLS Application Data，无法直接查看其中的 HTTP 明文内容，从而限制了进一步的分析和排查。

下面提供一种方法：使用浏览器生成的 TLS 密钥文件，在 Wireshark 中解密 HTTPS 报文。

【操作步骤】

步骤一：通过浏览器生成 TLS 密钥日志

使用提供的 PowerShell 脚本（分别对应 Chrome 和 Edge）。

在 PowerShell 中运行脚本后，会自动启动浏览器窗口。

在该浏览器窗口中访问目标站点，复现问题场景。

此时浏览器会自动生成 TLS 密钥日志文件（例如：D:\sslkeylog.txt）。

示例：

查看D盘，已经生成了这个文件

步骤二：使用 Wireshark 抓包并配置TLS解密

与此同时，我们可以在wireshark上开始抓包，在未解密前，HTTPS 流量通常只会显示为：TLS Application Data，无法看到具体的 HTTP 请求与响应内容。

我们在wireshark中做如下配置：

1）打开 Wireshark → Edit → Preferences

2）Protocols → TLS

3）设置 (Pre)-Master-Secret log filename：D:\sslkeylog.txt

4）点击Apply或OK

完成上述配置后，原先显示为 TLS Application Data 的数据包中，将可以看到解密后的 HTTP 明文内容。

【注意事项】

必须使用通过脚本启动的浏览器窗口访问目标站点，普通浏览器进程不会生成密钥日志。

密钥日志文件需与抓包时间段一致，否则无法解密对应流量。
