后台调查集群出现不健康状态是在5月29号左右，节点无法向控制平台汇报心跳。

我们尝试使用命令更新集群：az aks update --name myAKSCluster --resource-group myResourceGroup，等待几十分钟，集群状态还是异常

【缓解方法】

由于集群一直处于失败的状态中，所以其在Azure Portal上取消白名单功能的设置按钮为灰色。在这种情况下，建议用户使用命令行方式进行设置。禁用授权IP

Azure Kubernetes 服务 (AKS) 中的 API 服务器已授权 IP 范围 - Azure Kubernetes Service | Azure Docs

az aks update --resource-group myResourceGroup --name myAKSCluster --api-server-authorized-ip-ranges " "（双引号中添加一个空格）

经过与产品组的确认，该问题是由于一个临时性的后台问题所导致。在此情况下，请暂时使用以下命令进行设置。（双引号中添加一个空格）

如果在执行上述命令时，遇到错误提示仍有后台任务运行，可考虑使用中止命令取消任务。
