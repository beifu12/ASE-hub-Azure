Problem Description：

=====================

GET 504 error when post request at https://www.schott.cn/zh-cn/get-in-touch

System Environment/ Application information:

========================================

Client>>>>CDN>>>>APPGateway>>>WEB APP

Investigation Steps:

a.      We checked the access log (UTC +0) on the CDN side, the client get 504 error code , the POST request processing time of each 504 status code is about 10s

b.     We also checked the access log of the APPGW (UTC +8) and figured out APPGW logged 499 Error code , which means the CDN side closed connection actively

c.      We tested the connection without CDN accelerated network and found the post request was handled normally and the processing time was about 20-30 s

Problem Reason:

The timeout setting on the CDN side seems to be shorter than the normal processing time of the WEB APP

Resolution:

extended the default timeout of 10s to 30s on the CDN side
